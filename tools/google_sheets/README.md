# Google Sheets Sync

Этот инструмент собирает операционную таблицу для физики из текущей Obsidian-базы.

Главное правило:

```text
Obsidian -> Google Sheets
```

Obsidian остается первичным источником истины. Google Sheets является витриной и операционным представлением: расписание, темы, программы, прогресс, KPI, домашние задания и безопасные представления для учеников/родителей.

## Что уже реализовано

- Парсинг Markdown-файлов с YAML frontmatter.
- Сбор тем `type: curriculum_topic`.
- Сбор программ `type: curriculum`.
- Legacy-импорт учеников-кандидатов из папок `Репетиторство/Шизончик/Статистика учеников`, если для них еще нет карточек `type: student`.
- Разбор порядка тем внутри Markdown-программ через `[[wikilinks]]`.
- Создание 15 листов по утвержденной схеме.
- CSV-экспорт всех листов для проверки без Google-credentials.
- Опциональная запись в настоящий Google Spreadsheet через service account.
- Базовое оформление Google Sheets: заморозка первой строки, фильтр, жирный заголовок, автоширина.

## Быстрая проверка без Google Sheets

Из корня vault:

```powershell
python tools/google_sheets/sync_to_google_sheets.py --csv-only
```

CSV появятся в:

```text
Репетиторство/Шизончик/Google Sheets Export
```

## Подключение Google Sheets

1. Создай Google Cloud project.
2. Включи Google Sheets API.
3. Создай Service Account.
4. Скачай JSON-ключ.
5. Создай Google Spreadsheet.
6. Дай доступ на редактирование email сервисного аккаунта.
7. Установи зависимости:

```powershell
python -m pip install -r tools/google_sheets/requirements.txt
```

8. Запусти синхронизацию:

```powershell
python tools/google_sheets/sync_to_google_sheets.py `
  --spreadsheet-id "GOOGLE_SPREADSHEET_ID" `
  --credentials "E:/path/to/service-account.json"
```

## Важное про доступ родителей и учеников

Не выдавай родителям и ученикам доступ к основному Spreadsheet. Скрытые листы не являются защитой данных.

Правильная модель:

- рабочий Spreadsheet закрыт;
- родительские и ученические витрины экспортируются отдельно;
- один ученик/семья видит только свои строки;
- персональные и служебные поля не попадают во внешние представления.

Текущие листы `12_Доступ_ученики` и `13_Доступ_родители` являются внутренними витринами для последующего экспорта в отдельные файлы.

## Где брать данные

Сейчас синхронизатор читает:

- `Репетиторство/Шизончик/Теория/**/*.md` для тем;
- `Репетиторство/Шизончик/Базы/*.md` для программ;
- `Репетиторство/Шизончик/Статистика учеников/*` как временные legacy-кандидаты учеников;
- любые файлы vault с `type: student`, `type: group`, `type: lesson`, `type: homework`, `type: progress`, `type: test_result`, если они появятся позже.

Если расписание будет оформлено в Obsidian как `type: lesson`, оно автоматически попадет в `05_Расписание`.
