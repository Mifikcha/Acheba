## Сортировка и фильтр в Excel

**Сортировка** **диапазона данных**

|   |   |
|---|---|
|**Простая сортировка**|**Расширенная сортировка**|
|- Открыть вкладку “**данные**”<br>- Чтобы программа правильно выполнила задачу, выделяем нужный столбец в диапазоне данных.<br><br>![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image2.png)<br><br>- Выбираем каким способом сортировать по возрастанию/убыванию, нажимаем на соответствующую кнопку. ![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image3.png) <br>- Когда диапазон содержит более одного столбца, то Excel открывает диалоговое окно вида:<br><br>![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image4.png)<br><br>Чтобы сохранилось соответствие значений в строках, выбираем действие **«****автоматически расширить выделенный диапазон****».** В противном случае отсортируется только выделенный столбец – структура таблицы нарушится.|Необходима, чтобы при сортировке столбца сохранить соответствующие строки, а также при сортировке нескольких столбцов, расставить приоритет сортировки.<br><br>- Открыть вкладку **“****данные****”.**<br>- Нажать на **“****сортировка****”**<br><br>![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image5.png)<br><br>- В диалоговом окне выберите по какому критерию хотите сортировать в первую очередь и каким образом, после чего можно добавить сколько угодно уровней и выбрать еще критерии, по которым будете сортировать во вторую, третью … очередь.<br>- Нажать на кнопку **“****ОК****”**<br><br>![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image6.png)|

**Фильтрация диапазона данных** ![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image7.png)

- Открыть вкладку “данные”.
- Нажать на “фильтр”. После этого в колонках вашей таблице появятся «стрелочки»
- Нажимаем на «стрелочку» того столбца, фильтр по которому хотим выставить.
- Выбрать вид требуемого фильтра:

|                  |                                                                                   |                                                                                                                                               |
| ---------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| По поиску        | выбрать определенные подходящие элементы                                          | **![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image8.png)**  |
| Текстовый фильтр | выбрать элементы, которые начинаются/заканчиваются на определенный набор символов | **![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image9.png)**  |
| Числовой фильтр  | выбрать элементы, удовлетворяющие условиям                                        | **![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image10.png)** |

- Выбрать текстовые или числовые фильтры, а затем выбрать сравнение.
- Ввести условия фильтрации и нажать кнопку “ОК”.

**Пример задания:**

Найдите средний балл по математике у учеников Майского района. Ответ округлите до сотых

![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_231124_092714/image11.png)

**Решение:**

1. Для начала откроем вкладку «Данные» и откроем

панель «Фильтр»

2. Нажмем стрелочку возле «Район»

3. В открывшемся списке выберем только «Майский»

4. Нажимаем «ОК»

Получили список, который состоит только из учеников

Майского района.

5. Выделяем столбец «Математика»

6. В правом нижнем углу таблицы видим **«****Среднее: 57,63****»**
