## Модели и моделирование

**Модель** — упрощенное представление реального объекта. Это может быть небольшая машинка, корабль и многое другое.

**Моделирование** — деятельность человека по созданию модели.

Модели бывают информационные и натурные. Натурная модель объекта — это его физическое подобие, а информационная — его описание. В информатике в основном пользуются информационными моделями.

**Информационная** **модель** — описание объекта-оригинала на одном из языков представления информации.

Информационные модели можно поделить на три вида:

1) **_Знаковые_** **_модели_** — это модели, которые представлены в виде текста, формул или программ на специальном языке программирования.

_Примеры:_ теорема Пифагора; код, написанный на языке программирования Python.

2) **_Табличные_** **_модели_** — это представление свойств объектов и процессов в виде таблиц.

_Примеры:_ база данных сотрудников какой-либо фирмы; периодическая система химических элементов.

3) **_Графические_** **_модели_** — это представление объектов и процессов в виде их изображений.

_Примеры:_ карта какой-либо местности; диаграмма, которая отображает статистику.

**_Этапы_** **_построения_** **_информационной_** **_модели:_**

1.Определение цели и объекта моделирования;

2.Выявление ключевых характеристик объекта моделирования;

3.Формализация.

Также есть понятие **взвешенный** **граф** — это граф, каждому ребру которого поставлено в соответствие некое значение (вес ребра).

С помощью графов решаются многие алгоритмические задачи, поэтому это очень важная информационная модель. В ОГЭ, как и в ЕГЭ, в основном графы нужны для подсчета оптимального пути передвижений между населенными пунктами.

**Дерево** — это граф, между любыми двумя вершинами которого существует ровно один путь.

_Пример_: родословное дерево.

![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_230225_095240/image3.png)

**Пример** **задания** **с** **использованием** **графа** **№1:**

Через населенные пункты A, B, C и D проходит гравийная дорога. Дорога между пунктами B и D — новая трасса. Протяженность каждой дороги и трассы указана в км на графе. Какое минимальное время движения в ч может затратить автомобиль из пункта A в пункт C? Известно, что скорость движения автомобиля на гравийной дороге 80 км/ч, а по трассе 200 км/ч.

![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_230225_095240/image4.png)

**_Решение:_**

Перед нами граф, наша задача его проанализировать. Рассмотрим все возможные пути из пункта А в пункт С.

1) A — B — C = 80 + 480 = 560. Так как весь путь проходит через гравийную дорогу, автомобиль движется со скоростью 80 км/час. 560/80 = 7 часов.

2) A — B — D — C. Из А в B добираться по гравийной дороге 80 / 80 = 1 час. Из B в D по трассе 600 / 200 = 3 часа. Из D в C снова по гравийной дороге 160 / 80 = 2 часа. Итого: 1 + 3 + 2 = 6 часов.

3) A — D — B — C. Из А в D добираться по гравийной дороге 400 / 80 = 5 часов. Из D в B по трассе 600 / 200 = 3 часа. Из B в C снова по гравийной дороге 480 / 80 = 6 часов. Итого: 5 + 3 + 6 = 14 часов.

4) A — D — C. Из А в D добираться по гравийной дороге 400 / 80 = 5 часов. Из D в C снова по гравийной дороге 160 / 80 = 2 часа. Итого: 5 + 2 = 7 часов.

Очевидно, что минимальное время — 6 часов.

**_Ответ:_** **_6_**

**Пример** **задания** **с** **использованием** **таблицы:**

Два игрока играют в следующую игру. Перед ними лежит куча, в которой 15 каменей. Для того чтобы делать ходы, у каждого игрока есть неограниченное количество камней. Игроки ходят по очереди. За один ход игрок может добавить в кучу один камень или увеличить количество камней в куче в два раза. Выигрывает игрок, после хода которого общее число камней в куче становится не менее 31. Кто выигрывает при безошибочной игре обоих игроков — игрок, делающий первый ход, или игрок, делающий второй ход? В ответе напишите цифру 1 — если выигрывает первый игрок, цифру 2 — если выигрывает второй игрок.

**_Решение_**

Для решения задачи построим таблицу:

|   |   |   |
|---|---|---|
|Начальная позиция|Первый ход 1 игрока|Первый ход 2 игрока|
|15|16|32 — победа!|
||
|30|60 — победа!|
||

  

Из таблицы очевидно, что при безошибочной игре побеждает второй игрок, так как куда бы не пошел первый игрок, второй игрок одерживает победу, умножив количество камней на 2.

**_Ответ:_** **2**

**Базы** **данных**

**База** **данных** — организованная в соответствии с определёнными правилами и поддерживаемая в памяти компьютера совокупность данных.

Мы будем говорить о табличной базе данных. Есть 2 основных пункта, связанных с табличной базой данных:

1) В табличных базах данных вся информация хранится в таблице.

2) Каждая таблица содержит перечень объектов одного типа, т. е. объектов, имеющих одинаковый набор свойств. Каждый столбик отражает одно свойство объектов.
