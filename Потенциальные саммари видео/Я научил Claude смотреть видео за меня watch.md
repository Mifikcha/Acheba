## Краткое резюме

Видео — это русскоязычный разбор того, как настроить в Claude команду /watch для анализа видео не только по транскрипту, но и по кадрам. Визуальный ряд основан на говорящей голове, вставках с документацией, интерфейсах Claude Code и YouTube, а также на нескольких титульных/инструктивных слайдах. ## Главные выводы

- Главная идея: научить Claude разбирать видео по кадрам и тайм-кодам, а не только по субтитрам.
- Заявлены 3 бесплатных пакета: Whisper, yt-dlp и FFmpeg.
- yt-dlp используется для скачивания видео, метаданных и публичных субтитров; Whisper — как запасной вариант для транскрибации; FFmpeg — для извлечения кадров.
