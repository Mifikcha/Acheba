Я бы оценивал не “8 задач = 8 баллов”, а по **двум слоям**:

1. **Предметный результат** — что умеет.
2. **Поведенческий результат** — как решает.

Потому что ученик, который решил 5 задач сам, может быть лучше ученика, который решил 7 задач с постоянным “а что дальше?”.

# Как оценивать “как решил”

Вот прям жестко:

## Сам решил

Полный балл.

Даже если долго.

## Решил с маленькой подсказкой

Минус 20–30%.

Например задача на 5 баллов → ставишь 3–4.

## Решил только после существенного наведения

Половина или меньше.

## Решал вместе с тобой

Это почти не его баллы.

Ставишь 0–1, даже если в конце ответ правильный.

---

# Red flags прямо во время теста

Плохо, если:

* сидит молча и ждет;
* на каждую задачу говорит “я не знаю”;
* не пишет черновик;
* не читает условие;
* не может пересказать задачу 5 или 7;
* не проверяет корень в задаче 2;
* в задаче 4 пытается решать кубическое через “дискриминант”;
* в задаче 8 не понимает разницу между точкой минимума и минимумом функции.

---

# Green flags

Хорошо, если:

* делает попытку даже без знания метода;
* в задаче 4 пробует группировку или подбор корня;
* в задаче 5 рисует цепочку изменения цены;
* в задаче 7 сам вводит переменную;
* в задаче 8 читает график, а не паникует;
* после ошибки может объяснить, где сломался ход.

---

# Самая важная трактовка

Если ученик набрал мало по математике, но хорошо по поведению — **можно брать**.

Если ученик набрал нормально по математике, но плохо по поведению — **опасный клиент**.

То есть для тебя формула такая:

> Берем не того, кто всё уже знает, а того, кто способен работать в твоей системе.

# Поведенческий чек-лист диагностического урока

## Самостоятельность

### Начало решения

* [ ] Начинает решать сразу после получения задачи
* [ ] Не просит подсказку в первые минуты
* [ ] Сам выбирает направление решения
* [ ] Не зависает после первой неудачной попытки

### Работа с задачей

* [ ] Делает черновик
* [ ] Записывает промежуточные шаги
* [ ] Пробует несколько подходов
* [ ] Возвращается к условию при затруднении
* [ ] Самостоятельно проверяет вычисления

### Работа при сложности

* [ ] Продолжает работу, если решение не очевидно
* [ ] Не говорит сразу "я не знаю"
* [ ] Не требует немедленного объяснения
* [ ] Может работать без помощи 5+ минут
* [ ] Может работать без помощи 10+ минут

### Вопросы

* [ ] Задает конкретные вопросы
* [ ] Может объяснить, где именно возникла проблема
* [ ] Формулирует свои гипотезы
* [ ] Может объяснить собственный ход мысли

---

## Обучаемость

### После объяснения нового приема

* [ ] Понял идею после одного объяснения
* [ ] Может повторить прием на похожей задаче
* [ ] Может применить прием на немного измененной задаче
* [ ] Не требует повторного полного объяснения

### Работа с ошибками

* [ ] Сам замечает ошибку
* [ ] Может найти ошибку после намека
* [ ] Исправляет ошибку самостоятельно
* [ ] Не повторяет ту же ошибку через 5 минут

### Перенос знаний

* [ ] Узнает похожие задачи
* [ ] Видит связь между задачами
* [ ] Использует ранее изученный прием без подсказки

---

## Работа с текстом

* [ ] Может пересказать условие своими словами
* [ ] Выделяет, что дано
* [ ] Выделяет, что требуется найти
* [ ] Не теряется в длинном условии
* [ ] Может составить план решения до вычислений

---

## Дисциплина и взаимодействие

* [ ] Записывает важные замечания
* [ ] Использует записанные замечания позже
* [ ] Следует предложенному способу решения
* [ ] Готов сначала попробовать, а потом спорить
* [ ] Спокойно относится к замечаниям

---

## Эмоциональная устойчивость

* [ ] Не паникует при сложной задаче
* [ ] Не бросает задачу после первой ошибки
* [ ] Не обесценивает себя ("я тупой", "я ничего не умею")
* [ ] Не уходит в угадывание ответа
* [ ] Сохраняет концентрацию большую часть занятия
