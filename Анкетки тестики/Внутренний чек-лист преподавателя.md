## Назначение

Этот чек-лист нужен для внутренней оценки ученика после анкеты, разговора с родителем и диагностического урока.

Он не показывается ученику и родителям в полном виде.

Задача чек-листа — понять:

1. Подходит ли ученик под мой формат.
2. Сколько энергии он будет требовать.
3. Насколько вероятен результат.
4. Какие условия нужно поставить до начала работы.
5. Брать ученика, брать с ограничениями или не брать.

# Автоматические red flags

Поставить галочку, если пункт проявился.

| Red flag                                                                  | Да / нет |
| ------------------------------------------------------------------------- | -------- |
| Ученик прямо говорит, что ему это не нужно                                |          |
| Ученик пришел только потому, что заставили родители                       |          |
| Ученик не делает ни одной самостоятельной попытки без подсказки           |          |
| Ученик не может работать один даже 5–10 минут                             |          |
| Ученик не фиксирует рекомендации после прямой просьбы                     |          |
| Ученик спорит с базовыми правилами работы, но не предлагает аргументов    |          |
| Ученик не выполняет домашку и заранее говорит, что делать не будет        |          |
| Родители хотят высокий результат без самостоятельной работы дома          |          |
| Родители требуют нереалистичный результат за короткий срок                |          |
| Родители спорят с правилами оплаты / отмены до начала работы              |          |
| Родители пытаются начать без оплаты / “потом оплатим”                     |          |
| Родители просрочили оплату на старте                                      |          |
| Есть ощущение, что преподавателя хотят использовать как “няню для уроков” |          |

## Правило

Если есть 2+ автоматических red flags — ученика не брать, даже если общий балл выглядит приемлемо.

Если есть 1 red flag — брать только с явными условиями и пробным периодом.
