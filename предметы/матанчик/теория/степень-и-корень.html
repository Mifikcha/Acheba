Степень и корень

1. Понятие степени

1.1. Степень с натуральным показателем

Для любого числа (a) и натурального (n):

an=n разa⋅a⋅⋯⋅a​​.

1.2. Основные свойства степеней

Для всех действительных (a, b) и натуральных (m, n), если выражения имеют смысл:

  1. При умножении — складываем показатели
am⋅an=am+n.
  1. При делении — вычитаем показатели
anam​=am−n,a=0.
  1. Степень степени — умножаем показатели
(am)n=amn.
  1. Степень произведения
(ab)n=anbn.
  1. Степень дроби
(ba​)n=bnan​.

2. Степени с целыми показателями

2.1. Нулевая степень

a0=1,a=0.

2.2. Отрицательная степень

a−n=an1​,a=0.

3. Показатели вида (n1​) и связь со степенью

Тут начинается теория корней.

3.1. Определение

Для натурального, корень (n)-й степени из числа (a) — это число, которое в степени (n) даёт (a):

na​=b⟺bn=a.

Это связывает степень и корень так:

a1/n=na​.

3.2. ОГРАНИЧЕНИЯ на область определения

  • Если (n) чётное, то
na​ определён только при a≥0.

Нельзя извлекать чётный корень из отрицательного числа в действительных числах.

  • Если (n) нечётное, то
na​ определён при любых a.

4. Общая степень с рациональным показателем

4.1. Определение

Для рационального числа (nm​):

am/n=nam​,

если правая часть имеет смысл.

4.2. Пример

82/3=382​=364​=4.

5. Свойства корней (любого порядка)

Пусть при чётном (n), и любое (a) при нечётном.

5.1. Корень из степени

nan​=∣a∣,если n — чётное. nan​=a,если n — нечётное.

Почему появляется модуль?

Потому что, например:

(−5)2​=25​=5=∣−5∣.

5.2. Степень корня

(na​)n=a.

5.3. Корень из произведения

nab​=na​,nb​.

❗Это справедливо только при неотрицательности чисел для чётного (n).

5.4. Корень из дроби

nba​​=nb​na​​,b=0.

5.5. Корень корня

mna​​=mna​.

5.6. Свойства, аналогичные свойствам степеней

  1. Умножение корней:
na​⋅nb​=nab​.
  1. Деление корней:
nb​na​​=nba​​.
  1. Корень степени:
(na​)m=nam​.

6. Частые ошибки и их пояснения

❌ Ошибка 1: считать, что (nan​=a) всегда

Правильно:

  • при чётном (n): (nan​=∣a∣);
  • при нечётном (n): (nan​=a).

❌ Ошибка 2: извлекать чётный корень из отрицательного числа

−4​∈/R.

Корни чётной степени определены только для неотрицательных чисел.

❌ Ошибка 3: переносить степень внутрь корня без проверки условий

4a2​=a1/2всегда.

Правильно:

4a2​=∣a∣1/2.

❌ Ошибка 4: путать (a2+b2​) и (a+b)

Корни не линейны:

a+b​=a​+b​.

8. Мини-конспект (самое важное)

  • Корень и степень связаны формулой:
a1/n=na​.
  • Для рациональных степеней:
am/n=nam​=(na​)m.
  • Если (n) чётное, то:
na​ существует только для a≥0. nan​=∣a∣.
  • Если (n) нечётное, то корень существует для всех (a), и:
nan​=a.
