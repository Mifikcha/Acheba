## Типы данных в программировании

**Одно из основополагающих понятий программирования** **—** **это типы данных. Классификаци****я** **помогает определить, где они хранятся, что собой представляют и для каких операций применяются.**

**1.** **Целочисленный тип данных**

Целочисленный (int) — тип данных, который состоит только из целых чисел (без дробных частей).

Примеры: x = 500; a = 1000000000000; b = 2134354; l = -1000; z = 0

**Ввод типа данных пользователем**: x = int(input())

**2. Вещественный тип данных**

Вещественный (float) — тип данных, который состоит только из вещественных чисел (чисел с дробной частью).

Вещественные числа в python пишутся строго через точку!

Примеры: a = 13.234; b = 245.23445; c = 13.0; -3.13

**Ввод типа данных пользователем**: x = float(input())

**_Задание 1_**

На вход подается два вещественных числа — стороны прямоугольника. Напишите программу для нахождения периметра прямоугольника. Выведите получившиеся значение.

**_Решение:_**

a = float(input()) #ввод первой стороны

b = float(input()) #ввод второй стороны

print(2 * a + 2 * b) #Вывод периметра

**3. Строковый тип данных**

Строковый (str) — тип данных, хранящий в себе набор символов произвольной длины. Строки пишутся в одинарных или двойных кавычках.

_Примеры:_ x = “YES”; a = ‘beautiful cat’; c = ‘0000000000’

_Ввод типа данных пользователем:_ x = input()

**_Простые операции_****_:_**

- Конкатенация **—** это объединение двух или более строк в одну.
- Умножение строки на число **—** оператор, позволяющий повторить строку указанное количество раз.

_Примеры:_ x = ‘avd’, y = ‘456’; тогда x + y = ‘avd456’

⠀⠀⠀⠀⠀⠀⠀⠀x = ‘Delivery’; тогда x * 3 = ‘DeliveryDeliveryDelivery’

**len****(****)** **—** встроенный метод Python для нахождения длины строки (количество символов в строке). Пробелы и знаки в том числе считаются символами.

_Пример:_ a = “London is the capital of Great Britain!”; тогда len(a) = 39.

**4. Логический тип данных****, операции сравнения и логические операции.**

Логический (bool) **—** тип данных, который представляет одно из двух значений (True/False).

_Примеры__:_ a = True; b = False.

**Операции сравнения:**

1) == — возвращает True, если оба операнда равны. Иначе возвращает False;

Например, 5 == 5 True; 5 == 7 False.

2) != — возвращает True, если оба операнда НЕ равны. Иначе возвращает False;

Например, 5 != 5 False; 5 != 7 True.

3) > (больше чем) — возвращает True, если первый операнд больше второго;

Например, 5 > 5 False; 7 > 5 True.

4) < (меньше чем) — возвращает True, если первый операнд меньше второго;

Например, 5 < 5 False; 5 < 7 True.

5) >= (больше или равно) — возвращает True, если первый операнд больше или равен второму;

Например, 5 >= 5 True; 5 >= 7 False.

6) <= (меньше или равно) — возвращает True, если первый операнд меньше или равен второму.

Например, 5 <= 5 True; 7 <= 5 False.

**Логические операции**

1) and (логическое умножение) — возвращает True, если оба выражения равны True;

**Примеры****:**

8 > 5 and 5 <= 5 — True.

8 < 5 and 6 > 5 — False.

2) or (логическое сложение) — возвращает True, если хотя бы одно из выражений равно True;

**Примеры****:**

8 < 5 or 5 == 6 — False.

8 < 5 or 6 > 5 — True.

3) not (логическое отрицание) — возвращает True, если выражение равно False.

**Примеры****:**

not(8 < 5 or 5 == 6) — True.

not(8 < 5 or 6 > 5) — False.

**5. Встроенная функция** **type****(****)**

Встроенная функция type() — возвращает тип данных переданного значения.

Примеры: type(1.45) -> <class ‘float’>; x = 7, type(x) -> <class ‘int’>; s = ‘a345’, type(s) -> <class ‘str’>.
