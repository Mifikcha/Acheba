# Проверка Python

Обычный код в заметке:

```python
def solve(x):
    return x * x

print(solve(5))
```

Тот же кусок можно редактировать и запускать прямо здесь:

<div class="python-checker" data-title="Квадрат числа" data-tests="assert solve(5) == 25&#10;assert solve(-2) == 4&#10;assert solve(0) == 0">
<textarea>
def solve(x):
    return x

print(solve(5))
</textarea>
</div>
