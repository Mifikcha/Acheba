## Блок 5 (41–50, сложнее уровня ЕГЭ)

41. Найдите область определения функции $y=\sqrt{4-\sqrt{x}}$.

> [!tip]- Подсказка
> Во вложенных корнях условие неотрицательности нужно выписать для каждого уровня отдельно: сначала для самого внутреннего подкоренного выражения, а затем — для выражения под внешним корнем целиком (в которое уже входит внутренний корень).
>
> **Пример попроще.** Для $y=\sqrt{9-\sqrt{x}}$: внутреннее условие $x\ge0$, внешнее $9-\sqrt x\ge0 \Rightarrow \sqrt x\le9 \Rightarrow x\le81$. Пересекая оба условия, получаем $x\in[0;81]$.

45. Найдите область определения функции $y=\dfrac{1}{\sqrt{x-1}}+\sqrt{5-x}$.

46. Тело падает с высоты $h$ по закону $t=\sqrt{\dfrac{2h}{g}}$. При $g=10$ найдите, с какой высоты падение длится ровно $3$ секунды.
