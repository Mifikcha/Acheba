# Hopes and Dreams

Это стартовая публичная страница Quartz.

Сюда лучше класть только те заметки, которые можно показывать наружу: материалы, статьи, объяснения, программу обучения, ответы на частые вопросы и демо-конспекты.

## Для начала

- Создай рядом новые `.md`-заметки.
- Связывай их через `[[вики-ссылки]]`.
- Проверяй сайт локально из папки `_quartz` командой `npx quartz build --serve`.
