# Пример 1)

![[_Resours/Pasted image 20250204160802.png]]

Собсна открываем эксель вместе с этим заданием и видим вот такую шнягу:

![[_Resours/Pasted image 20240928092720.png]]

Это таблица чисел с которой предстоит работать. Заметим, что в некоторых строках числа действительно повторяются. Для решения этого задания полезно знать следующие команды:

`СЧЁТЕСЛИ` - считает кол-во непустых ячеек, соответствующие определенному условию.
`ЕСЛИ` - условие.
`И / ИЛИ` - операторы конъюнкции и дизъюнкции соответственно.
`СРЗНАЧЕСЛИ` - среднее значение определенного диапазона при заданных условиях.
`СУММЕСЛИ` - сумма определенного диапазона при заданных условиях.
`СУММ` - обычная сумма определенного диапазона
`ЕСЛИОШИБКА` - условие при котором ошибка меняется на иной символ.

Здесь будем разбираться максимально подробно, потом можно объединять некоторые команды или использовать иные методы решения.

Для начала вопрос - как узнать какие числа повторяются, а какие нет?

Самый простой способ - с помощью команды `СЧЁТЕСЛИ`. Работает она так: первым аргументом указывается диапазон, который будет считаться, а вторым - критерий, согласно которому этот диапазон считается. Т.е., условно, есть у нас строка из 6 значений А1:G1 и мы указываем критерий 1. Тогда команда `СЧЁТЕСЛИ` буквально ищет в строке единицы. Если указываем в критерии, например, А1, то будет искать А1. Как только найдет - увеличится на единичку. Вот и все!

Таким образом, напишем в ячейку H1 следующее:

```
=СЧЁТЕСЛИ(A1:G1;A1)
```

И скопируем это до N1 (и все что есть в ячейках с H1 по N1 тоже скопируем, но уже вниз; Делается это двойным нажатием ЛКМ по зеленому квадратику внизу выделенных ячеек, при условии, что соседние ячейки выделенного диапазона не пустые). Не забывайте писать знаки доллара для фиксации определенных параметров функции. Получится что-то такое:

![[_Resours/Pasted image 20241007203106.png]]

Как видим, иногда `СЧЁТЕСЛИ` выдает не единицу, а тройку, двойку или что-то еще отличное от единицы. Это нормально, так и должно быть. Это всего лишь значит, что команда нашла число, которое мы написали как критерий (т.е. одно из чисел с A по G) несколько раз.

Прекрасно, теперь мы знаем какое число встречается сколько раз. Но это знаем мы, а не комп. Как сообщить об этом компу? Все с помощью той же команды `СЧЁТЕСЛИ`. Пишем в O1 следующее:

```
=СЧЁТЕСЛИ(H1:N1;3)
```

Теперь наш `СЧЁТЕСЛИ` смотрит на диапазон других `СЧЁТЕСЛИ` и ищет там тройку. Если найдет - выдаст 3 (потому, что 3 встречается 3 раза буквально всегда). Если не найдет - выдаст 0.

Тоже самое надо сделать с единицей ибо нельзя исключать, что в какой-то строке одно число повторяется трижды, другое дважды и еще 2 не повторяются, а нам надо, чтобы именно одно повторялось трижды, а остальные были различны. Пишем в важно:

```
=СЧЁТЕСЛИ(H1:N1;1)
```

и растягиваем вниз

Получилось что-то вот такое:

![[_Resours/Pasted image 20241007203909.png]]

Супер, остались мелочи: проверить встречается ли в столбце О число 3, а в столбце P число 4. Наша завсегдатая команда ЕСЛИ нам поможет:

В ячейку Q1: `=ЕСЛИ(И(O1=3;важно=4);1;0)` и растягиваем вниз таблицы.

Это наш первый критерий, по сути, половина ответа. Давайте выделим его каким-нибудь ярким цветом, чтобы не забыть.

![[_Resours/Pasted image 20241007204158.png]]

Едем дальше. Теперь нам нужен второй критерий: среднее арифметическое неповторяющихся чисел строки не больше повторяющегося числа. Сначала разберемся с тем как посчитать среднее арифметическое неповторяющихся.

У нас уже есть информация какие числа повторяются, а какие - нет. Она содержится в диапазоне H1:N16000 т.е. там, где была написана первая команда `СЧЁТЕСЛИ`. Давайте воспользуемся этой информацией с помощью команды `СРЗНАЧЕСЛИ`. Работает она приблизительно также, как и `СУММЕСЛИ`, только с средним арифметическим. Первый аргумент - диапазон критериев, второй - сам критерий, третий - диапазон взятия среднего. В данном случае мы должны вбить в ячейку R1 следующее:

`=СРЗНАЧЕСЛИ(H1:N1;1;A1:G1)` и скопировать до конца таблицы.

Команда ищет в строке H1:N1 единицы (т.е. неповторяющиеся числа) и когда находит - фиксирует эти числа из строки A1:G1 в среднее значение, буквально сопоставляя позиции этих чисел (имеется ввиду, что если единица на второй позиции из диапазона H1:N1, то она возьмет число на второй позиции из диапазона A1:G1). В результате мы получаем столбец средних значений неповторяющихся чисел.

Теперь выполним то же самое с повторяющимися. Т.е. команда та же, но критерий будет не 1, а 3:

`=СРЗНАЧЕСЛИ(H1:N1;3;A1:G1)` - вбиваем в S1 и копируем вниз.

Тут мы получаем интересный результат:

![[_Resours/Pasted image 20241007205322.png]]

Неужели мы сделали что-то не так? Спокуха, все окей. Просто таким образом ексель пытается нам сообщить, что не видит в указанной строке критериев нужный т.е. в некоторых строках нет тройки. Не будем его обвинять, ему и так тяжело живется. Давайте лучше придумаем как избежать ошибки (если мы оставим дело как есть - любые дальнейшие действия над этим столбцом также будут приводить к ошибке). Существует команда ЕСЛИОШИБКА, которая буквально нейтрализует последствия такой поебистики. Ее можно вбить прям поверх нашей. Т.е. теперь мы исправляем в S1:

`=ЕСЛИОШИБКА(СРЗНАЧЕСЛИ(H1:N1;3;A1:G1);0)` - вбиваем в S1 и копируем вниз.

Теперь когда ексель будет видеть ошибку он будет выдавать 0.

![[_Resours/Pasted image 20241007205807.png]]

Дело за малым - осталось сравнить то, что просят и проверить, что выполняются оба условия.

`=ЕСЛИ(R1<=S1;1;0)` - в ячейку T1 и копируем вниз.

`=ЕСЛИ(И(Q1=1;T1=1);1;0)` - в ячейку U1 и копируем вниз.

В ячейке V1 пишем `=СУММ(U:U)`

**Ответ: 36.**

Если во втором аргументе указана ячейка, в нашем случае А1, В1 итд, то он будет искать значение этой ячейки в указанном диапазоне и возвращать сколько раз он встретил значение ячейки в указанном диапазоне.

# Пример 5)

Возможно, этот прототип посложнее остальных именно реализацией, но идея тут едва ли отличается.

![[_Resours/Pasted image 20241030154622.png]]

В том или ином виде условие о двух повторяющихся два раза числах может встретиться на реальном экзамене, поэтому такое задание тоже нужно знать как решать. Будем действовать наиболее наглядно, кто +- разобрался с экселькой сам поймет как можно упростить решение этого задания.

Итак, идея такая: мы знаем как находить кол-во чисел которые повторяются - с помощью `СЧЁТЕСЛИ`. Было бы славно, если бы мы имели копию таблицы, которая дана в задании, но только лишь с теми числами, которые повторяются дважды. Тогда в первом критерии мы бы написали: "Братец на екселе, если ты видишь в новой табличке 4 непустых ячейки - это та строка, которая нам нужна".
Более того, для второго критерия, нам потребуется знать какие числа повторяются а какие нет. Т.е. если мы придумаем как реализовать идею, то мы сможем построить еще одну таблицу, но уже только с неповторяющимися числами путем простого отрицания команды командой НЕ.

Давайте попробуем реализовать идею. Нам потребуется `СЧЁТЕСЛИ`, который должен быть равен 2 и если он таки равен 2, то пускай кексельчик пишет нам саму ячейку иначе ниче пусть не пишет. Итого:

`=ЕСЛИ(СЧЁТЕСЛИ(\$A1:\$G1;A1)=2;A1;"")`

Это команда буквально так и работает. Т.е. она смотрит на диапазон с А1 по G1 (фиксированный кстати) и считает там сколько раз встречается число в ячейке А1. Если 2 раза, тогда команда пишет само число А1 иначе ниче не пишет. Растягиваем на 7 вправо и до конца вниз. Имеем:

![[_Resours/Pasted image 20241030155635.png]]

Вуаля, у нас есть фиолетовая таблица, которая отображает только те числа, которые повторяются дважды. Соответственно, если в такой таблице найдется строка, где есть 4 числа - это та строка, где 2 числа повторяются по 2 раза.

Теперь можно делать первый критерий:

```
=ЕСЛИ(СЧЁТЕСЛИ(H1:N1;">0")=4;1;0)
```

Тут есть прикол. Прикол состоит в том, что ексель бездушная машина, также, как и большинство вещей, с которыми работает прогер. Он делает ровно то, что ему сказали, а не то, что вы хотите, чтобы он делал. Он пошлет вас нахуй, если вы будете сравнивать числа со строками. А "" - это пустая СТРОКА. Т.е. если вы в `СЧЁТЕСЛИ` напишите в качестве критерия число, ексель будет выдавать ошибку в данном случае т.к. в таблице у нас есть пустые ячейки (а ноль там писать нельзя, т.к. в дальнейшем мы будем вычислять среднее). Фиксится это просто. Нужно написать во втором аргументе к `СЧЁТЕСЛИ` вот это: `">0"`. Для экселя это значит, что теперь надо искать символы (т.е. теперь он ищет именно строки, ошибки нет), которые по числовому значению больше нуля. Соответственно, если он в фиолетовой табличке видит 4 штуки нечто, что больше нуля, то выдаст 1 иначе 0. Работаем.

# Решение кодом

Ну а теперь все те же самые задания, но кодом. Начнем по порядку с [[#Пример 1]].

Для начала, нам нужно открыть файлик командой `open`

```python
f = open('9.txt')
```

Далее введем счетчик. Этот счетчик будет отвечать за кол-во удовлетворяющих обоим условиям строк.

```python
count = 0
```

А далее сделаем такую классную штуку: разобьем наш файл `f`, в котором сейчас хранится вся таблица на несколько отдельных строк генератором строк:

```python
m = [int(x) for x in s.split()] # s - одна строка из файла f
```

Теперь в `m` хранятся все числа из какой-нибудь отдельной строки. Например, так:

```
[23, 57, 77, 23, 80, 62, 23]
```

Вот теперь мы можем работать со строкой по отдельности. Нам нужно, чтобы повторялось какое-то число `x` три раза, остальные были различны. Сделаем так:

```python
    pov = [x for x in m if m.count(x)==3] # Повторяющиеся
    nepov = [x for x in m if m.count(x)==1] # Неповторяющиеся
```

Это все списки, если что. Т.е. вот так:

```
m = [23, 57, 77, 23, 80, 62, 23]
pov = [23, 23, 23]
nepov = [57, 77, 80, 62]
```

Стало быть, если `len(pov) == 3 and len(nepov) == 4`, то первый критерий условия выполнен. В строке есть 3 числа, которые повторяются и остальные не повторяются.

Теперь второй критерий. Среднее арифметическое неповторяющихся чисел строки не больше повторяющегося числа. Так это же `if (sum(nepov)/4) <= (pov[0]):`. Ну т.е. буквально: сумма всех неповторяющихся поделить на их количество - это среднее арифметическое, вот оно не больше, чем повторяющееся (т.е. любой элемент из `pov`)

Если оба критерия (условия) выполняются, тогда к `count` прибавляем единицу.

По итогу:

```python
f = open('9.txt')
count = 0
for s in f:
    m = [int(x) for x in s.split()]
    pov = [x for x in m if m.count(x) == 3]
    nepov = [x for x in m if m.count(x) == 1]
    if len(pov) == 3 and len(nepov) == 4:
        if (sum(nepov) / 4) <= (pov[0]):
            count += 1
print(count)
```

Вычисляем среднее арифметическое стандартным образом, выебываемся только тогда, когда этот способ станет кристально понятен т.е. `sum(max(m), min(m)) / 2` - это сумма максимального и минимального чисел в строке, делится на 2, получается среднее арифметическое максимального и минимального, а `(sum(m) - sum(max(m), min(m))) / 4` - среднее арифметическое всех оставшихся чисел.

```python
f = open('9.txt')
count = 0
for s in f:
    m = [int(x) for x in s.split()]
    pov = [x for x in m if m.count(x) > 1]
    nepov = [x for x in m if m.count(x) == 1]
    if len(nepov) == 6:
        if sum(max(m), min(m)) / 2 < (sum(m) - sum(max(m), min(m))) / 4:

print(count)
```
