# Пример 1)

![[_Resours/Pasted image 20241005103829.png]]

Согласно условию, в пароле могут быть использовано 26 символов. Известно, что с помощью N бит можно закодировать $2^N$ различных вариантов. Поскольку 24 < 26 < 25, то для записи каждого из 26 символов необходимо 5 бит.

Для хранения всех 10 символов номера нужно 10 · 5  =  50 бит, а так как для записи используется целое число байт, то берём ближайшее не меньшее значение, кратное восьми, это число 56  =  7 · 8 бит (7 байт).

Для хранения всех сведений о 50 пользователях используется 50 · 7  =  350 байт, то есть для хранения данных о 50 пользователях необходимо выделить 350 байт.

**Ответ: 350**

# Пример 2)

![[_Resours/Pasted image 20241005104122.png]]

Всего для кодирования может быть использовано 10 десятичных цифр, 30 строчных и 30 прописных букв, то есть 70 символов. Известно, что с помощью $N$ бит можно закодировать $2^N$ различных символов. Поскольку 26 < 70 < 27 и для каждого пароля число бит одинаково, то для записи каждого из 8 символов необходимо 7 бит памяти. Для хранения всех 8 символов номера нужно 56 бит, или 7 байт. Поэтому для хранения 110 паролей понадобится 110 · 7  =  770 байт.

# Пример 3)

![[_Resours/Pasted image 20241005104239.png]]

Для кодирования одного символа из десятисимвольного алфавита требуется 4 бита ($2^3<10\leq 2^4$)
Тогда для кодирования пароля из 11 символов требуется $4*11=44$ бита. Минимальное количество байт, содержащее в себе 44 бита - 6.
Тогда для кодирования 70 паролей нужно $6*70=420$ байт.

# Пример 4)

![[_Resours/Pasted image 20241005104740.png]]

При кодировании $k$ бит позволяют кодировать $2^k$ символов. Заметим, что $2^4<22<2^5$, поэтому для кодирования 22-символьного алфавита требуется 5 бит. Для хранения 13 символов требуется $13*5=65$ бит.

Минимальное число бит, необходимое для кодирования числа, не превышающего 1000, равно 10 битам. Следовательно, для хранения двух таких чисел потребуется 20 бит. Личный код и код подразделения записываются подряд и вместе занимают минимально возможное целое число байт. Минимальное количество байт, вмещающее в себя 85 бит,  — 11 байт. Всего на пропуске хранится 32 байт данных. Значит, для хранения дополнительных сведений о сотруднике отводится 32 байта − 11 байт  =  21 байт данных.

**Ответ: 21.**

# Пример 5)

![[_Resours/Pasted image 20241005104928.png]]

Согласно условию, в пароле могут быть использовано 26 символов. Известно, что с помощью $N$ бит можно закодировать $2^N$ различных вариантов. Поскольку 24 < 26 < 25, то для записи каждого из 26 символов необходимо 5 битов.

Для хранения всех 10 символов номера нужно 10 · 5  =  50 битов, а так как для записи используется целое число байтов, берём ближайшее не меньшее значение, кратное восьми. Это число 56  =  7 · 8 битов (7 байтов).

Итак, на одного пользователя 7 + 14  =  21 байт. Для хранения всех сведений о 5 пользователях используется 21 · 5  =  105 байтов.

**Ответ: 105.**
