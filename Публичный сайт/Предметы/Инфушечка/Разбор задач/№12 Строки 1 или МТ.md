> Исполнитель МТ представляет собой читающую и записывающую головку, которая может передвигаться вдоль бесконечной горизонтальной ленты, разделённой на равные ячейки. В каждой ячейке находится ровно один символ из алфавита исполнителя (множество символов A  =  {a0, a1, ..., an − 1}), включая специальный пустой символ a0.
> Время работы исполнителя делится на дискретные такты (шаги). На каждом такте головка МТ находится в одном из множества допустимых состояний Q  =  {q0, q1, ..., qn − 1}. В начальный момент времени головка находится в начальном состоянии q0.
> На каждом такте головка обозревает одну ячейку ленты, называемую текущей ячейкой. За один такт головка исполнителя может переместиться в ячейку справа или слева от текущей, не меняя находящийся в ней символ, или заменить символ в текущей ячейке без сдвига в соседнюю ячейку. После каждого такта головка переходит в новое состояние или остаётся в прежнем состоянии.

> Программа работы исполнителя МТ задаётся в табличном виде.


| Абоба     | $a_{0}$ | $a_{1}$ | ... | $a_{n-1}$ |
| :-------- | :------ | :------ | :-- | :-------- |
| $q_{0}$   | команда | команда | ... | команда   |
| $q_{1}$   | команда | команда | ... | команда   |
| ...       | ...     | ...     | ... | ...       |
| $q_{n-1}$ | команда | команда | ... | команда   |

> В первой строке перечислены все возможные символы в текущей ячейке ленты, в первом столбце  — возможные состояния головки. На пересечении i⁠-й строки и j⁠-го столбца находится команда, которую выполняет МТ, когда головка обозревает j⁠-й символ, находясь в i⁠-м состоянии. Если пара «символ  — состояние» невозможна, то клетка для команды остаётся пустой.
> 
Каждая команда состоит из трёх элементов, разделённых запятыми: первый элемент  — записываемый в текущую ячейку символ алфавита (может совпадать с тем, который там уже записан). Второй элемент  — один из четырёх символов «L», «R», «N», «S». Символы «L» и «R» означают сдвиг в левую или правую ячейки соответственно, «N»  — отсутствие сдвига, «S»  — завершение работы исполнителя МТ после выполнения текущей команды.

> Сдвиг происходит после записи символа в текущую ячейку. Третий элемент  — новое состояние головки после выполнения команды.
Например, команда 0, L, q3 выполняется следующим образом: в текущую ячейку записывается символ «0», затем головка сдвигается в соседнюю слева ячейку и переходит в состояние q3.

## Переформулирую,,,

![[_Resours/Pasted image 20260129131349.png]]

А еще у нас есть некая "головка исполнителя МТ". Я предлагаю не принимать мысль о том, что мы работаем с головкой некоего МТ, поэтому назовем его Борисом, исполнительным нашим дройдекой. Так вот, Боря стоит изначально справа от всей ленты, над правой буквой `λ`.

Боря умеет:

1) Читать символы в клетке
2) Записывать символ в клетку
3) Двигаться влево и вправо
4) Менять режимы работы `q0, q1, ...`

Боря - это робот с памятью в 1 клетку.
## Ну а теперь к тому как работает программа из условия

Программа - это таблица. Например такая:

| Абоба   | λ               | 1           | 0           |
| :------ | :-------------- | :---------- | :---------- |
| $q_{0}$ | $\lambda,\ L,\ q_{1}$ |             |             |
| $q_{1}$ | $\lambda,\ S,\ q_{0}$ | $0,S,q_{1}$ | $1,L,q_{1}$ |

* Строки - это текущее состояние Бори `q0, q1, ...`
* Столбцы - это символы, которые Боря сейчас зрит `λ, 0, 1`

В клетке таблицы:

```
Что записать, куда двинуться, в какое состояние перейти
```

Например:

```
1, L, q1
```

Означает:

1) Записать 1 в текущую клетку
2) Сдвинуться влево
3) Перейти в состояние `q1`

***Когда программа заканчивается?***

Если во второй части стоит `S`:

```
Что-то, S, что-то
```

Это значит СТОП. Программа завершает работу.

## Что делает программа (по факту)

**Она идёт справа налево:**

1) пока видит 0 — заменяет 0→1 и идёт влево;

2) как только впервые видит 1 — заменяет 1→0 и останавливается;

3) если 1 так и не встретилась (строка вся из нулей) — дойдёт до λ и остановится (при этом все нули уже станут единицами).

То есть это вычитание 1 из двоичного числа (с правого конца).

Решаем.
### Обозначения

Пусть в исходной строке было ($Z_0$) нулей (длина строки 1000).

Пусть (k) — число **нулей в самом конце** (сколько подряд нулей стоит справа).

### Если в строке есть хотя бы одна `1`

Тогда операция такая:

* эти (k) последних нулей станут единицами ⇒ нулей станет **на (k) меньше**
* первая слева от них единица станет нулём ⇒ нулей станет **на 1 больше**

Значит:
$$
Z_f = Z_0 - k + 1
$$
По условию ($Z_f$=343), значит
$$
343 = Z_0 - k + 1 \Rightarrow Z_0 = 342 + k
$$

Чтобы ($Z_0$) было **максимальным**, надо сделать (k) **максимальным**, но при этом:

1. в строке должна быть хотя бы одна `1` (иначе финальных нулей было бы 0),
2. ($Z_0 \le 1000$),
3. если ($Z_0$=1000) — это “все нули”, а единиц нет, противоречие.

Значит максимум — **($Z_0$=999)** (999 нулей и 1 единица).
### Ответ

**Максимально возможное число нулей в исходной последовательности: 999.**

## Почему словарь нужен в машине Тьюринга

В таблице МТ есть правило:

> **если я в таком состоянии и вижу такой символ — сделай вот это**

Это **идеально ложится на словарь**:

```python
rules = {
    ("q1", "0"): ("1", "L", "q2"),
    ("q1", "1"): ("0", "S", "q1"),
}
```

Читается так:

* ключ: `(состояние, символ)`
* значение: `(что_писать, куда_идти, новое_состояние)`

4) Сама Машина Тьюринга

```python
while True:

        break  # если команды нет — стоп
```

Построчно:

```python

```

Значит повторяй вечно, пока не будет `break`.

```python
symbol = tape[head]
```

Считываем символ под Борей.

```python
if (state, symbol) not in rules:
        break  # если команды нет — стоп
```

Если текущей ситуации т.е. связки "символ + состояние" нет в правилах, то мы ломаем цикл.

```python
write, move, new_state = rules[(state, symbol)]
```

Иначе, если ситуация знакома, то смотрим в правила. Объявляем 3 новые переменные и задаем им соответствующие правила из нашего словаря.

```python
tape[head] = write
```

Записываем символ из наших правил.

```python

        head -= 1
    elif move == "R":
        head += 1
    elif move == "S":
        break  # команда "стоп"
```

Далее, движение Бори. Ну, тут все очевидно - если у нас `move == "L"`, то Боре надо сместится налево т.е. `head -= 1`, аналогично если направо `head += 1`, и если надо встать, то `break`.

Не забываем поменять состояние Бори.

```python
state = new_state
```

Если совсем коротко, то сам алгоритм Машины Тьюринга делится на 5 этапов:

Каждая итерация цикла = один такт машины Тьюринга:

* прочитал символ
* нашёл команду по `(состояние, символ)`
* записал
* сдвинулся или остановился
* поменял состояние

5) Зрим в результат

```python
result = "".join(tape).strip("λ")

print("Результат на ленте (двоичное):", result)
print("Результат в десятичной системе:", int(result, 2))
```

Ну, тут собственно пояснять только первую строчку, остальное должно быть очевидно.

Мы к пустой строке справа прибавляем нашу итоговую ленту из символов и обрезаем `λ`.

```python
# ===============================
# ПРАВИЛА МАШИНЫ (из демоверсии с 343 нулями)
# ===============================
rules = {
    ("q0", "λ"): ("λ", "L", "q1"),

    ("q1", "λ"): ("λ", "S", "q1"),
    ("q1", "1"): ("0", "S", "q1"),
    ("q1", "0"): ("1", "L", "q1"),
}

TARGET_ZEROS = 343
N = 1000

best_initial_zeros = -1
best_string = None

# ===============================
# ПЕРЕБОР k = сколько нулей в конце
# ===============================
for k in range(0, N):  # k=0..999
    # Чтобы машина остановилась на '1', нужна 1 перед хвостовыми нулями
    # Значит структура: [левая часть] + "1" + "0"*k
    # Длина должна быть N, значит левая часть длины: N - k - 1
    left_len = N - k - 1

    # Чтобы нулей было максимально, делаем левую часть из нулей
    s = "0" * left_len + "1" + "0" * k

    # --- симуляция на списке ---
    SIZE = 5000
    tape = ["λ"] * SIZE
    start = 2500

    for i, ch in enumerate(s):
        tape[start + i] = ch

    head = start + N      # головка справа от последовательности
    state = "q0"

    while True:
        symbol = tape[head]
        if (state, symbol) not in rules:
            break

        write, move, new_state = rules[(state, symbol)]
        tape[head] = write

        if move == "L":
            head -= 1
        elif move == "R":
            head += 1
        elif move == "S":
            break

        state = new_state

    final_segment = tape[start : start + N]
    final_zeros = final_segment.count("0")

    # Проверяем условие
    if final_zeros == TARGET_ZEROS:
        initial_zeros = s.count("0")
        if initial_zeros > best_initial_zeros:
            best_initial_zeros = initial_zeros
            best_string = s

print("Максимум нулей в исходной строке:", best_initial_zeros)
print("Пример строки (первые 80 символов):", best_string[:80])
print("... последние 80 символов:", best_string[-80:])
```

## 1) Что делает программа

Старт:

* `q0` на правом `λ`: `(q0,λ)→λ,L,q1` — заходим на последний символ.

Дальше в `q1` она идёт **влево по всей строке**, пока не встретит левый `λ`, где остановится: `(q1,λ)→λ,S,q1`.

При этом замены такие:

* если видит `3` → пишет `0` (то есть `3→0`)
* если видит `1` → пишет `1` (то есть `1→1`)
* если видит `0` → пишет `3` (то есть `0→3`)

Итого это просто отображение:
$$
0\to3,\quad 1\to1,\quad 3\to0
$$
### 2) Переводим условие “сумма цифр после = 100” в уравнение

Пусть в исходной строке было:

* ($n_{0}$) нулей
* ($n_{1}$) единиц
* ($n_{3}$) троек
  и ($n_{0}$+$n_{1}$+$n_{3}$=1000).

После замены:

* троек станет ровно ($n_{0}$) (потому что ($0\to3$))
* единиц станет ($n_{1}$)
* нулей станет ($n_{3}$)

Сумма цифр после:
$$
0\cdot n_3 + 1\cdot n_1 + 3\cdot n_0 = n_1 + 3n_0 = 100
$$

### 3) Максимизируем число единиц в исходной строке

Из уравнения:
$$
n_1 = 100 - 3n_0
$$

Чтобы ($n_{1}$) было **максимальным**, надо ($n_{0}$) сделать **минимальным**.

Минимум ($n_{0}$) — это 0.

Тогда:

* ($n_{0}$=0)
* ($n_{1}$=100)
* ($n_{3}$=1000-0-100=900)

Ответ: 900

# Пример 3)

## 24553

![[_Resours/Pasted image 20260130153931.png]]

## 1) Что делает программа

* `q0`:

  * на `λ` → `λ, L, q1`
  * на `0` → `0, L, q1`
  * на `1` → `0, L, q1`  *(то есть в `q0` единица превращается в ноль)*

* `q1`:

  * на `λ` → `λ, S, q1` (остановка)
  * на `0` → `0, L, q0`
  * на `1` → `1, L, q0`  *(то есть в `q1` символ не меняется)*

Старт: головка справа от последовательности, состояние `q0`.
Первый шаг: увидели `λ` → шагнули влево на последний символ и стали `q1`.

Дальше головка всегда идёт **влево** и состояния **строго чередуются**:
`q1, q0, q1, q0, ...`

## 2) Какие позиции “портятся”, а какие остаются

Нумеруем символы **с правого края**: самый правый имеет номер 0, левее — 1, 2, …

* позиция 0 обрабатывается в `q1` → **не меняется**
* позиция 1 обрабатывается в `q0` → **становится 0 всегда**
* позиция 2 в `q1` → **не меняется**
* позиция 3 в `q0` → **становится 0 всегда**
* и т.д.

👉 Значит:

* **все позиции с нечётным номером (1,3,5,...) гарантированно станут 0**
* **позиции с чётным номером (0,2,4,...) останутся как были**

## 3) Условие: после работы осталось 101 единица

Единицы могут остаться **только** на чётных позициях (считая справа).
Чётных позиций в строке длины 1000 ровно **500**.

Чтобы после работы было **101 единица**, нужно:

* на чётных позициях изначально поставить **ровно 101 единицу**
* остальные чётные позиции сделать нулями

## 4) Максимизируем число единиц в исходной строке

Нечётные позиции (их тоже 500) *всё равно обнулятся*, поэтому туда можно смело поставить **все единицы**, чтобы увеличить исходное количество.

Тогда максимум единиц в исходной:

* 500 (все нечётные позиции)

- 101 (на чётных, чтобы после осталось 101)

Итого: 500 + 101 = 601
