Итак, задание решается перебором (эксплуатируем скорость вычисления машин на полную). Идея такая: мы переберем произвольное кол-во A от 0 до n (где `n` выбирается методом тыка), для каждого значения А мы прогоним n циклов со значениями x и если хоть в одном из них окажется, что функция ложна - это значения А не подходит.

Начнем с написания функции, которая задана в условии. Ее можно написать по-разному, можно перефразировать итд. Я, для наглядности, буду писать ее в первозданном виде, как она описана в условии:

```python
def f(x,A):
    if (x & 85 == 0) <= ((x & 54 != 0) <= (x & A != 0)): #Вот это и есть функция
        return True
    else:
        return False
```

> [!note] Нюанс
> `return True` и `return False` здесь написаны исключительно для вашего лучшего понимания что делает функция. Сама по себе функция - это законченное логическое выражение, оно и так возвращает `True` в случае `1` и `False` в случае `0`.

Обратите внимание:

1) Побитовая конъюнкция уже закреплена в питоне и обозначается как &.
2) Импликация или следование имеет обозначение <= (легко проверить, что это так, их таблицы истинности совпадают).

|  X  |  Y  | F ($\to$) |
| :-: | :-: | :-------: |
|  0  |  0  |     1     |
|  0  |  1  |     1     |
|  1  |  0  |     0     |
|  1  |  1  |     1     |

|  X  |  Y  | F (<=) |
| :-: | :-: | :----: |
|  0  |  0  |   1    |
|  0  |  1  |   1    |
|  1  |  0  |   0    |
|  1  |  1  |   1    |

3) Нам не нужно ставить какое-то итоговое числовое значение функции, мы просто ретерним истину либо ложь в зависимости от того выполняется ли условие.

# Пример 10)

![[_Resours/Pasted image 20241103215115.png]]

Собсна, для того, чтобы решить это задание нам нужно как-то упростить логическую функцию, которую мы видим. Делается это с помощью законов логики. Вот все, которые нужны для решения подобных заданий (чисто для того, чтобы проще было писать - конъюнкция это умножение т.е. $*$, а дизъюнкция - это $+$):

| Название                                        | Для конъюнкции                                                                                                                        | Для дизъюнкции                                                            |
| :---------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------ |
| Закон повторения (идемпотенции)                 | $A*A = A$                                                                                                                             | $A + A = A$                                                               |
| Третьего не дано                                | $A*\bar{A}=0$                                                                                                                         | $A+\bar{A}=1$                                                             |
| Поглощение                                      | $A*(A+B)=A$                                                                                                                           | $A+(A*B)=A$                                                               |
| Коммутативность (переместительный)              | $A*B=B*A$                                                                                                                             | $A+B=B+A$                                                                 |
| Ассоциативность (сочетательный)                 | $A*(B*C)=(A*B)*C=A*B*C$                                                                                                             | $A+(B+C)=(A+B)+C=A+B+C$                                                 |
| Дистрибутивность (распределительный)            | $A*(B+C)=A*B+A*C$                                                                                                                     | $A+(B*C)=(A+B)*(A+C)$                                                     |
| Закон двойного отрицания                        | $\bar{\bar{A}}=A$ (это не значит, что этот закон работает только для конъюнкции, он универсален)                                      | -                                                                         |
| Закон де Моргана                                | $\bar{A*B}=\bar{A}+\bar{B}$ (тут имеется ввиду, что знак отрицания слева стоит над всем выражением, я прост хз эту палочку растянуть) | $\bar{A+B}=\bar{A}*\bar{B}$ (опять же, отрицается полное выражение слева) |
| Импликация                                      | $A\to B=\bar{A}+B$                                                                                                                    | -                                                                         |
| Эквивалентность                                 | $A\leftrightarrow B=A*B+\bar{A}*\bar{B}$ (стрелочка влево и вправо - это эквивалентность, иногда обозначается как тройное равно "≡")  | -                                                                         |
| XOR или исключающее или или антиэквивалентность | $A\oplus B=\bar{A}*B+A*\bar{B}$ (иногда обозначают как перечеркнутая эквивалентность)                                                 |                                                                           |

Итак, перепишем это выражение и будем последовательно его преобразовывать:

$$(x \in P)\to(((x \in Q)*(\bar{x\in A}))\to(\bar{x\in P}))$$

Чтобы было проще работать, давайте введем обозначения: $(x\in P)=P$; $(x \in Q)=Q$; $(x\in A)=A$. Перепишем выражение, используя новые обозначения:

$$P\to((Q*\bar{A})\to \bar{P})$$

Раскроем внешнюю импликацию:

$$\bar{P}+((Q*\bar{A})\to \bar{P})$$

Раскроем внутреннюю импликацию (ту, которая в скобках):

$$\bar{P}+(\bar{(Q*\bar{A})}+\bar{P})$$

Для скобки $(\bar{Q*\bar{A}})$ воспользуемся законом де Моргана:

$$\bar{P}+((\bar{Q}+\bar{\bar{A}})+\bar{P})$$

Двойное отрицание А даст просто А:

$$\bar{P}+((\bar{Q}+A)+\bar{P})$$

Скобки с $(\bar{Q}+A)$ можно опустить:

$$\bar{P}+(\bar{Q}+A+\bar{P})$$

Опускаем скобки и применяем закон повторения для $\bar{P}$:

$$\bar{P}+\bar{Q}+A$$

Вуаля, мы получили адекватное выражение.

Теперь, вспоминаем, что отрезок $P=[15;40]$, а отрезок $Q=[21;63]$. Стоит нарисовать числовую прямую для наглядности:

Идея такая: мы формируем нашу логическую функцию как функцию в python, перебираем значения из наших множеств и если так станется, что `f(x) == 1 for x in d` - это будет истинной всегда, тогда мы нашли наш отрезок А.

Самая мутная строка здесь - это `d = [y for x in (17, 29, 58, 80) for y in (x, x - 0.1, x + 0.1)]`. Из плюсов - она шаблонная. Из минусов: непонятно че она нахуй делает.

Эта строка для каждого граничного значения `x` из кортежа `(17, 29, 58, 80)` формирует по 3 значения `x, x - 0.1, x + 0.1` и записывает всех их в список `d`. Т.е., фактически, в `d` записаны значения `[17, 16.9, 17.1, 29, 28.9, 29.1, 58, 57.9, 58.1, 80, 79.9, 80.1]`. Теперь главный вопрос - зачем, а главное: зачем?

Дело в том, что истинность выражения может меняться только при переходе через границы `P, Q, A`. Мы заранее знаем границы `P`и `Q`: `17, 29, 58, 80`. Поэтому мы тестируем: сами границы и точки чуть левее и чуть правее от границ, чтобы уловить различия между значениями функций.

А потом мы в `a1` и `a2` будущего отрезка `A` тоже перебираем по множеству `d`. Таким образом, узнаем наилучший отрезок `A`, который делает формулу истинной. Как-то так.

В чем проблема? Вот в этом условии: `78125 != y + 4x`. Во-первых, в связи с ним надо перебирать А в диапазоне от 0 до 100_000 хотя бы. Во-вторых - х и у в диапазоне ну хотя бы 80_000. Т.е. это дает нам по итогу вот такой код:

<div class="python-checker" data-title="Пример 13 Большие числа и способ побыстрее" data-code="def f(x,y,A):&#10;	return ((78125 != y + 4*x) or (A &gt; x) and (A &gt; y))&#10;&#10;for A in range (1,100_000):&#10;    flag = True&#10;    for x in range (1,80_000):&#10;        for y in range (1,80_000):&#10;            if not(f(x,y,A)):&#10;                flag = False&#10;    if flag:&#10;        print(A)"></div>

Так вот, проблема в числе перебора: `100_000 * 80_000 * 80_000`. Это бля вот столько: `640 000 000 000 000`. Это типа много окда. Даже на домашних компах будет долго считать, а на школьных и подавно. Поэтому нам надо как-то упростить этот перебор, чтобы компику было полегче. Предлагаю сделать так:

1) Что-то одно т.е. либо x либо y придется изначально (т.е. в первом цикле) перебирать много раз. Много - это столько, сколько говорит само условие `78125 != y + 4x`. Т.е. если речь о `y` - то 80_000 раз, а если `x` - то 20_000 раз, поскольку там у нас `4x` стоит.
2) Исходя из этого, будем перебирать `х` 20_000 раз. Но тогда нужно перебирать конкретные значения `у`. Найти их просто - выразить из нашего условия. Т.е. `y = 78125 - 4*x` Однако в таком случае нам нужно поставить дополнительно условие, что `y > 0`, ведь там у нас вычитание происходит.
3) И вот только тогда писать наши обычные `if not (f (x,y,A)):` и `flag = False`

Т.е., по итогу, все это выглядит так:

<div class="python-checker" data-title="Пример 13 Большие числа и способ побыстрее" data-code="def f(x, y, A):&#10;    return ((78125 != y + 4*x) or (A &gt; x) and (A &gt; y))&#10;&#10;for A in range(0, 100_000):&#10;    flag = True&#10;    for x in range (1, 20_000):&#10;        y = 78125 - 4*x&#10;        if y &gt; 0:&#10;            if not (f (x,y,A)):&#10;                flag = False&#10;                break&#10;    if flag:&#10;        print(A)&#10;        exit()"></div>

**Ответ: 78122**

## Еще быстрее

Итак, давайте подумаем когда у нас выражение выдает `False`. Это происходит при одновременном выполнении трех условий (поскольку там между скобками в функции стоит дизъюнкция т.е. `or`):

**Для референса: оригинал**

* `x * y < A` - оригинальная первая скобка
* `y > 5 * x` - оригинальная вторая скобка
* `x >= 486` - оригинальная третья скобка

**Развернутые условия**

* `x * y >= A` - отрицается первая скобка
* `y <= 5 * x` - отрицается вторая скобка
* `x < 486` - отрицается третья скобка

Причем последние 2 выражения вообще не зависят от `A`. Раз так, то если `x` и `y` такие, что последние 2 условия не выполняются, то чтобы выражение было `True` должно выполняться только первое условие т.е. `A` должно быть таким большим, чтобы превосходить произведение `x * y`.

> [!tip] Переформулирую
> Таким образом, мы можем переформулировать задачу: нужно найти максимальное значение `x * y` при условиях `y <= 5 * x` и `x < 486`

Так как `x` и `y` неотрицательные, максимум будет при максимально возможном `x` и максимально возможном `y`. Максимальное `x = 485`, а максимальное `y = 5 * x = 5 * 485 = 2425`. Т.е. максимальное значение `x * y = 485 * 2425 = 1176125`. Однако, у нас `A > x * y`. Значит надо взять на единицу больше т.е. **ответ здесь `1176126`.**

Соответственно, код:

<div class="python-checker" data-title="Еще быстрее" data-code="mx = 0&#10;for x in range(486):&#10;    y = 5 * x&#10;    mx = max(mx, x * y)&#10;print(mx + 1)"></div>

Аналогичные рассуждения можно привести с примером 13. Там у нас была вот такая задача:

![[_Resours/Pasted image 20260301130902.png]]

Здесь у нас выражение `(78125 != y + 4x) or (A > x) and (A > y)` может стать ложным тогда, когда первая скобка ложна т.е. `78125 == y + 4x`.

> [!note] Кста
> Если что, то в питоне выражение выше читается как `(78125 != y + 4*x) or ((A > x) and (A > y))`, поскольку `and` имеет приоритет выполнения выше чем `or`.

Стало быть, мы должны проверить только значения `y = 78125 - 4x`. Для всех остальных пар первая часть уже истинна, и `A` вообще не важно. Если же пара такая, что `78125 == y + 4x`, то выражение спасается от ложности двумя скобками `A > x` и `A > y`. Значит, `A` должно быть больше и `x`, и `y` для всех таких пар. Поэтому мы ищем максимальное значение среди всех опасных `x` и `y`, а потом прибавляем 1.

<div class="python-checker" data-title="Еще быстрее" data-code="mx = 0&#10;&#10;for x in range(1, 20_000):&#10;    y = 78125 - 4 * x&#10;&#10;    if y &gt; 0:&#10;        mx = max(mx, x, y)&#10;&#10;print(mx + 1)"></div>
