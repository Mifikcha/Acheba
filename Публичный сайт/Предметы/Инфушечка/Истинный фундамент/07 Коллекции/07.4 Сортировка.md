# Сортировка

`sorted()` возвращает новый отсортированный список.

```python
numbers = [5, 1, 3]
print(sorted(numbers))  # [1, 3, 5]
print(numbers)          # [5, 1, 3]
```

`.sort()` меняет исходный список.

```python
numbers = [5, 1, 3]
numbers.sort()
print(numbers)  # [1, 3, 5]
```

Для обратного порядка используют `reverse=True`.

```python
print(sorted([5, 1, 3], reverse=True))  # [5, 3, 1]
```

Для сортировки слов по длине можно дать ключ:

```python
words = ["bb", "a", "ccc"]
print(sorted(words, key=len))  # ['a', 'bb', 'ccc']
```

Если `len` как аргумент выглядит странно, пока просто запомни пример. Подробнее о функциях было в [[04.1 Вызов функции]].

### Задачи

1. Отсортируй числа по возрастанию.
2. Найди второе по величине различное число.
3. Отсортируй слова сначала по длине.

### Предскажи вывод

```python
a = [3, 1, 3, 2]
b = sorted(set(a))
print(b)
```

> [!tip]- Ответ
> Будет `[1, 2, 3]`.
