# Списки

Список хранит несколько значений в одном месте.

```python
numbers = [3, 5, 8, 1]
print(numbers[0])  # 3
print(numbers[-1]) # 1
```

Список сохраняет порядок и повторы.

```python
marks = [5, 4, 5]
marks.append(3)
marks[1] = 2
```

Чаще всего список проходят циклом.

```python
for x in numbers:
    print(x)
```

Если путаешь индексы, вернись к [[03.14 Индексы строк]]. Если сам цикл ещё шатается, смотри [[06.9 Цикл for и range]].

### Полезное для ввода

Так строку чисел превращают в список чисел:

```python
numbers = list(map(int, input().split()))
```

Здесь `input()` читает строку, `.split()` режет её на части, `map(int, ...)` превращает части в числа, `list(...)` собирает результат в список.

### Задачи

1. Выведи максимальное число списка.
2. Посчитай количество положительных чисел.
3. Найди сумму чисел, которые делятся на `7`.

### Предскажи вывод

```python
nums = [4, 1, 4]
nums.append(9)
print(len(nums))
print(nums[0] + nums[-1])
```

> [!tip]- Ответ
> Сначала `4`, потом `13`.
