# Первая программа

Зачем это нужно: любая программа должна уметь показать результат, иначе непонятно, что она вообще сделала.

Самая маленькая полезная команда:

```
print("Hello, World!")
```

`print` выводит значение на экран. Это ваша первая и самая важная программа. В круглых скобках пишем то, что хотим увидеть. Если это текст, берем его в кавычки.

Если не понимаешь, почему текст берется в кавычки, смотри [[03.1 Строка это текст]] и [[03.2 Кавычки]].

Запусти:

```
print("Я запустил программу")
print("Питон работает")
```

На экране должны появиться две строки.

> [!Note]
> Питон выполняет команды сверху вниз: сначала первую, потом вторую.

### Задачи

1. Выведи на экран имя `Anon`.
2. Выведи на экран три строки:

```
ЕГЭ
Информатика
Питон
```

3. Напиши программу, которая выводит:

```
2 + 2
```

Именно текст `2 + 2`, а не результат арифметической операции.

4. Напиши программу, которая выводит:

```
Сначала думаю
Потом пишу
Потом запускаю
```

### Предскажи вывод

Что появится на экране?

```
print("2 + 2")
print(2 + 2)
```

Если можешь объяснить разницу без подсказки, идем дальше.

> [!tip]- Ответ
> В первом случае будет `2 + 2`. Во втором - `4`.
> Если разница неочевидна, подробнее об этом в [[03.1 Строка это текст]] и [[Типы данных]].
