# Числа и арифметика

> [!note] Зачем это нужно:
Арифметика - база для всех заданий, где она есть. Например, №7, №11, №14, №15, №16 и кусков №24.

Питон умеет считать обычные выражения:

```
print(3 + 4)
print(10 - 6)
print(7 * 8)
```

Текст берем в кавычки, числа — нет:

```
print("3 + 4")  # выведет текст
print(3 + 4)    # выведет число 7
```

Основные операции:

| Запись | Что значит |
|---|---|
| `+` | сложение |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `//` | целая часть от деления |
| `%` | остаток от деления |
| `**` | степень |

Особенно важны `//` и `%`. Они постоянно встречаются в задачах, где надо работать с цифрами числа или остатками.

> [!tip] Зачем нужен `%`
> Через `% 10` мы будем доставать последнюю цифру числа. Через `% 7`, `% 14`, `% 25` будем проверять делимость в заданиях вроде [[№14 Операнды]] и [[№15 Флажки]].

```
print(17 // 5)  # 3
print(17 % 5)   # 2
```

Это значит: 17 делится на 5 три раза, остаток равен 2.

### Задачи

1. Выведи результат `81 / 9`.
2. Выведи результат `81 // 9`.
3. Выведи остаток от деления `81` на `9`.
4. Выведи остаток от деления `100` на `7`.
5. Выведи `2` в десятой степени.
6. Выведи сумму квадратов чисел `8` и `6`.
7. Найди целую часть и остаток от деления `1234` на `10`.
8. Найди последнюю цифру числа `98765`.
9. Мини-мостик к ЕГЭ: выведи сумму последней и предпоследней цифры числа `98765`.
10. Предскажи вывод, а потом проверь:

```
print(25 % 10)
print(25 // 10)
```

Если можешь достать последнюю цифру через `% 10`, а предпоследнюю через `// 10` и `% 10`, идем дальше.
