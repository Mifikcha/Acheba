# Минимальный Питон

Перед этим: [[01 Поставить Python, открыть IDE, создать рабочую папку|поставить Питон, открыть среду и создать рабочую папку]]

Цель этой заметки простая: ты должен не "понять программирование вообще", а руками запустить первые программы, увидеть результат, сломать код, починить код и научиться считать выражения так, как это делает Питон.

После этой заметки ты умеешь:

- запускать файл с программой;
- выводить текст и числа на экран;
- писать несколько команд подряд;
- оставлять комментарии;
- читать простые сообщения об ошибках;
- считать выражения с `+`, `-`, `*`, `/`, `//`, `%`, `**`;
- ставить скобки и понимать порядок действий;
- не пугаться дробных чисел с длинным хвостом.

Формат работы: коротко прочитал, сразу запустил, предсказал вывод, сломал код, починил код. Если просто читать и скроллить, смысла мало.

## Первая программа

Зачем это нужно: любая программа должна уметь показать результат, иначе непонятно, что она вообще сделала.

Самая маленькая полезная команда:

```
print("Hello, World!")
```

`print` выводит значение на экран. Это ваша первая и самая важная программа. В круглых скобках пишем то, что хотим увидеть. Если это текст, берем его в кавычки.

Запусти:

```
print("Я запустил программу")
print("Питон работает")
```

На экране должны появиться две строки.

> [!Note]
Питон выполняет команды сверху вниз: сначала первую, потом вторую.

### Задачи

1. Выведи на экран имя `Anon`.
2. Выведи на экран три строки:

```
ЕГЭ
Информатика
Питон
```

3. Напиши программу, которая выводит:

```
2 + 2
```

Именно текст `2 + 2`, а не результат арифметической операции.

4. Напиши программу, которая выводит:

```
Сначала думаю
Потом пишу
Потом запускаю
```

### Предскажи вывод

Что появится на экране?

```
print("2 + 2")
print(2 + 2)
```

Если можешь объяснить разницу без подсказки, идем дальше.

> [!tip]- Ответ
> В первом случае будет `2 + 2`. Во втором - `4`.

## Текст и кавычки

> [!note] Зачем это нужно:
Почти все ошибки в первых программах - это забытые кавычки, скобки и мелкие опечатки.

Текст в программе должен быть в кавычках:

```
print("Информатика")
print('Информатика')
```

Одинарные и двойные кавычки здесь работают одинаково. Главное: если открыл двойную кавычку, закрывай двойной; если открыл одинарную, закрывай одинарной.

Так нельзя:

```
print("Информатика')
```

Так тоже нельзя:

```
print("Информатика)
```

Во втором случае забыли закрыть кавычку.

> [!warning] Кавычки должны закрываться
> Если строка началась с `"`, она должна закончиться на `"`. Если началась с `'`, закрывай через `'`.

### Задачи

1. Выведи строку `Я решаю номер 5`.
2. Выведи строку `Ответ: 42`.
3. Специально сломай программу: убери закрывающую кавычку и запусти. Посмотри, что напишет Питон.
4. Почини программу из прошлого пункта.

### Мини-челлендж на 2 минуты

Сделай программу, которая сначала выводит текст `Ответ`, а потом на следующей строке число `2026`.

## Комментарии

> [!note] Зачем это нужно:
Комментарии помогают подписывать шаги решения, особенно когда код становится длиннее трех строк.

Комментарий — это заметка для человека. Питон ее не выполняет.

```
# Это комментарий
print("Эта строка выполнится")
```

Комментарий начинается со знака `#`. Его удобно использовать, чтобы подписывать шаги решения:

```
# Считаем значение выражения
print(17 + 25)
```

Комментарий может стоять и после команды:

```
print(100)  # выводим ответ
```

### Задачи

1. Напиши программу из двух строк: на первой комментарий `начало`, на второй вывод числа `10`.
2. Напиши три команды вывода и подпиши каждую комментарием.
3. Закомментируй одну команду вывода так, чтобы она не выполнилась.

Если можешь выключить строку кода через `#` и потом вернуть ее обратно — идем дальше.

## Команды выполняются по порядку

> [!note] Зачем это нужно:
В разборах ЕГЭ код всегда читается сверху вниз как рецепт решения.

Программа — это набор команд. Обычно одна команда пишется на одной строке.

```
print("Первая")
print("Вторая")
print("Третья")
```

Результат будет в том же порядке:

```
Первая
Вторая
Третья
```

Можно написать две команды в одной строке через `;`, но так почти никогда не надо делать:

```
print("Первая"); print("Вторая")
```

Для учебы и экзамена лучше писать понятно: одна команда — одна строка.

### Задачи

1. Выведи числа `1`, `2`, `3`, каждое на новой строке.
2. Поменяй порядок команд так, чтобы программа вывела:

```
старт
решение
ответ
```

3. Напиши пять команд вывода. Перед каждой поставь комментарий с номером шага.

### Задача на ошибку

Что не так с программой?

```
print("старт")
print("ответ")
print("решение")
```

Исправь порядок строк так, чтобы получился нормальный ход решения.

## Синтаксические ошибки

> [!note] Зачем это нужно:
На экзамене ошибка в одной скобке может съесть больше времени, чем сама задача.

Синтаксис - это правила записи программы. Если нарушить правило, программа не запустится.

Примеры частых ошибок:

```
print("Привет"
```

Забыли закрыть скобку.

```
print("Привет)
```

Забыли закрыть кавычку.

```
pront("Привет")
```

Опечатка в названии команды.

Когда появляется ошибка, не надо паниковать. Сначала смотри на номер строки, потом на место рядом со стрелкой или последним показанным символом. Часто ошибка находится прямо там или на предыдущем символе.

> [!warning] Сначала чини первую ошибку
> Если Питон показывает много текста, не читай все подряд. Найди строку ошибки, почини самый очевидный символ и запусти еще раз.

### Задачи

1. Запусти программу с пропущенной закрывающей скобкой. Найди строку ошибки.
2. Запусти программу с опечаткой `pront`. Посмотри, чем это сообщение отличается от ошибки со скобкой.
3. Исправь обе программы.
4. Напиши правильную программу:

```
print("ошибка найдена")
```

Если можешь сам найти пропущенную кавычку и скобку — идем дальше.

## Числа и арифметика

> [!note] Зачем это нужно:
Арифметика - база для всех заданий, где она есть. Например, №7, №11, №14, №15, №16 и кусков №24.

Питон умеет считать обычные выражения:

```
print(3 + 4)
print(10 - 6)
print(7 * 8)
```

Текст берем в кавычки, числа — нет:

```
print("3 + 4")  # выведет текст
print(3 + 4)    # выведет число 7
```

Основные операции:

| Запись | Что значит |
|---|---|
| `+` | сложение |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `//` | целая часть от деления |
| `%` | остаток от деления |
| `**` | степень |

Особенно важны `//` и `%`. Они постоянно встречаются в задачах, где надо работать с цифрами числа или остатками.

> [!tip] Зачем нужен `%`
> Через `% 10` мы будем доставать последнюю цифру числа. Через `% 7`, `% 14`, `% 25` будем проверять делимость в заданиях вроде [[№14 Операнды]] и [[№15 Флажки]].

```
print(17 // 5)  # 3
print(17 % 5)   # 2
```

Это значит: 17 делится на 5 три раза, остаток равен 2.

### Задачи

1. Выведи результат `81 / 9`.
2. Выведи результат `81 // 9`.
3. Выведи остаток от деления `81` на `9`.
4. Выведи остаток от деления `100` на `7`.
5. Выведи `2` в десятой степени.
6. Выведи сумму квадратов чисел `8` и `6`.
7. Найди целую часть и остаток от деления `1234` на `10`.
8. Найди последнюю цифру числа `98765`.
9. Мини-мостик к ЕГЭ: выведи сумму последней и предпоследней цифры числа `98765`.
10. Предскажи вывод, а потом проверь:

```
print(25 % 10)
print(25 // 10)
```

Если можешь достать последнюю цифру через `% 10`, а предпоследнюю через `// 10` и `% 10`, идем дальше.

## Оператор и операнд

> [!note] Зачем это нужно:
Когда в условии много знаков, надо видеть не “кашу”, а действия и числа, к которым они применяются.

В выражении:

```
print(8 + 2)
```

`+` — оператор, то есть знак действия. `8` и `2` — операнды, то есть значения, с которыми действие выполняется.

Операция с двумя значениями называется бинарной:

```
print(6 * 7)
```

Операция с одним значением называется унарной:

```
print(-5)
```

Минус перед числом делает число отрицательным.

### Задачи

1. Выведи `6 - -81`.
2. Выведи `-10 + 3`.
3. Выведи `5 * -4`.
4. В выражении `12 // 5` назови оператор и два операнда.
5. В выражении `-9` объясни, почему минус работает с одним числом.

### Предскажи вывод

```
print(6 - -81)
print(6 - 81)
```

Почему ответы разные?

> [!tip]- Ответ
> Первое - Питон воспринимает это как `6 - (-81) = 87`, а во втором случае - `6 - 81 = -75`

## Порядок имеет значение

> [!note] Зачем это нужно:
В задачах нельзя просто переставлять числа местами “для красоты”. Иногда от порядка меняется весь ответ.

Аналогично, как и в обычной математике.

Сложение и умножение можно менять местами:

```
print(3 + 5)
print(5 + 3)
```

Ответ одинаковый. Но с вычитанием и делением так нельзя:

```
print(10 - 3)
print(3 - 10)
```

Ответы разные. Поэтому в задачах важно не просто увидеть числа, а понять, в каком порядке они используются.

### Задачи

1. Проверь кодом, что `4 * 9` и `9 * 4` дают одинаковый ответ.
2. Проверь кодом, что `20 - 7` и `7 - 20` дают разные ответы.
3. Проверь кодом, что `20 / 5` и `5 / 20` дают разные ответы.
4. Придумай свой пример операции, где порядок не важен.
5. Придумай свой пример операции, где порядок важен.

Если можешь объяснить, почему `a - b` и `b - a` обычно разные, идем дальше.

## Составные выражения

> [!note] Зачем это нужно:
В реальных разборах часто одна строка кода считает сразу несколько действий, например в [[№16 Простая рекурсия]] и [[№24 Строки 2]].

Операции можно соединять:

```
print(2 * 4 * 5 * 10)
```

Питон сначала вычисляет выражение, потом выводит результат.

Еще пример:

```
print(8 / 2 + 5 - -3 / 2)
```

Вручную считать не нужно. Задача программы — посчитать за нас.

### Задачи

4. Выведи результат `2 ** 5 + 3 ** 3`.
5. Выведи результат `123 // 10 + 123 % 10`.

## Приоритет операций и скобки

> [!note] Зачем это нужно:
Скобки решают, что именно считается первым. В №16 это особенно заметно: одна скобка может полностью поменять ответ.

Питон считает выражения по тем же правилам, что и школьная математика:

1. сначала скобки;
2. потом степень;
3. потом умножение, деление, целая часть и остаток;
4. потом сложение и вычитание.

```
print(2 + 2 * 2)      # 6
print((2 + 2) * 2)    # 8
print(2 ** 3 * 2)     # 16
print(2 ** (3 * 2))   # 64
```

Если есть сомнение, ставь скобки. На экзамене понятная запись лучше, чем красивая.

> [!warning] Скобки меняют смысл
> `print((f(2024) + 2 * f(2023)) // f(2022))` и `print(f(2024) + 2 * f(2023) // f(2022))` — это разные вычисления. Такой тип ошибки встречается в [[№16 Простая рекурсия]].

### Задачи

1. Расставь скобки так, чтобы `70 * 3 + 4 / 8 + 2` сначала считало `3 + 4` и `8 + 2`.
2. Напиши программу для выражения: сумма чисел `15` и `25`, умноженная на `3`.
3. Напиши программу для выражения: квадрат разности `20` и `7`.
4. Напиши две программы: одна считает `2 + 3 * 4`, другая считает `(2 + 3) * 4`.
5. Объясни, почему ответы разные.

Если можешь поставить скобки так, чтобы программа считала именно твою мысль, идем дальше.

## Дробные числа

> [!note] Зачем это нужно:
> Дроби иногда появляются в вычислениях, но в первых программных задачах ЕГЭ чаще надежнее держаться целых чисел.

У дробных чисел в Питоне есть особенность:

```
print(0.2 + 0.1)
```

Можно увидеть:

```
0.30000000000000004
```

Это не ошибка. Компьютер хранит дробные числа приближенно. Для первых задач ЕГЭ чаще всего лучше работать с целыми числами, остатками и целой частью от деления.

Если дроби все-таки нужны, результат можно округлить:

```
print(round(0.2 + 0.1, 2))
```

> [!warning] Осторожно с `/`
> `/` дает дробный результат. Если нужна целая часть деления, используй `//`. Если нужен остаток, используй `%`.

### Задачи

1. Выведи `0.39 * 0.22`.
2. Выведи `0.1 + 0.2`.
3. Округли результат `0.1 + 0.2` до двух знаков.
4. Сравни `7 / 2` и `7 // 2`.
5. Объясни, почему в задачах с цифрами числа удобнее `%` и `//`, а не `/`.

## Как писать аккуратно

> [!note] Зачем это нужно:
> Аккуратный код легче проверять, а значит меньше шанс потерять балл из-за мелочи.

Питон поймет и так:

```
print(3+4*5)
```

Но человеку читать неприятно. Лучше писать с пробелами:

```
print(3 + 4 * 5)
```

Скобки тоже лучше ставить не "на магии", а там, где они помогают глазам:

```
print((123 // 10) % 10)
```

Эта программа получает десятки числа `123`.

### Задачи

1. Перепиши аккуратно:

```
print(8+2*5-3)
```

2. Перепиши аккуратно:

```
print((100//10)%10)
```

3. Напиши программу, которая получает последнюю цифру числа `456`.
4. Напиши программу, которая получает десятки числа `456`.
5. Напиши программу, которая получает сотни числа `456`.

## Мини-проверка

Напиши не на этом сайте, а у себя в IDE одну программу, которая выводит:

Решение не подглядывать сразу. Сначала набрать самому, запустить, исправить ошибки, потом сверить идею:

> [!tip]- Ответ
> ```
> print("Начало")
print(2 + 2 * 2)
print((2 + 2) * 2)
print(2026 % 10)
print((2026 // 10) % 10)

> ```

Дальше можно переходить к условиям, циклам и первым экзаменационным переборам.
