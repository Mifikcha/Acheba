# Звезда 071. Предскажи вывод 1. Индексы

Уровень: E

### Задача

Напиши predict_output_1(): верни список строк, которые выведет программа из условия.

### Программа

```python
s = "informatics"
result = ""
for i in range(len(s)):
    if i % 2 == 0:
        result += s[i]
    elif s[i] == "a":
        result += "!"
print(result)
```
