# Звезда 079. Две ссылки на один список

Что выведет?

```python
a = [3, 1, 2]
b = a
b.sort()
a.append(0)
print(a)
print(b)
```

В редакторе справа напечатай ровно тот вывод, который получится у программы из условия. Лишние строки и пояснения в выводе считаются другим ответом.

## Примеры

- `print('[1, 2]') -> stdout '[1, 2]'`
- `print('[1]\n[1]') -> two output lines`
- `print('[]') -> stdout '[]'`

> [!tip]- Подсказка 1
> `b = a` не копирует список.

> [!tip]- Подсказка 2
> Обе переменные видят одни изменения.
