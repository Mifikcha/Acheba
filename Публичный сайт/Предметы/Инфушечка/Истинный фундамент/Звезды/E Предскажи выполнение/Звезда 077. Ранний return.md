# Звезда 077. Ранний return

Что выведет?

```python
def f(text):
    for ch in text:
        if ch.isdigit():
            return ch
    return '-'

print(f('ab3c4'))
print(f('abcd'))
```

В редакторе справа напечатай ровно тот вывод, который получится у программы из условия. Лишние строки и пояснения в выводе считаются другим ответом.

## Примеры

- `print('3') -> stdout '3'`
- `print('3\n-') -> two output lines`
- `print('-') -> stdout '-'`

> [!tip]- Подсказка 1
> Вернётся первая найденная цифра.

> [!tip]- Подсказка 2
> Во второй строке цифр нет.
