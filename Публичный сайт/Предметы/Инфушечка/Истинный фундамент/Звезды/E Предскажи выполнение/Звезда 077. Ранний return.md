# Звезда 077. Ранний return

Что выведет?

```python
def f(text):
    for ch in text:
        if ch.isdigit():
            return ch
    return '-'

print(f('ab3c4'))
print(f('abcd'))
```

> [!tip]- Подсказка 1
> Вернётся первая найденная цифра.

> [!tip]- Подсказка 2
> Во второй строке цифр нет.
