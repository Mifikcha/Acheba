# Звезда 080. Частоты и сортировка

Что выведет?

```python
text = 'abbccc'
freq = {}
for ch in text:
    freq[ch] = freq.get(ch, 0) + 1
result = []
for ch in freq:
    if freq[ch] >= 2:
        result.append(ch)
print(sorted(result, reverse=True))
```

В редакторе справа напечатай ровно тот вывод, который получится у программы из условия. Лишние строки и пояснения в выводе считаются другим ответом.

## Примеры

- `print(['a']) -> stdout "['a']"`
- `print(['c', 'b']) -> stdout "['c', 'b']"`
- `print([]) -> stdout '[]'`

> [!tip]- Подсказка 1
> Подходят символы с частотой минимум 2.

> [!tip]- Подсказка 2
> Потом обратная сортировка.
