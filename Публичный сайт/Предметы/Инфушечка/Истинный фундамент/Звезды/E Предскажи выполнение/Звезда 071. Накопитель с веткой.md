# Звезда 071. Накопитель с веткой

Что выведет код?

```python
total = 0
for x in range(1, 6):
    if x % 2 == 0:
        total += x
    else:
        total -= 1
print(total)
```

> [!tip]- Подсказка 1
> Пройди значения 1–5.

> [!tip]- Подсказка 2
> Для нечётных вычитается 1, а не `x`.
