# Звезда 076. Множество

Что выведет?

```python
a = [1, 1, 2, 3, 3, 3]
b = set(a)
b.add(2)
b.add(4)
print(len(b))
```

> [!tip]- Подсказка 1
> Повторное добавление не меняет множество.

> [!tip]- Подсказка 2
> Изначально различны 1,2,3.
