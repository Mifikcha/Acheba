# Звезда 076. Множество

Что выведет?

```python
a = [1, 1, 2, 3, 3, 3]
b = set(a)
b.add(2)
b.add(4)
print(len(b))
```

В редакторе справа напечатай ровно тот вывод, который получится у программы из условия. Лишние строки и пояснения в выводе считаются другим ответом.

## Примеры

- `print('4') -> stdout '4'`
- `print('2') -> stdout '2'`
- `print('set') -> stdout 'set'`

> [!tip]- Подсказка 1
> Повторное добавление не меняет множество.

> [!tip]- Подсказка 2
> Изначально различны 1,2,3.
