# Звезда 072. Строка по индексам

Что выведет?

```python
s = 'python'
result = ''
for i in range(len(s)):
    if i % 2 == 0:
        result += s[i].upper()
    else:
        result += s[i]
print(result)
```

> [!tip]- Подсказка 1
> Индексы начинаются с 0.

> [!tip]- Подсказка 2
> Верхний регистр только на чётных индексах.
