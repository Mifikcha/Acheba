# Звезда 072. Строка по индексам

Что выведет?

```python
s = 'python'
result = ''
for i in range(len(s)):
    if i % 2 == 0:
        result += s[i].upper()
    else:
        result += s[i]
print(result)
```

В редакторе справа напечатай ровно тот вывод, который получится у программы из условия. Лишние строки и пояснения в выводе считаются другим ответом.

## Примеры

- `print('Ab') -> stdout 'Ab'`
- `print('TEXT') -> stdout 'TEXT'`
- `print('x\ny') -> two output lines`

> [!tip]- Подсказка 1
> Индексы начинаются с 0.

> [!tip]- Подсказка 2
> Верхний регистр только на чётных индексах.
