# Звезда 075. Вложенное условие

Что выведет?

```python
count = 0
for x in range(1, 11):
    if x % 2 == 0:
        if x % 3 != 0:
            count += 1
print(count)
```

> [!tip]- Подсказка 1
> Сначала выпиши чётные.

> [!tip]- Подсказка 2
> Из них убери делящиеся на 3.
