# Звезда 074. break

Что выведет?

```python
answer = 0
for x in range(10):
    if x == 4:
        break
    answer += x
print(answer)
```

> [!tip]- Подсказка 1
> При `x == 4` прибавление уже не происходит.

> [!tip]- Подсказка 2
> Складываются 0,1,2,3.
