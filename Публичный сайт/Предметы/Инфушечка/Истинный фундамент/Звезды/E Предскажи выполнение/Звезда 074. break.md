# Звезда 074. break

Что выведет?

```python
answer = 0
for x in range(10):
    if x == 4:
        break
    answer += x
print(answer)
```

В редакторе справа напечатай ровно тот вывод, который получится у программы из условия. Лишние строки и пояснения в выводе считаются другим ответом.

## Примеры

- `print('10') -> stdout '10'`
- `print('0') -> stdout '0'`
- `print('done') -> stdout 'done'`

> [!tip]- Подсказка 1
> При `x == 4` прибавление уже не происходит.

> [!tip]- Подсказка 2
> Складываются 0,1,2,3.
