# Звезда 097. Категории товаров

Строки `название:категория:цена`. Для каждой категории верни вложенный словарь: `count`, `min_price`, `max_price`, `names` (по алфавиту).

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `group_products(['pen:office:10', 'cup:kitchen:5'])` → `{'office': {'count': 1, 'min_price': 10, 'max_price': 10, 'names': ['pen']}, 'kitchen': {'count': 1, 'min_price': 5, 'max_price': 5, 'names': ['cup']}}`
- `group_products([])` → `{}`
- `group_products(['b:c:2', 'a:c:1'])` → `{'c': {'count': 2, 'min_price': 1, 'max_price': 2, 'names': ['a', 'b']}}`

> [!tip]- Подсказка 1
> При первом появлении категории создай структуру.

> [!tip]- Подсказка 2
> После обработки отсортируй списки имён.
