# Звезда 098. Кодирование серий

Напиши `rle(text)`: `aaabbc -> a3b2c1`; затем `unrle(code)`. Для декодирования гарантируется, что количество — одна цифра 1–9.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `rle('aaabbc')` → `'a3b2c1'`
- `unrle('a3b2c1')` → `'aaabbc'`
- `rle('')` → `''`

> [!tip]- Подсказка 1
> Для кодирования храни текущий символ и длину серии.

> [!tip]- Подсказка 2
> Для декодирования иди по строке парами.
