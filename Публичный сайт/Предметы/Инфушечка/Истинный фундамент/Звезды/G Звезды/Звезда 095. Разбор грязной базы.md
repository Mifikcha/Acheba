# Звезда 095. Разбор грязной базы

Строки имеют вид `ID|Имя|Балл`. Игнорируй строки не из 3 полей и строки, где ID/балл не цифры. Верни словарь `id -> {'name':..., 'score':...}`; при повторном ID оставь больший балл.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `parse_database(['1|Ann|5', 'bad'])` → `{1: {'name': 'Ann', 'score': 5}}`
- `parse_database(['1|Ann|5', '1|Ann|7'])` → `{1: {'name': 'Ann', 'score': 7}}`
- `parse_database([])` → `{}`

> [!tip]- Подсказка 1
> Перед `int` используй `.isdigit()`.

> [!tip]- Подсказка 2
> Сначала проверь число полей.
