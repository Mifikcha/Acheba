# Звезда 095. Разбор грязной базы

Строки имеют вид `ID|Имя|Балл`. Игнорируй строки не из 3 полей и строки, где ID/балл не цифры. Верни словарь `id -> {'name':..., 'score':...}`; при повторном ID оставь больший балл.

> [!tip]- Подсказка 1
> Перед `int` используй `.isdigit()`.

> [!tip]- Подсказка 2
> Сначала проверь число полей.
