# Звезда 099. Турнирная таблица

Даны матчи `A-B:3-1`. Победа 3 очка, ничья 1. Верни команды, отсортированные по очкам ↓, забитым голам ↓, названию ↑, и словарь статистики `points`, `goals`, `games`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `table(['A-B:3-1'])` → `(['A', 'B'], {'A': {'points': 3, 'goals': 3, 'games': 1}, 'B': {'points': 0, 'goals': 1, 'games': 1}})`
- `table(['A-B:1-1'])` → `(['A', 'B'], {'A': {'points': 1, 'goals': 1, 'games': 1}, 'B': {'points': 1, 'goals': 1, 'games': 1}})`
- `table([])` → `([], {})`

> [!tip]- Подсказка 1
> Сначала разбери строку на две команды и два счёта.

> [!tip]- Подсказка 2
> Ключ сортировки: `(-points, -goals, name)`.
