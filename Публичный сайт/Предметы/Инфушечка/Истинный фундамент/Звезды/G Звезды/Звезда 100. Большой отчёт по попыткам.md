# Звезда 100. Большой отчёт по попыткам

Финальная задача. Строки: `ученик|тема|номер|результат|время`, где результат `OK/FAIL`, время — секунды. Для ученика верни общие `attempts`, `solved`, `success_rate`, `average_time`, статистику каждой темы (`attempts`, `solved`, `fails`, `average_time`) и `weak_topic`. Слабая тема: минимальная доля успеха; при равенстве — больше попыток; затем алфавит. Если ученика нет — `None`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `build_report(['Аня|логика|1|OK|30'], 'Аня')` → `{'attempts': 1, 'solved': 1, 'success_rate': 1.0, 'average_time': 30.0, 'topics': {'логика': {'attempts': 1, 'solved': 1, 'fails': 0, 'average_time': 30.0}}, 'weak_topic': 'логика'}`
- `build_report([], 'Аня')` → `None`
- `build_report(['Боря|циклы|1|FAIL|40'], 'Аня')` → `None`

> [!tip]- Подсказка 1
> Сначала собери сырые счётчики и суммы времени.

> [!tip]- Подсказка 2
> Средние и слабую тему вычисляй только после чтения всех строк.
