# Звезда 092. Отчёт ученика

Даны строки `Имя;тема;балл`. Для выбранного ученика верни число попыток, средний балл, словарь лучшего балла по темам и список тем, где лучший балл < 7. Если ученика нет — `None`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `student_report(['Аня;логика;5', 'Аня;логика;8'], 'Аня')` → `{'attempts': 2, 'average': 6.5, 'best_by_topic': {'логика': 8}, 'weak_topics': []}`
- `student_report([], 'Аня')` → `None`
- `student_report(['Боря;циклы;6'], 'Аня')` → `None`

> [!tip]- Подсказка 1
> Нужен словарь лучших баллов по теме.

> [!tip]- Подсказка 2
> Среднее считай по всем попыткам ученика.
