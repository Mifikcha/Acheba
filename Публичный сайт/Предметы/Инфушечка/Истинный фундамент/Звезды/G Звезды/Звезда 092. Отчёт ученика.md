# Звезда 092. Отчёт ученика

Даны строки `Имя;тема;балл`. Для выбранного ученика верни число попыток, средний балл, словарь лучшего балла по темам и список тем, где лучший балл < 7. Если ученика нет — `None`.

> [!tip]- Подсказка 1
> Нужен словарь лучших баллов по теме.

> [!tip]- Подсказка 2
> Среднее считай по всем попыткам ученика.
