# Звезда 094. Мини-антиплагиат

Для двух строк слов верни: число общих разных слов, только в A, только в B и `same_vocabulary`. Регистр не учитывать.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `similarity('one two', 'two three')` → `{'common': 1, 'only_a': 1, 'only_b': 1, 'same_vocabulary': False}`
- `similarity('A a', 'a')` → `{'common': 1, 'only_a': 0, 'only_b': 0, 'same_vocabulary': True}`
- `similarity('', '')` → `{'common': 0, 'only_a': 0, 'only_b': 0, 'same_vocabulary': True}`

> [!tip]- Подсказка 1
> Сделай два множества слов.

> [!tip]- Подсказка 2
> Используй пересечение, разности и равенство множеств.
