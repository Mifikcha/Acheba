# Звезда 079. Предскажи вывод 9. While

Уровень: E

### Задача

Напиши predict_output_9(): верни список строк, которые выведет программа из условия.

### Программа

```python
n = 25
count = 0
while n > 0:
    if n % 10 > 2:
        count += 1
    n //= 10
print(count)
```
