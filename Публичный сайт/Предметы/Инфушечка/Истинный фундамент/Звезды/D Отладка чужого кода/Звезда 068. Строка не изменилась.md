# Звезда 068. Строка не изменилась

Почему печатается исходная строка?

```python
text = 'abracadabra'
text.replace('a', '*')
print(text)
```

> [!tip]- Подсказка 1
> Строки неизменяемы.

> [!tip]- Подсказка 2
> Метод возвращает новую строку.
