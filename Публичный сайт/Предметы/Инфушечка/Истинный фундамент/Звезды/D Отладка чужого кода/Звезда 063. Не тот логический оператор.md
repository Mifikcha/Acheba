# Звезда 063. Не тот логический оператор

Функция должна проверять делимость одновременно на 2 и 3:

```python
def good(x):
    return x % 2 == 0 or x % 3 == 0
```

> [!tip]- Подсказка 1
> Слово «и» важно буквально.

> [!tip]- Подсказка 2
> `or` пропускает выполнение одного условия.
