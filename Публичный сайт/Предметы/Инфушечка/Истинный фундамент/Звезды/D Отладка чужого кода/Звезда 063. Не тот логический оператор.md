# Звезда 063. Не тот логический оператор

Функция должна проверять делимость одновременно на 2 и 3:

```python
def good(x):
    return x % 2 == 0 or x % 3 == 0
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `good(6)` → `True`
- `good(4)` → `False`
- `good(9)` → `False`

> [!tip]- Подсказка 1
> Слово «и» важно буквально.

> [!tip]- Подсказка 2
> `or` пропускает выполнение одного условия.
