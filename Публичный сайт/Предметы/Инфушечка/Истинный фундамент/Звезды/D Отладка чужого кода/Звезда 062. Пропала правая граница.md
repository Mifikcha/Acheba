# Звезда 062. Пропала правая граница

Код должен вернуть `[1,2,...,n]`, но `n` теряется:

```python
for x in range(1, n):
    result.append(x)
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `numbers(3)` → `[1, 2, 3]`
- `numbers(1)` → `[1]`
- `numbers(0)` → `[]`

> [!tip]- Подсказка 1
> Правая граница `range` не включается.

> [!tip]- Подсказка 2
> Нужно `n + 1`.
