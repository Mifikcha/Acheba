# Звезда 062. Пропала правая граница

Код должен вернуть `[1,2,...,n]`, но `n` теряется:

```python
for x in range(1, n):
    result.append(x)
```

> [!tip]- Подсказка 1
> Правая граница `range` не включается.

> [!tip]- Подсказка 2
> Нужно `n + 1`.
