# Звезда 067. Соседа справа нет

Иногда возникает `IndexError`:

```python
for i in range(1, len(a)):
    if a[i] > a[i-1] and a[i] > a[i+1]:
        ...
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `peaks([1, 3, 2])` → `[3]`
- `peaks([1, 2, 3])` → `[]`
- `peaks([5, 1, 5])` → `[]`

> [!tip]- Подсказка 1
> На последнем индексе `i+1` не существует.

> [!tip]- Подсказка 2
> Остановись на предпоследнем.
