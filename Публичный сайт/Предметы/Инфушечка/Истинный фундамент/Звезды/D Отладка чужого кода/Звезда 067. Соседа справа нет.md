# Звезда 067. Соседа справа нет

Иногда возникает `IndexError`:

```python
for i in range(1, len(a)):
    if a[i] > a[i-1] and a[i] > a[i+1]:
        ...
```

> [!tip]- Подсказка 1
> На последнем индексе `i+1` не существует.

> [!tip]- Подсказка 2
> Остановись на предпоследнем.
