# Звезда 070. Пустая строка ломает индекс

Сделай безопасной функцию:

```python
def question(text):
    return text[-1] == '?'
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `question('Да?')` → `True`
- `question('нет')` → `False`
- `question('')` → `False`

> [!tip]- Подсказка 1
> Сначала убедись, что символ существует.

> [!tip]- Подсказка 2
> `and` умеет короткое замыкание.
