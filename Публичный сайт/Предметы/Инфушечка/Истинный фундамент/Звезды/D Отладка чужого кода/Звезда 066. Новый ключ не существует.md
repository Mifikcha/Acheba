# Звезда 066. Новый ключ не существует

Код падает на первом слове:

```python
result = {}
for word in words:
    result[word] += 1
```

> [!tip]- Подсказка 1
> Новый ключ ещё не имеет значения.

> [!tip]- Подсказка 2
> Используй `.get(word, 0)`.
