# Звезда 066. Новый ключ не существует

Код падает на первом слове:

```python
result = {}
for word in words:
    result[word] += 1
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `freq(['a', 'b', 'a'])` → `{'a': 2, 'b': 1}`
- `freq([])` → `{}`
- `freq(['x'])` → `{'x': 1}`

> [!tip]- Подсказка 1
> Новый ключ ещё не имеет значения.

> [!tip]- Подсказка 2
> Используй `.get(word, 0)`.
