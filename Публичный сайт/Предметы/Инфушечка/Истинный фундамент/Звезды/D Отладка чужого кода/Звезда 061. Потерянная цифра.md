# Звезда 061. Потерянная цифра

Код должен считать сумму цифр, но зацикливается:

```python
def digit_sum(n):
    total = 0
    while n > 0:
        total += n % 10
    return total
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `digit_sum(123)` → `6`
- `digit_sum(1000)` → `1`
- `digit_sum(0)` → `0`

> [!tip]- Подсказка 1
> Состояние `n` должно меняться.

> [!tip]- Подсказка 2
> После обработки цифру надо удалить.
