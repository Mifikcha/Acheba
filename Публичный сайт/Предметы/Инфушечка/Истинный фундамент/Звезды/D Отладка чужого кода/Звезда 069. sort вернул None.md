# Звезда 069. sort вернул None

Почему `result = numbers.sort()` даёт `None`? Исправь двумя способами.

В редакторе справа оставь переменную `result` со списком по возрастанию. Можно выбрать любой из двух способов, но итоговое значение должно быть списком, а не `None`.

## Примеры

- `result for [5, 2, 8, 1]` → `[1, 2, 5, 8]`
- `result for [3, 3, 1]` → `[1, 3, 3]`
- `result for []` → `[]`

> [!tip]- Подсказка 1
> `.sort()` меняет список на месте.

> [!tip]- Подсказка 2
> `sorted()` возвращает новый список.
