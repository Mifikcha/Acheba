# Звезда 064. Счётчик стирается

Почему код возвращает максимум 1?

```python
def count_a(text):
    for ch in text:
        count = 0
        if ch == 'a':
            count += 1
    return count
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `count_a('banana')` → `3`
- `count_a('bbb')` → `0`
- `count_a('aaa')` → `3`

> [!tip]- Подсказка 1
> Где должен создаваться накопитель?

> [!tip]- Подсказка 2
> Не обнуляй его на каждой итерации.
