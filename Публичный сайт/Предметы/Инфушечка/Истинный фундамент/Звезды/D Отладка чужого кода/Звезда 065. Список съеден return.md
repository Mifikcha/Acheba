# Звезда 065. Список съеден return

Функция возвращает только один удвоенный элемент:

```python
def double(numbers):
    result = []
    for x in numbers:
        result.append(x * 2)
        return result
```

> [!tip]- Подсказка 1
> `return` завершает функцию.

> [!tip]- Подсказка 2
> Перенеси его после цикла.
