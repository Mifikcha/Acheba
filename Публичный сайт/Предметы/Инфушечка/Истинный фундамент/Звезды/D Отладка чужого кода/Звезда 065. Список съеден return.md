# Звезда 065. Список съеден return

Функция возвращает только один удвоенный элемент:

```python
def double(numbers):
    result = []
    for x in numbers:
        result.append(x * 2)
        return result
```

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `double([1, 2, 3])` → `[2, 4, 6]`
- `double([])` → `[]`
- `double([-1, 5])` → `[-2, 10]`

> [!tip]- Подсказка 1
> `return` завершает функцию.

> [!tip]- Подсказка 2
> Перенеси его после цикла.
