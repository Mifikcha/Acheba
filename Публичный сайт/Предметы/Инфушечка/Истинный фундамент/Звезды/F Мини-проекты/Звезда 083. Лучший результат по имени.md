# Звезда 083. Лучший результат по имени

Дан список строк `Имя:балл`. Верни словарь `имя -> лучший балл`; имя может повторяться.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `score_table(['Аня:5', 'Аня:8'])` → `{'Аня': 8}`
- `score_table([])` → `{}`
- `score_table(['Боря:7'])` → `{'Боря': 7}`

> [!tip]- Подсказка 1
> Разбей строку по `:`.

> [!tip]- Подсказка 2
> Обновляй только если нового имени ещё нет или балл выше.
