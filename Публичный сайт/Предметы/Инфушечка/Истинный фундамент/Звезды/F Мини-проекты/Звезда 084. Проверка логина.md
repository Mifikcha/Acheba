# Звезда 084. Проверка логина

Верни первую причину отказа: `too_short` (<5), `bad_first` (первый не буква), `space`, `no_digit`, иначе `ok`. Порядок важен.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `check_login('ab1')` → `'too_short'`
- `check_login('1abcd')` → `'bad_first'`
- `check_login('abcde1')` → `'ok'`

> [!tip]- Подсказка 1
> Проверки должны идти ровно в заданном порядке.

> [!tip]- Подсказка 2
> Для цифры нужен отдельный поиск по строке.
