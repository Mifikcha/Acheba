# Звезда 087. Журнал температур

Для непустого списка верни среднее, min, max, число дней выше среднего и длину самой длинной серии строгого ежедневного роста.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `temperature_report([1, 2, 3])` → `{'average': 2.0, 'min': 1, 'max': 3, 'above_average': 1, 'longest_growth': 3}`
- `temperature_report([3, 2, 1])` → `{'average': 2.0, 'min': 1, 'max': 3, 'above_average': 1, 'longest_growth': 1}`
- `temperature_report([5])` → `{'average': 5.0, 'min': 5, 'max': 5, 'above_average': 0, 'longest_growth': 1}`

> [!tip]- Подсказка 1
> Среднее нужно узнать до второго показателя.

> [!tip]- Подсказка 2
> Для серии храни текущую и лучшую длину.
