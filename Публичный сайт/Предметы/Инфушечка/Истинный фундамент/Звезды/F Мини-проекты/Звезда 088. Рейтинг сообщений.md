# Звезда 088. Рейтинг сообщений

Рейтинг строки = `2*буквы + 3*цифры - пробелы`. Верни индекс сообщения с максимальным рейтингом; при равенстве — самый ранний.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `message_rating(['a1', 'abc'])` → `1`
- `message_rating(['x', 'y'])` → `0`
- `message_rating(['  ', '1'])` → `1`

> [!tip]- Подсказка 1
> Считай рейтинг каждой строки отдельно.

> [!tip]- Подсказка 2
> Лучший ответ обновляй только при строго большем значении.
