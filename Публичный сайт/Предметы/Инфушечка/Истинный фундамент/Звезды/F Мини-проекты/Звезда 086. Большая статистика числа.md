# Звезда 086. Большая статистика числа

Для неотрицательного `n` верни: число цифр, сумму, min, max, число чётных, число различных цифр и наличие одинаковых соседних цифр.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `analyze_number(1220)` → `{'digits': 4, 'sum': 5, 'min': 0, 'max': 2, 'even': 3, 'unique': 3, 'adjacent_same': True}`
- `analyze_number(0)` → `{'digits': 1, 'sum': 0, 'min': 0, 'max': 0, 'even': 1, 'unique': 1, 'adjacent_same': False}`
- `analyze_number(987)` → `{'digits': 3, 'sum': 24, 'min': 7, 'max': 9, 'even': 1, 'unique': 3, 'adjacent_same': False}`

> [!tip]- Подсказка 1
> Строка упрощает соседей и уникальность.

> [!tip]- Подсказка 2
> Все показатели можно посчитать за один проход.
