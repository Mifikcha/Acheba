# Звезда 081. Анализатор текста

Верни словарь: длина строки, количество букв, цифр, пробелов и различных символов. Пунктуация влияет только на длину и число уникальных.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `analyze_text('A1 !')` → `{'length': 4, 'letters': 1, 'digits': 1, 'spaces': 1, 'unique': 4}`
- `analyze_text('')` → `{'length': 0, 'letters': 0, 'digits': 0, 'spaces': 0, 'unique': 0}`
- `analyze_text('abc')` → `{'length': 3, 'letters': 3, 'digits': 0, 'spaces': 0, 'unique': 3}`

> [!tip]- Подсказка 1
> Все счётчики можно обновить одним проходом.

> [!tip]- Подсказка 2
> Для уникальных символов используй множество.
