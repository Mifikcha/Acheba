# Звезда 075. Предскажи вывод 5. Range

Уровень: E

### Задача

Напиши predict_output_5(): верни список строк, которые выведет программа из условия.

### Программа

```python
result = []
for x in range(2, 7, 2):
    result.append(x)
print(result)
```
