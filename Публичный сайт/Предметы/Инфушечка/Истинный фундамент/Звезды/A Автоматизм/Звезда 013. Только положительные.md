# Звезда 013. Только положительные

Верни новый список положительных элементов, сохраняя порядок.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `positive_only([-1, 2, 0, 5])` → `[2, 5]`
- `positive_only([-3, -2])` → `[]`
- `positive_only([1, 2, 3])` → `[1, 2, 3]`

> [!tip]- Подсказка 1
> Не меняй исходный список.

> [!tip]- Подсказка 2
> Фильтруй условием `x > 0`.
