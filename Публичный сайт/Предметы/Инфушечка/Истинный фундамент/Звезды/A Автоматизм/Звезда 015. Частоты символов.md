# Звезда 015. Частоты символов

Верни словарь `символ -> количество появлений` для строки.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `frequencies('aba')` → `{'a': 2, 'b': 1}`
- `frequencies('')` → `{}`
- `frequencies('112')` → `{'1': 2, '2': 1}`

> [!tip]- Подсказка 1
> Нужен словарь-счётчик.

> [!tip]- Подсказка 2
> `.get(ch, 0)` даёт 0 для нового ключа.
