# Звезда 001. Три цифры наоборот

Дано трёхзначное положительное число `n`. Напиши `reverse3(n)`, возвращающую число с цифрами в обратном порядке. Строки использовать нельзя.

> [!tip]- Подсказка 1
> Последняя цифра — `n % 10`.

> [!tip]- Подсказка 2
> После `n // 10` последняя цифра исчезает.
