# Звезда 014. Количество разных

Верни количество различных элементов списка.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `unique_count([1, 1, 2, 3])` → `3`
- `unique_count('banana')` → `3`
- `unique_count([])` → `0`

> [!tip]- Подсказка 1
> Множество удаляет повторы.

> [!tip]- Подсказка 2
> Используй `len(set(...))`.
