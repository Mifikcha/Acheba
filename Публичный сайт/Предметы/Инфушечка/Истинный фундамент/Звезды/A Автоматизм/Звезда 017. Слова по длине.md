# Звезда 017. Слова по длине

Верни слова, отсортированные сначала по длине, затем по алфавиту.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `sort_words(['aa', 'b', 'ccc'])` → `['b', 'aa', 'ccc']`
- `sort_words(['cat', 'a', 'bb'])` → `['a', 'bb', 'cat']`
- `sort_words([])` → `[]`

> [!tip]- Подсказка 1
> `sorted` принимает `key`.

> [!tip]- Подсказка 2
> Ключом может быть пара `(len(word), word)`.
