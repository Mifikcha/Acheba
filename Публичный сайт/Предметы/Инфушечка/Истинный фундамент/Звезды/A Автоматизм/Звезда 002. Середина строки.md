# Звезда 002. Середина строки

Напиши `middle(text)`: для нечётной длины вернуть один центральный символ, для чётной — два центральных.

> [!tip]- Подсказка 1
> Центральный индекс связан с `len(text) // 2`.

> [!tip]- Подсказка 2
> Для чётной длины нужны позиции `m - 1` и `m`.
