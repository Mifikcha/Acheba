# Звезда 005. Рамка

Напиши `frame(text)`, добавляющую по три `*` слева и справа: `ЕГЭ -> ***ЕГЭ***`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `frame('ЕГЭ')` → `'***ЕГЭ***'`
- `frame('x')` → `'***x***'`
- `frame('')` → `'******'`

> [!tip]- Подсказка 1
> Строки можно умножать на число.

> [!tip]- Подсказка 2
> Потом склей три части.
