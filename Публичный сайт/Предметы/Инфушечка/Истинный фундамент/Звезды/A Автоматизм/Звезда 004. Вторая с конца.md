# Звезда 004. Вторая с конца

Напиши `second_last(text)`, возвращающую предпоследний символ строки длиной не меньше 2.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `second_last('python')` → `'o'`
- `second_last('ab')` → `'a'`
- `second_last('ЕГЭ')` → `'Г'`

> [!tip]- Подсказка 1
> В Python есть отрицательные индексы.

> [!tip]- Подсказка 2
> Последний индекс — `-1`.
