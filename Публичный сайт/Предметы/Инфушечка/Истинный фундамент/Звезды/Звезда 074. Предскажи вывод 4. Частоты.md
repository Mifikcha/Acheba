# Звезда 074. Предскажи вывод 4. Частоты

### Задача

Напиши predict_output_4(): верни список строк, которые выведет программа из условия.

### Программа

```python
freq = {}
for ch in "abba":
    freq[ch] = freq.get(ch, 0) + 1
print(freq["a"])
print(freq["b"])
```
