# Звезда 080. Предскажи вывод 10. Условия

Уровень: E

### Задача

Напиши predict_output_10(): верни список строк, которые выведет программа из условия.

### Программа

```python
text = "A1b2C3"
result = ""
for ch in text:
    if ch.isdigit():
        result += "#"
    elif ch.isupper():
        result += ch.lower()
print(result)
```
