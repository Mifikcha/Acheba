# Звезда 072. Предскажи вывод 2. Сумма нечетных

Уровень: E

### Задача

Напиши predict_output_2(): верни список строк, которые выведет программа из условия.

### Программа

```python
total = 0
for x in range(1, 6):
    if x % 2 == 1:
        total += x
print(total)
```
