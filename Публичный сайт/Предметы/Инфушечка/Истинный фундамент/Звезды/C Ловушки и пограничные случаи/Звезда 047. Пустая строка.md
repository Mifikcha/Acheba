# Звезда 047. Пустая строка

`same_edges(text)` возвращает `True`, если строка непустая и первый символ равен последнему; для `` — `False`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `same_edges('aba')` → `True`
- `same_edges('abc')` → `False`
- `same_edges('')` → `False`

> [!tip]- Подсказка 1
> Нельзя сразу брать `text[0]`.

> [!tip]- Подсказка 2
> Используй короткое замыкание `and`.
