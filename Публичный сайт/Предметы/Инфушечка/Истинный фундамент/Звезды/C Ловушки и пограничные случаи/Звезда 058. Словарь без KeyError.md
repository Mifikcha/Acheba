# Звезда 058. Словарь без KeyError

Верни балл `scores[name]`, а если имени нет — 0, не допуская `KeyError`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `score_of({'Аня': 5}, 'Аня')` → `5`
- `score_of({'Аня': 5}, 'Боря')` → `0`
- `score_of({}, 'x')` → `0`

> [!tip]- Подсказка 1
> У словаря есть безопасный метод.

> [!tip]- Подсказка 2
> Нужно значение по умолчанию.
