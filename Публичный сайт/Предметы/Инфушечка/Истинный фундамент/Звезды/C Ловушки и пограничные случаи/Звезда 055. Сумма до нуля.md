# Звезда 055. Сумма до нуля

Суммируй элементы до первого нуля, не включая его. Если нуля нет — весь список.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `sum_before_zero([1, 2, 0, 5])` → `3`
- `sum_before_zero([0, 1])` → `0`
- `sum_before_zero([1, 2, 3])` → `6`

> [!tip]- Подсказка 1
> `break` завершает цикл.

> [!tip]- Подсказка 2
> Сначала проверка, потом прибавление.
