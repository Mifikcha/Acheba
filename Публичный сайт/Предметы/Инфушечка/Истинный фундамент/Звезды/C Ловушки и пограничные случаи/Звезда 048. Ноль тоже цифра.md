# Звезда 048. Ноль тоже цифра

Посчитай цифры неотрицательного числа. Для `0` ответ 1.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `digit_count_zero(0)` → `1`
- `digit_count_zero(10)` → `2`
- `digit_count_zero(999)` → `3`

> [!tip]- Подсказка 1
> `while n > 0` для нуля не запустится.

> [!tip]- Подсказка 2
> Обработай ноль отдельно.
