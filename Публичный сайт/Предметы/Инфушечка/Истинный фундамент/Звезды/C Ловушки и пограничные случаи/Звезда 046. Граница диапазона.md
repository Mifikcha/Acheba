# Звезда 046. Граница диапазона

Посчитай числа на закрытом отрезке `[a,b]`, делящиеся на `k`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `multiples(1, 10, 3)` → `3`
- `multiples(5, 5, 5)` → `1`
- `multiples(2, 4, 10)` → `0`

> [!tip]- Подсказка 1
> Главная ловушка — правая граница `range`.

> [!tip]- Подсказка 2
> Для включения `b` нужен `b + 1`.
