# Звезда 052. Ровно одна ошибка

`almost_equal(a,b)` должна вернуть `True`, если строки одинаковой длины отличаются ровно в одной позиции.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `almost_equal('cat', 'cut')` → `True`
- `almost_equal('cat', 'cat')` → `False`
- `almost_equal('cat', 'dog')` → `False`

> [!tip]- Подсказка 1
> Сначала длины.

> [!tip]- Подсказка 2
> Считай различия; одинаковые строки не подходят.
