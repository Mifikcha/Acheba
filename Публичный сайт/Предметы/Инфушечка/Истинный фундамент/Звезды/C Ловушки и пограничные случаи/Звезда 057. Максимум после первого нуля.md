# Звезда 057. Максимум после первого нуля

Верни максимум элементов после **первого** нуля. Ноль и элементы после него гарантированы.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `max_after_zero([1, 0, 5, 3])` → `5`
- `max_after_zero([2, 0, 4])` → `4`
- `max_after_zero([0, -1])` → `-1`

> [!tip]- Подсказка 1
> `.index(0)` возвращает первый индекс.

> [!tip]- Подсказка 2
> Срез начинай с позиции после него.
