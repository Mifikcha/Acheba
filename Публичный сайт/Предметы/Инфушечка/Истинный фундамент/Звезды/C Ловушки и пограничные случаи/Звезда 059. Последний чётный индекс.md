# Звезда 059. Последний чётный индекс

Верни индекс последнего чётного элемента или `None`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `last_even_index([1, 3, 4, 5])` → `2`
- `last_even_index([2, 4, 6])` → `2`
- `last_even_index([1, 3])` → `None`

> [!tip]- Подсказка 1
> Не возвращай на первом совпадении.

> [!tip]- Подсказка 2
> Каждое совпадение может перезаписать ответ.
