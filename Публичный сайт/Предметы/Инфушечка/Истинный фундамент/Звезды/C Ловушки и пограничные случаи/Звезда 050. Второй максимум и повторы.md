# Звезда 050. Второй максимум и повторы

Для `[9,9,8,7]` второе различное максимальное — 8, не 9.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `second_max([5, 5, 4])` → `4`
- `second_max([1, 3, 2])` → `2`
- `second_max([7, 4])` → `4`

> [!tip]- Подсказка 1
> Обычной сортировки мало.

> [!tip]- Подсказка 2
> Удали повторы перед сортировкой.
