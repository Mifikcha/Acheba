# Звезда 051. Самая частая длина

Верни длину слова, встречающуюся чаще всего. При равенстве — меньшую длину.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `most_common_length(['a', 'bb', 'cc'])` → `2`
- `most_common_length(['one'])` → `3`
- `most_common_length([])` → `None`

> [!tip]- Подсказка 1
> Считай частоты `len(word)`.

> [!tip]- Подсказка 2
> При равной частоте сравни длины.
