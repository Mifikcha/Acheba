# Звезда 049. Все одинаковые

Верни `True`, если все элементы списка одинаковы. Пустой список и список из одного элемента тоже подходят.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `all_same([1, 1, 1])` → `True`
- `all_same([1, 2])` → `False`
- `all_same([])` → `True`

> [!tip]- Подсказка 1
> Не бери `items[0]` без проверки.

> [!tip]- Подсказка 2
> Для длины < 2 ответ сразу `True`.
