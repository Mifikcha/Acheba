# Звезда 045. Сводка по словам

Верни словарь: число слов, число уникальных слов без учёта регистра, самое длинное слово в исходном написании (при равенстве первое).

> [!tip]- Подсказка 1
> Список слов нужен для количества.

> [!tip]- Подсказка 2
> Для уникальности добавляй `.lower()` в множество.
