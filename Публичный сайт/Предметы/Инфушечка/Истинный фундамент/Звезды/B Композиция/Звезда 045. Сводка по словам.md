# Звезда 045. Сводка по словам

Верни словарь: число слов, число уникальных слов без учёта регистра, самое длинное слово в исходном написании (при равенстве первое).

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `word_summary('one two one')` → `{'count': 3, 'unique': 2, 'longest': 'one'}`
- `word_summary('One one TWO')` → `{'count': 3, 'unique': 2, 'longest': 'One'}`
- `word_summary('a bb ccc')` → `{'count': 3, 'unique': 3, 'longest': 'ccc'}`

> [!tip]- Подсказка 1
> Список слов нужен для количества.

> [!tip]- Подсказка 2
> Для уникальности добавляй `.lower()` в множество.
