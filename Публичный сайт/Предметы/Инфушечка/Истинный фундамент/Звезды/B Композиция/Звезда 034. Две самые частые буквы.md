# Звезда 034. Две самые частые буквы

Верни два самых частых символа. При равенстве частоты раньше идёт алфавитно меньший.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `top_two_chars('banana')` → `['a', 'n']`
- `top_two_chars('aabbc')` → `['a', 'b']`
- `top_two_chars('x')` → `['x']`

> [!tip]- Подсказка 1
> Построй словарь частот.

> [!tip]- Подсказка 2
> Сортируй по `(-частота, символ)`.
