# Звезда 040. Общие элементы вручную

Верни общие различающиеся элементы двух списков в порядке первого появления в `a`. Пересечение множеств использовать нельзя.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `common_manual([1, 2], [2, 3])` → `[2]`
- `common_manual(['a'], ['b'])` → `[]`
- `common_manual([], [])` → `[]`

> [!tip]- Подсказка 1
> `set(b)` можно использовать для проверки.

> [!tip]- Подсказка 2
> Отдельно помни уже добавленные элементы.
