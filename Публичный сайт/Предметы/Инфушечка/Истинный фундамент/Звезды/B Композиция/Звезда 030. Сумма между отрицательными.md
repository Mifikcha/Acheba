# Звезда 030. Сумма между отрицательными

В списке минимум два отрицательных. Верни сумму элементов между первым и последним отрицательными, не включая их.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `between_negatives([5, -1, 2, 3, -4, 9])` → `5`
- `between_negatives([-1, -2])` → `0`
- `between_negatives([7, -1, 4, -2, 8])` → `4`

> [!tip]- Подсказка 1
> Найди два индекса.

> [!tip]- Подсказка 2
> Потом просуммируй нужный диапазон.
