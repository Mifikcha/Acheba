# Звезда 031. Рейтинг слов

Верни словарь `слово -> частота`, не учитывая регистр. Пунктуации нет.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `word_rating('aa b ccc')` → `{'aa': 1, 'b': 1, 'ccc': 1}`
- `word_rating('one two')` → `{'one': 1, 'two': 1}`
- `word_rating('')` → `{}`

> [!tip]- Подсказка 1
> Сначала `.lower()`.

> [!tip]- Подсказка 2
> Используй `.get()`.
