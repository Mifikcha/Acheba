# Звезда 021. Сумма чётных цифр

Верни сумму чётных цифр положительного числа.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `even_digit_sum(1234)` → `6`
- `even_digit_sum(135)` → `0`
- `even_digit_sum(802)` → `10`

> [!tip]- Подсказка 1
> Обрабатывай число по цифре.

> [!tip]- Подсказка 2
> Добавляй цифру только если она чётная.
