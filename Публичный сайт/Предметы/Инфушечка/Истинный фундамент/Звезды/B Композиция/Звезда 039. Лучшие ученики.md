# Звезда 039. Лучшие ученики

В словаре `имя -> балл` верни отсортированный список имён с максимальным баллом.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `best_students({'Аня': 5, 'Боря': 4})` → `['Аня']`
- `best_students({'a': 1, 'b': 1})` → `['a', 'b']`
- `best_students({'one': -2, 'two': -5})` → `['one']`

> [!tip]- Подсказка 1
> Сначала максимум значений.

> [!tip]- Подсказка 2
> Потом собери все ключи с ним.
