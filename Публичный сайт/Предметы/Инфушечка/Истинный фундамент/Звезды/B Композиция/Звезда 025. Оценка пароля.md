# Звезда 025. Оценка пароля

Начисли по 1 баллу за: длина ≥ 8, есть цифра, есть заглавная буква, нет пробелов. Верни 0–4.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `password_score('abc')` → `1`
- `password_score('aB3!')` → `3`
- `password_score('12345')` → `2`

> [!tip]- Подсказка 1
> Заведи логические флаги.

> [!tip]- Подсказка 2
> Пройди пароль один раз.
