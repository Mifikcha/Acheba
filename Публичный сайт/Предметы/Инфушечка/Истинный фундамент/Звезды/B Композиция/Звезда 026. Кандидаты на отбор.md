# Звезда 026. Кандидаты на отбор

Из списка баллов верни результаты не ниже `border`, без повторов, по убыванию.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `selected([40, 75, 90], 70)` → `[90, 75]`
- `selected([1, 2], 5)` → `[]`
- `selected([5, 5, 6], 5)` → `[6, 5]`

> [!tip]- Подсказка 1
> Сначала отфильтруй.

> [!tip]- Подсказка 2
> Потом `set` и сортировка.
