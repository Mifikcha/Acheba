# Звезда 044. Удалить каждое третье

Верни строку без каждого третьего символа, считая позиции с единицы.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `remove_each_third('abcdef')` → `'abde'`
- `remove_each_third('ab')` → `'ab'`
- `remove_each_third('123456789')` → `'124578'`

> [!tip]- Подсказка 1
> Индекс Python на 1 меньше позиции.

> [!tip]- Подсказка 2
> Проверяй `(i + 1) % 3`.
