# Звезда 028. Цифры без повторов

Из числа верни строку цифр, оставляя каждую только при первом появлении слева направо. `11234321 -> 1234`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `unique_digits_in_order(112233)` → `'123'`
- `unique_digits_in_order(9879)` → `'987'`
- `unique_digits_in_order(0)` → `'0'`

> [!tip]- Подсказка 1
> Нужно помнить уже встреченные цифры.

> [!tip]- Подсказка 2
> Порядок сохраняй строкой, проверку — множеством.
