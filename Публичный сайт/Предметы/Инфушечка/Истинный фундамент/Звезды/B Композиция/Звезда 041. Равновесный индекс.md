# Звезда 041. Равновесный индекс

Верни первый индекс, где сумма слева равна сумме справа; сам элемент не считать. Если нет — `None`.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `balance_index([1, 2, 3, 3])` → `2`
- `balance_index([1, 2, 3])` → `None`
- `balance_index([0])` → `0`

> [!tip]- Подсказка 1
> Для начала разрешено считать суммы заново для каждого индекса.

> [!tip]- Подсказка 2
> Правильность важнее оптимизации.
