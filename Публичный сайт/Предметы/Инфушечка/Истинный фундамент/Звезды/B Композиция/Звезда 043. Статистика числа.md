# Звезда 043. Статистика числа

Верни словарь: количество цифр, сумма, максимум, количество чётных. Разрешена строка.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `number_stats(1203)` → `{'digits': 4, 'sum': 6, 'max': 3, 'even': 2}`
- `number_stats(7)` → `{'digits': 1, 'sum': 7, 'max': 7, 'even': 0}`
- `number_stats(1000)` → `{'digits': 4, 'sum': 1, 'max': 1, 'even': 3}`

> [!tip]- Подсказка 1
> Все показатели обновляй в одном цикле.

> [!tip]- Подсказка 2
> Начальные значения продумай заранее.
