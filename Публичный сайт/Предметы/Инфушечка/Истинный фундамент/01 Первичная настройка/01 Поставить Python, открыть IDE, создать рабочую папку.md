# IDE

IDE - это среда, где вы будете прогать. Можно сказать, обертка вашего взаимодействия с командной строкой. Итак, варианты:

* Без IDE (cmd или powershell для Windows, аналоги для прочих систем)
* IDLE, стандартная среда выполнения Питон (этот вариант, скорее всего, вы будете видеть в школе чаще всего)
* VS Code, самый частый выбор в мире среди прогеров
* PyCharm и иные (теоретически, PyCharm есть на экзамене как среда, но, я думаю, не надолго)

В целом, вам рекомендую тренироваться в школе на IDLE (потому, что у вас нет выбора), а дома поставить VS Code или также продолжать на IDLE. Именно эти варианты мы и возьмем как основные, настройка для дальнейшей работы будет производится там.

> [!note]
Код никак не будет отличаться от среды к среде, будет отличаться именно удобство использования и интерфейс в целом.

# Создание рабочей папки и базовое управление

> [!tip] Совет
> Запоминаете что и как вы делаете в этом разделе, поскольку на экзамене вам придется создавать папки заново и настраивать рабочую среду под себя.

## Папка в IDLE

К сожалению, в IDLE нет такой концепции как "рабочая среда" или "проект" аналогично VS Code и другим IDE. Это налагает некоторые ограничения. Например, вы не сможете сделать вот так:

```python
open('file_name.txt')
```

В случае IDLE, обычно нужно указывать полный путь до файла, что часто неудобно. Но все же, есть хитрость.

* По дефолту IDLE открывается в вашей папке пользователя. Например: `C:\Users\Сергей`. Соответственно, все программы, файлы и прочее должны лежать там, если вы не хотите открывать его в другой папке.
* Если же вам хочется открыть IDLE в другой папке, то можно сделать вот как: открываете cmd, вводите туда `cd {путь до вашей папки}`, а далее `python -m idlelib`. IDLE будет считать эту папку рабочей и будет видеть файлы оттуда.

Также, в IDLE нет понятия "плагин". IDLE такой какой он есть, его нельзя как-то настроить под себя.

Чтобы начать писать программу в IDLE вам нужно тыкнуть следующее:

```
file --> new file --> [пишите программу] --> save --> [выбираете свою рабочую папку] --> f5 (запустить код)
```

## Папка в VS Code и плагины

### Рабочая папка

Первый раз, когда вы откроете VS Code вы увидите что-то вот такое:

![[Pasted image 20260822155310.png]]
