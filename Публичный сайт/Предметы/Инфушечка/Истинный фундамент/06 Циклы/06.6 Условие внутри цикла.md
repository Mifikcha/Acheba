# Условие внутри цикла

Внутри цикла можно использовать `if`.

```python
text = "banana"
count = 0
i = 0

while i < len(text):
    if text[i] == "a":
        count += 1
    i += 1

print(count)  # 3
```

Так решают задачи, где надо пройти по всем символам, но учитывать только подходящие.

Если `if` внутри `while` выглядит слишком плотным, повтори [[05.8 Условие if]].

### Задачи

1. Посчитай буквы `a` в строке.
2. Посчитай цифры `5` в строке.
3. Посчитай символ без учета регистра: `E` и `e` считаются одинаковыми.

### Мини-проверка

```python
text = "AaA"
count = 0
i = 0
while i < len(text):
    if text[i].lower() == "a":
        count += 1
    i += 1

print(count)
```

> [!tip]- Ответ
> Будет `3`.
