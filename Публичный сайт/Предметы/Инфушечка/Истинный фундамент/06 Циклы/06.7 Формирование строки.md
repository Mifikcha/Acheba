# Формирование строки

Цикл может не печатать, а собирать новую строку и вернуть её.

```python
def reverse_string(text):
    result = ""
    i = len(text) - 1

    while i >= 0:
        result = result + text[i]
        i -= 1

    return result
```

Смысл простой: берем символы с конца и по одному добавляем в новую строку.

Если не помнишь, чем `return` отличается от `print`, смотри [[04.10 Возврат значения]].

### Задачи

1. Переверни строку.
2. Верни первые `length` символов строки без срезов.
3. Удали из строки все пробелы, собирая новую строку.

### Предскажи вывод

```python
print(reverse_string("abc"))
```

> [!tip]- Ответ
> Будет `cba`.
