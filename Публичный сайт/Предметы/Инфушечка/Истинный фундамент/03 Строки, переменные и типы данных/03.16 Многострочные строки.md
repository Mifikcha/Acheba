# Многострочные строки

Если строка большая и в ней много переносов, можно использовать тройные кавычки.

```python
text = """первая
вторая
третья"""

print(text)
```

Это обычная строка, просто записанная в несколько строк кода.

Тройные кавычки удобны для длинного текста, шаблонов и заготовок вывода.

### Задачи

1. Создай строку из двух строк текста через `"""`.
2. Создай многострочную f-строку с переменной `name`.
3. Проверь, появляется ли лишняя пустая строка, если закрывающие кавычки поставить на новой строке.

### Мини-проверка

Напиши программу, которая выводит:

```text
Python
строки
готово
```

> [!tip]- Ответ
> ```python
> text = """Python
> строки
> готово"""
> print(text)
> ```
