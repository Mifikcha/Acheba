# Имена переменных

Компьютеру почти все равно, как назвать переменную. Человеку — нет.

Плохо:

```python
x = 100
```

Лучше:

```python
user_score = 100
```

В Python для обычных переменных используют `snake_case`: маленькие английские слова через `_`.

```python
first_number = 20
last_digit = 7
```

### Задачи

1. Придумай имя для переменной «последняя цифра числа».
2. Создай `first_number = 20` и `second_number = -100`, выведи произведение.
3. Исправь плохое имя `x`, если в нем лежит возраст ученика.

### Предскажи вывод

```python
name = "Tom"
Name = "Ann"
print(name)
print(Name)
```

> [!tip]- Ответ
> Будет `Tom`, потом `Ann`. Регистр важен: `name` и `Name` — разные имена.
