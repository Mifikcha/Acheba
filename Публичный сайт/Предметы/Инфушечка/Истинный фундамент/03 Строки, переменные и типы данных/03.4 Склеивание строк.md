# Склеивание строк

Строки можно складывать через `+`. Это называется конкатенация.

```python
print("Py" + "thon")
```

Пробел сам не появляется:

```python
print("Python" + "lesson")   # Pythonlesson
print("Python " + "lesson")  # Python lesson
```

Знак `+` умеет и складывать числа, и склеивать строки. Если это путается, смотри [[Типы данных]].

### Задачи

1. Склей `Инфор` и `матика`.
2. Склей `ЕГЭ`, пробел и `2026`.
3. Одним `print` выведи `a+b=c`, используя склеивание строк.

### Предскажи вывод

```python
print("2" + "2")
print(2 + 2)
```

> [!tip]- Ответ
> Первая строка: `22`. Вторая строка: `4`.
