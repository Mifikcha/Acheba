# Переменные и строки

Если в переменных лежат строки, их тоже можно склеивать:

```python
first = "Py"
second = "thon"

print(first + second)
```

Пробел, запятая и перенос строки — обычные части текста. Их нужно добавить явно.

```python
name = "Аня"
print("Привет, " + name)
```

### Задачи

1. Создай `a = "Инфор"` и `b = "матика"`, выведи склеенную строку.
2. Создай `name = "Миша"`, выведи `Привет, Миша`.
3. Двумя переменными и `\n` выведи две строки.

### Предскажи вывод

```python
x = "2"
y = "3"
print(x + y)
```

> [!tip]- Ответ
> Будет `23`, потому что `x` и `y` — строки. Подробнее: [[Типы данных]].
