# Вызов функции как выражение

Вызов функции возвращает результат. Значит, его можно использовать в выражении.

```python
word = "Python"
last_index = len(word) - 1
print(last_index)
```

`len(word)` сначала превратится в `6`, потом выполнится `6 - 1`.

Можно писать сразу:

```python
print(len("Python") - 1)
```

Если выражения в переменных забылись, смотри [[03.9 Выражения в переменных]].

### Задачи

1. Для `word = "Информатика"` выведи индекс последнего символа.
2. Выведи последний символ строки через `word[len(word) - 1]`.
3. Выведи `len("abc") + len("de")`.

### Предскажи вывод

```python
s = "abcd"
print(s[len(s) - 1])
```

> [!tip]- Ответ
> Будет `d`.
