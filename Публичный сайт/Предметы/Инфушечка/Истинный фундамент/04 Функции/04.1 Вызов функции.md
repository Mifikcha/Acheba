# Вызов функции

Функция — готовое действие с именем.

```python
print("Привет")
```

`print` выводит на экран. Скобки означают: функцию вызывают.

Еще одна полезная функция:

```python
print(len("Python"))  # 6
```

`len` считает длину строки. Внутрь скобок передаем значение, с которым функция работает.

Если путаешь, почему `"Python"` — строка, вернись к [[03.1 Строка это текст]].

### Задачи

1. Выведи длину строки `Информатика`.
2. Выведи сумму длин строк `ЕГЭ` и `Python`.
3. Выведи `len("2 + 2")`, а потом `2 + 2`.

### Предскажи вывод

```python
print(len("ЕГЭ"))
print("ЕГЭ")
```

> [!tip]- Ответ
> Сначала будет `3`, потом `ЕГЭ`.
