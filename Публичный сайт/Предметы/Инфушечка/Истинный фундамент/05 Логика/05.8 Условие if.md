# Условие if

`if` запускает блок кода только при истинном условии.

```python
def get_sentence_type(sentence):
    if sentence[-1] == "?":
        return "question"
    return "normal"
```

После условия ставится двоеточие. Внутренний блок пишется с отступом.

`return` внутри `if` сразу завершает функцию.

Если отступы путаются, смотри [[04.9 Создание функции]]: тело функции работает по тем же правилам отступов.

### Задачи

1. Если число равно `0`, верни строку `zero`.
2. Если строка заканчивается `?`, верни `question`.
3. Если возраст больше или равен `18`, верни `adult`.

### Предскажи вывод

```python
def f(x):
    if x > 0:
        return "plus"
    return "not plus"

print(f(3))
```

> [!tip]- Ответ
> Будет `plus`.
