# Оператор and

`and` означает «и».

```python
age = 20
print(age >= 18 and age < 60)
```

Все условие истинно только тогда, когда истинны обе части.

| A | B | A and B |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

Скобки помогают читать сложные условия:

```python
number > 10 and (number % 2 == 0)
```

### Задачи

1. Проверь, что число положительное и четное.
2. Проверь, что строка длиннее 5 символов и начинается с `A`.
3. Проверь, что последняя цифра числа равна 5 и число больше 100.

### Предскажи вывод

```python
print(True and True)
print(True and False)
```

> [!tip]- Ответ
> `True`, потом `False`.
