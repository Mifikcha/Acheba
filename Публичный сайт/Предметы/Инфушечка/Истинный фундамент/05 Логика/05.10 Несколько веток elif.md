# Несколько веток elif

`elif` означает «иначе если».

```python
def sentence_type(sentence):
    last = sentence[-1]

    if last == "?":
        return "question"
    elif last == "!":
        return "exclamation"
    else:
        return "normal"
```

В такой конструкции выполнится только одна ветка.

Это удобно, когда вариантов больше двух: друг, враг, нейтральный; маленькое, нормальное, большое; вопрос, восклицание, обычное предложение.

### Задачи

1. Верни `negative`, `zero` или `positive` для числа.
2. Верни тип предложения: `question`, `exclamation`, `normal`.
3. Верни статус дома: `friend`, `enemy`, `neutral`.

### Мини-проверка

```python
def sign(x):
    if x < 0:
        return "negative"
    elif x == 0:
        return "zero"
    else:
        return "positive"

print(sign(0))
```

> [!tip]- Ответ
> Будет `zero`.
