# План миграции курса информатики

Никаких удалений на первом проходе. Все действия ниже являются планом после согласования архитектуры.

## Статус после согласования

Первый фактический этап выполнен только внутри `Публичный сайт`:

- создан [[Маршруты подготовки|публичный план курса]] с маршрутами минимальный маршрут / обычный маршрут / сильный маршрут;
- создан [[Предметы/Инфушечка/Фундамент/index|фундаментальный слой]] с недостающими срочно-темами;
- создан [[За пределами ЕГЭ]] для тем неосновной траектории;
- создана страница [[Контрольные точки]];
- заглушки [[№26 Сложна 1]] и [[№27 Сложна 2]] теперь ведут в advanced-track.

Старые материалы не удалялись и не переименовывались.

## Что сделать после согласования

1. Создать новые фундаментальные модули после `старый справочник Питона`: списки, файлы, алгоритмические шаблоны.
2. Переписать публичный план курса простыми блоками для ученика/родителя.
3. Для ключевых заданий ввести структуру Worked Example / Guided Practice / Independent Practice.
4. Обновить офисные материалы под Либраофис и форматы ЕГЭ-2026.
5. Только после этого переименовывать или объединять файлы, предварительно построив карту ссылок.
