# Аудит текущего курса информатики

Первый проход без массового переписывания. Проверены публичные материалы старого справочника и [[Предметы/Инфушечка/Разбор задач/index|Разбор задач]]: 72 урока старый справочник Питона, служебная заметка «Где взять, брат» и 25 разборов ЕГЭ.

Официальная опора по формату: страница ФИПИ «Демоверсии, спецификации, кодификаторы ЕГЭ 2026», архив `inf_11_2026.zip` и опубликованные проекты изменений ЕГЭ-2027. В архиве 2026 дополнительные файлы идут как `DEMO_3.ods`, `DEMO_9.ods`, `DEMO_17.txt`, `DEMO_18.ods`, `DEMO_22.ods`, `DEMO_24.txt`, `DEMO_26.txt`, `DEMO_27_A.txt`, `DEMO_27_B.txt`; в проекте 2027 старая тема №10 про текстовый процессор заменена на IP-адреса и маски подсети.

## Главный диагноз

Сейчас это два почти отдельных продукта:

| Слой | Что есть | Сильная сторона | Главная проблема |
|---|---|---|---|
| старый справочник Питона | Микроуроки от `print` до `for/range` | Последовательный вход в синтаксис, много маленьких шагов | Заканчивается до списков, файлов, сортировок, алгоритмических шаблонов |
| Разбор задач | Разборы заданий ЕГЭ 1-27, кроме пустых 26/27 | Живой голос, много конкретных примеров, реальные приемы | Часто справочник решений, а не обучающая траектория |
| Публичный сайт | `Разбор задач` уже опубликован, `старый справочник Питона` отсутствовал | Quartz/Obsidian готовы к графу ссылок | Питон не был доступен на сайте и не был связан с ЕГЭ-разборами |

## Аудит старый справочник Питона по блокам

| Блок | Категория | Темы | Полезность для ЕГЭ | Что не так | Решение |
|---|---|---|---|---|---|
| `1) Основы` | CORE | Hello World, комментарии, инструкции, синтаксические ошибки | Нужен как старт для нулевого ученика | Слишком общий вход, нет привязки к экзаменационной среде | Оставить, объединить в модуль «Питон: минимальный старт», добавить цель и мини-проверку |
| `2) Арифметика в Питон` | CORE/SUPPORTING | операции, приоритет, float, коммутативность, композиция, линтер | Нужны `+ - * / // % **`, приоритет, остатки | Коммутативность/композиция/линтер раздуты для ЕГЭ | Свернуть часть в врезки; усилить `//`, `%`, разбор числа по цифрам |
| `3) Строки` | CORE | кавычки, escaping, конкатенация, кодировка | База для 10, 12, 24 | Нет экзаменационных строковых паттернов | Объединить базу строк и связать с поиском/заменой/подсчетом |
| `4) Переменные` | CORE/SUPPORTING | создание, изменение, имена, ошибки, константы, магические числа | Нужны для любого кода | Много отдельных уроков про стиль, мало задач ЕГЭ | Собрать в 1-2 урока; стиль оставить как короткие правила |
| `5) Еще немного строк` | CORE | интерполяция, индексация, срезы, multiline | Индексы и срезы нужны для 12/24 | Хорошие темы, но нет перехода к строковым алгоритмам | Оставить и расширить задачами на цепочки символов |
| `6) Типы данных` | CORE/SUPPORTING | типы, строгая типизация, неизменяемость, преобразования | `int`, `str` критичны; остальное поддерживающее | Нет полноценного `input()`-потока | Сфокусировать на вводе/преобразовании/ошибках типов |
| `7) Вызов функции` | SUPPORTING | вызов, сигнатура, аргументы, стандартная библиотека | Полезно для `len/min/max/sum/open/range` | Сигнатуры и variadic args перегружены | Свернуть продвинутые детали, дать стандартные функции ЕГЭ |
| `8) Свойства и методы` | SUPPORTING | объекты, методы, цепочки вызовов | Нужно для `.split()`, `.count()`, `.replace()`, строк | Изложено как общий Питон, не как инструмент ЕГЭ | Оставить как мост к строковым и файловым задачам |
| `9) Определение функций` | SUPPORTING/OPTIONAL | `def`, return, параметры, аннотации | Нужно для 15, 16, 23, иногда 25/27 | Аннотации и именованные аргументы не основной маршрут | Базовые функции оставить, аннотации/именованные аргументы вынести в optional |
| `10) Логика` | CORE | `bool`, предикаты, `and/or/not`, результат выражений | Критично для 2, 5, 15, фильтрации данных | Хороший блок, но без явной матрицы заданий | Оставить, добавить таблицы истинности и ЕГЭ-примеры |
| `11) Условные конструкции` | CORE/OPTIONAL | `if`, `else`, `elif`, ternary, `match` | `if/elif/else` критичны | ternary и `match` не нужны в основной траектории | `if/elif/else` оставить; ternary/match в optional |
| `12) Циклы` | CORE | `while`, агрегация, обход строк, `for`, `range` | Ключ к 5, 8, 12, 14, 15, 17, 23-27 | Нет списков, файлов, вложенных циклов, больших данных | Оставить как базу, затем добавить новые модули после него |

## Аудит разборов ЕГЭ

| Задания | Состояние | Полезность | Что не так | Решение |
|---|---|---|---|---|
| 1-4 | Есть рабочие разборы, много картинок | Хороший стартовый справочник | Местами начинается с примера, а не с типа задачи | Добавить верхний слой «что проверяет / прототипы / алгоритм» |
| 5-6 | Есть кодовые и геометрические приемы | Хорошо связывается с циклами и условиями | Нужны предварительные знания по перебору и исполнителям | Связать с ядро Питона и отдельным модулем исполнителей |
| 7-11 | Есть формулы и табличные приемы | Полезно для первых баллов | №10 теперь IP-адреса; 3/9 в `.ods` | Добавить «Инструменты экзамена» и Либраофис callout |
| 12-15 | Много программирования и логики | Сильный материал по примерам | Не хватает системного слоя паттернов | Вынести повторяющиеся шаблоны в фундамент |
| 16, 19-21, 23 | Есть рекурсия/игры/число программ | Хорошая база для отдельных модулей | Не везде разделены ручные и программные стратегии | Развести «учим тему» и «как решать на экзамене» |
| 17, 24, 25 | Много кода и файловых задач | Ценные живые разборы | Питон Base не готовит к спискам, файлам, большим строкам | Перед ними поставить списки, файлы, окна, поиск, делители |
| 18, 22 | Есть табличные/оптимизационные задачи | Нужны для `.ods` и алгоритмического мышления | Основной путь пока Эксель, не таблицы | Обновить под Либраофис Таблицы |
| 26-27 | Фактически пустые заглушки | Признают пробел | Нет прототипов, алгоритмов, асимптотики | Спроектировать сложные задания ЕГЭ до написания решений |

## Критические пробелы Питон

| Навык | Статус в текущей базе | Приоритет | Комментарий |
|---|---|---:|---|
| `input()`, чтение пользовательского ввода | Почти нет | важно | Нужно для базовой автономии ученика |
| Списки: создание, индексация, изменение, `append` | Нет полноценного блока | срочно | Блокирует 17, 24, 25, 26, 27 |
| `len`, `min`, `max`, `sum`, `count` на последовательностях | Частично и рассыпано | срочно | Нужны как стандартные инструменты |
| Файлы: `open`, `with`, `readline`, `readlines`, `split`, `map` | Нет в Питон Base | срочно | Блокирует задания с `.txt` |
| Поиск, счетчики, накопление, максимум/минимум | Частично в циклах | срочно | Нужно оформить как переносимые шаблоны |
| Вложенные циклы | Нет отдельного блока | важно | Нужно для перебора, логики, 15, 26/27 |
| Сортировка `sort/sorted` | Нет | срочно | Критично для 26 и части 27 |
| Системы счисления | Есть отдельная теория, не в Питон Base | важно | Нужна связка с 5, 8, 14 |
| `itertools` | Нет в базе, используется в разборах | важно | Давать как инструмент, не как магию |
| ДП/оптимальные алгоритмы | Нет | срочно для сильного маршрута | Нужно перед 27 |

## Признаки заимствованности

Многие уроки Питон содержат прямые ссылки на Code Basics/Hexlet/Replit и выглядят как адаптированный внешний учебный материал. Для публичного курса это не надо «слегка перефразировать». Правильная миграция: извлечь знания, написать собственные уроки под ЕГЭ, оставить источники в references там, где они нужны.

## Первый вывод

Сильное ядро уже есть: живые разборы, много примеров, понятный стиль. Слабое место не в количестве файлов, а в архитектуре: Питон не доводит ученика до тех инструментов, которые разборы уже требуют.
