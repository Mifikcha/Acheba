# За пределами ЕГЭ

Это не мусорная корзина, а полка «полезно, но не в основной траектории ЕГЭ». Сюда попадают темы, которые развивают программиста, но редко дают прямой прирост баллов.

## Необязательные темы

| Тема                                   | Почему не в основной маршрут                                     |
| -------------------------------------- | ---------------------------------------------------------------- |
| Проверка стиля кода                    | полезно для аккуратности, но не является экзаменационным навыком |
| Многострочные строки                   | можно пройти после базовых строк                                 |
| Строгая типизация                      | поддерживающая теория                                            |
| Неизменяемость простых типов           | полезно, но не блокирует ЕГЭ                                     |
| Сигнатура функции                      | полезно для общей грамотности                                    |
| Аргументы по умолчанию                 | не нужны для большинства решений                                 |
| Функции с переменным числом параметров | продвинутый синтаксис                                            |
| Детерминированность                    | хорошая идея, но не отдельный экзаменационный урок               |
| Необязательные параметры функций       | продвинутый синтаксис                                            |
| Именованные аргументы                  | не обязательны для ЕГЭ                                           |
| Аннотации типов                        | полезны в разработке, но не на экзамене                          |
| Тернарный оператор                     | сокращенная запись условия                                       |
| Сопоставление с образцом               | не нужно для основной траектории                                 |

## Как пользоваться

Если ученик уверенно идет по [[Маршруты подготовки|обычному]] или [[Маршруты подготовки|сильному]] маршруту, эти темы можно давать как расширение. Если цель — быстро набрать баллы, их спокойно пропускаем.
