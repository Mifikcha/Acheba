# Задание 27. Сложные алгоритмы

Связанные темы: [[Предметы/Инфушечка/Истинный фундамент/02 Минимальный Python/02.1 Первая программа|минимальный Питон]], [[06 Списки и последовательности|списки и последовательности]], [[07 Файлы TXT в Python|текстовые файлы]], [[10 Алгоритмические паттерны|алгоритмические шаблоны]], [[№27 Сложна 2]].

Задание 27 проверяет не умение написать длинный код, а умение заменить прямой перебор более умной идеей. Обычно есть два файла: маленький для проверки мысли и большой для настоящего ответа.

## Что должно быть готово

- читать файл и превращать строки в числа;
- проверять решение на маленьком наборе;
- оценивать, сколько действий делает программа;
- хранить лучший ответ на текущем шаге;
- использовать остатки, префиксные суммы, окно или таблицу состояний.

## Типовой порядок решения

1. Сначала решить маленький файл прямым перебором.
2. Убедиться, что ответ совпал с ожидаемым.
3. Найти, что именно повторяется в переборе.
4. Сохранить нужную часть прошлого состояния: минимум, максимум, количество, остаток или сумму.
5. Написать быстрое решение.
6. Снова проверить его на маленьком файле.
7. Только после этого запускать большой файл.

## Частые приемы

| Прием | Что дает |
|---|---|
| Остатки от деления | быстро проверять кратность суммы или произведения |
| Префиксные суммы | быстро считать сумму отрезка |
| Скользящее окно | двигать границы подходящего участка |
| Таблица состояний | хранить лучший вариант для каждого остатка или признака |
| Однопроходное решение | читать данные один раз и сразу обновлять ответ |

## Мини-задачи перед разбором

1. Дан список чисел. Найди максимальную сумму пары, кратную `3`.
2. Дан список чисел. Найди минимальную сумму пары с разными остатками при делении на `5`.
3. Дан список положительных чисел. Найди самый длинный участок с суммой не больше `100`.
4. Дан список чисел. Для каждого остатка при делении на `7` сохрани минимальное число с таким остатком.
5. Дан список чисел. Придумай, какие данные надо хранить, чтобы не проверять все пары.

После этого переходи к [[№27 Сложна 2|конкретным разборам задания 27]].
