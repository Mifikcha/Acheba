# Делители и маски 25

## Что проверяет модуль

Умение перебрать числа, проверить маску, найти делители, работать с простотой и не запускать лишний миллиард операций.

## Prerequisites

- `%` и `//`;
- циклы;
- функции;
- строки для проверки маски.

## Поиск делителей до корня

```python
def divisors(n):
    result = []
    for d in range(2, int(n**0.5) + 1):
        if n % d == 0:
            result.append(d)
            if d != n // d:
                result.append(n // d)
    return result
```

## Проверка простоты

```python
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, int(n**0.5) + 1):
        if n % d == 0:
            return False
    return True
```

from fnmatch import fnmatch
