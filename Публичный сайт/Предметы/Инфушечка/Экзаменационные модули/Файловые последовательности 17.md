# Файловые последовательности 17

## Что проверяет модуль

Чтение списка чисел из `.txt` и обработка соседних элементов: пары, тройки, минимум/максимум, количество подходящих фрагментов.

## Prerequisites

- [[06 Списки и последовательности|списки и последовательности]]
- [[07 Файлы TXT в Python|текстовые файлы]]
- [[10 Алгоритмические паттерны|алгоритмические шаблоны]]

## Базовый шаблон

```python
with open("17.txt") as file:
    nums = [int(line) for line in file]

count = 0
best = -10**20

for i in range(1, len(nums)):
    a = nums[i - 1]
    b = nums[i]
    if a % 16 == 0 or b % 16 == 0:
        count += 1
        best = max(best, a + b)

print(count, best)
```

## Прототипы

| Прототип | Что меняется |
|---|---|
| Пары соседей | условие на `a` и `b` |
| Тройки соседей | цикл начинается с `2` |
| Условие через минимум/максимум файла | сначала считаем `min(nums)` или `max(nums)` |
| Условие на количество цифр | добавляем функцию проверки |

## Guided Practice

Файл содержит числа. Найди количество соседних пар, где хотя бы одно число кратно минимальному элементу файла.

## Independent Practice

Файл содержит числа. Найди максимальную сумму соседней пары, в которой ровно одно число оканчивается на 7.
