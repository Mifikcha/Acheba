# Файловые строки 24

## Что проверяет модуль

Чтение длинной строки из `.txt` и поиск максимального фрагмента по правилу: цепочка символов, количество подстрок, запретная комбинация, окно.

## Prerequisites

- [[05 Строки для ЕГЭ|строки]]
- [[07 Файлы TXT в Python|текстовые файлы]]
- [[10 Алгоритмические паттерны|алгоритмические шаблоны]]

## Базовый шаблон

```python
with open("24.txt") as file:
    s = file.readline().strip()

best = 0
current = 0

for ch in s:
    if ch == "A":
        current += 1
        best = max(best, current)
    else:
        current = 0

print(best)
```

## Прототипы

| Прототип | Подход |
|---|---|
| Максимальная цепочка одного типа | счетчик текущей длины |
| Запретная подстрока | `replace`, разбиение или окно |
| Ограничение на количество фрагментов | скользящее окно |
| Сумма длин сегментов | список длин + префиксные суммы |

## Guided Practice

Дана строка из букв `A`, `B`, `C`. Найди максимальную длину фрагмента, где нет двух букв `C` подряд.

## Independent Practice

Файл содержит строку. Найди максимальную длину подстроки, где буква `A` встречается не более трех раз.
