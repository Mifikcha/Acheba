# Контрольные точки курса информатики

Контрольная точка не дает новых знаний. Она проверяет, переносится ли навык на короткие задачи.

## Checkpoint 1. Базовый синтаксис

После: [[Предметы/Инфушечка/Истинный фундамент/02 Минимальный Python/02.1 Первая программа|Истинный фундамент]].

Задачи:

1. Ввести два числа и вывести большее.
2. Ввести число и вывести его последнюю цифру.
3. Посчитать сумму чисел от 1 до `n`.
4. Найти количество трехзначных чисел, делящихся на 9.
5. Перевести строку `"123"` в число и прибавить 7.

Готовность: ученик пишет решения без подсказок по синтаксису.

## Checkpoint 2. Условия

После: [[03 Условия и логика для перебора]].

Задачи:

1. Посчитать числа от 1 до 1000, которые делятся на 7 и не делятся на 5.
2. Проверить, оканчивается ли число на 3 или на 7.
3. Переписать условие «не A и B» на Питон.
4. Найти числа, для которых выполняются три условия одновременно.
5. Объяснить разницу между `and` и `or` на примере.

Готовность: ученик сам переводит русский текст условия в `if`.

## Checkpoint 3. Циклы

После: [[04 Циклы и перебор]].

Задачи:

1. Найти сумму всех чисел от 1 до 100.
2. Найти максимальное число от 1 до 1000, кратное 37.
3. Посчитать пары `(a, b)`, где `a + b = 50`.
4. Перебрать цифру `x` от 0 до 9 и проверить условие.
5. Написать цикл `while`, который разбирает число по цифрам.

Готовность: ученик не путает границы `range`.

## Checkpoint 4. Строки

После: [[05 Строки для ЕГЭ|строки]].

Задачи:

1. Посчитать количество букв `A` в строке.
2. Найти максимальную длину цепочки из `B`.
3. Проверить, начинается ли строка с `AB`.
4. Заменить все `111` на `2`.
5. Найти количество вхождений подстроки `ABC`.

Готовность: ученик уверенно использует индексы, срезы и методы строк.

## Checkpoint 5. Списки

После: [[06 Списки и последовательности|списки и последовательности]].

Задачи:

1. Найти максимум списка.
2. Посчитать четные элементы.
3. Найти максимальную сумму соседней пары.
4. Найти количество троек, где сумма делится на 5.
5. Создать список подходящих чисел через `append`.

Готовность: ученик не выходит за границы списка.

## Checkpoint 6. Файлы

После: [[07 Файлы TXT в Python|текстовые файлы]].

Задачи:

1. Прочитать числа по строкам.
2. Прочитать одну длинную строку.
3. Прочитать первую строку как `n`, остальные как данные.
4. Разбить строку чисел через `.split`.
5. Переписать абсолютный путь в относительный.

Готовность: ученик может начать задания 17/24/26/27 без борьбы с файлом.

## Checkpoint 7. Алгоритмы

После: [[10 Алгоритмические паттерны|алгоритмические шаблоны]].

Задачи:

1. Решить задачу на счетчик.
2. Решить задачу на максимум по условию.
3. Решить задачу на пары соседей.
4. Решить задачу на сортировку и лимит.
5. Решить задачу на окно или префиксные суммы.

Готовность: ученик узнает паттерн до написания кода.
