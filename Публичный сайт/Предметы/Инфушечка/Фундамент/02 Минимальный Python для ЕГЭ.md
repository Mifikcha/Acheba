# Минимальный Питон для ЕГЭ

## Зачем это нужно

Для ЕГЭ не нужно становиться профессиональным Питон-разработчиком. Нужно уверенно писать короткие программы, которые перебирают варианты, проверяют условия и считают ответ.

## После урока ты умеешь

- запускать программу;
- использовать переменные;
- печатать результат через `print`;
- вводить данные через `input`;
- превращать строки в числа через `int`;
- использовать `//` и `%` для делимости и цифр числа.

## Минимальный набор

```python
a = int(input())
b = int(input())

print(a + b)
print(a * b)
print(a % b)
print(a // b)
```

Самые важные операции для экзамена:

| Операция | Что делает | Где всплывает |
|---|---|---|
| `+`, `-`, `*` | обычная арифметика | почти везде |
| `//` | целая часть деления | цифры числа, системы счисления |
| `%` | остаток от деления | делимость, последняя цифра, перевод систем |
| `**` | степень | 7, 8, 11, 14 |

## Разбор числа по цифрам

```python
n = 12345

while n > 0:
    digit = n % 10
    print(digit)
    n //= 10
```

Здесь `% 10` берет последнюю цифру, а `// 10` отрезает ее.

## Попробуй сам

Посчитай, сколько чисел от 100 до 999 оканчиваются на 7 и делятся на 3.
