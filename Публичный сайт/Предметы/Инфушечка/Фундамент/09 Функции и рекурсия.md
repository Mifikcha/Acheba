# Функции и рекурсия

## Зачем это нужно

Функции позволяют вынести проверку условия или рекурсивное правило в отдельный блок. В ЕГЭ это особенно полезно в заданиях 15, 16, 19-21 и 23.

## После урока ты умеешь

- писать функцию через `def`;
- возвращать значение через `return`;
- читать простую рекурсию;
- видеть базовый случай;
- не путать обучающий порядок и стратегию экзамена.

## Функция-проверка

```python
def ok(x, a):
    return x % a == 0 or x > 100

for a in range(1, 100):
    good = True
    for x in range(1, 300):
        if not ok(x, a):
            good = False
    if good:
        print(a)
        break
```

## Простая рекурсия

```python
def f(n):
    if n <= 1:
        return 1
    return n * f(n - 1)

print(f(5))
```

`if n <= 1` — базовый случай. Без него функция будет вызывать сама себя бесконечно.

## Теория игр

В играх рекурсия отвечает на вопрос: «из этой позиции можно гарантированно выиграть или нет?»

```python
def win(s):
    if s >= 129:
        return True
    moves = [s + 1, s * 2]
    return any(not win(m) for m in moves)
```

Это не готовая универсальная заготовка для всех игр, а идея: позиция выигрышная, если есть ход в проигрышную позицию соперника.
