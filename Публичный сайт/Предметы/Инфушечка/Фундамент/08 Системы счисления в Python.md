# Системы счисления в Питон

## Зачем это нужно

Системы счисления в ЕГЭ часто выглядят как теория, но Питон полезен там, где нужно перебрать цифру, проверить делимость или посчитать количество нулей/единиц.

## После урока ты умеешь

- переводить число через `bin`, `oct`, `hex`;
- использовать `int(s, base)`;
- разбирать число остатками;
- перебирать цифры неизвестного основания;
- связывать системы счисления с заданиями 8, 13, 14.

## Готовые функции

```python
print(bin(25))      # 0b11001
print(oct(25))      # 0o31
print(hex(25))      # 0x19

print(int("11001", 2))
print(int("31", 8))
print(int("19", 16))
```

## Перевод через остатки

```python
n = 100
base = 7
digits = []

while n > 0:
    digits.append(n % base)
    n //= base

digits = digits[::-1]
print(digits)
```

## Перебор неизвестной цифры

```python
alphabet = "0123456789ABCDE"

for x in alphabet:
    value = int("12" + x + "4", 15)
    if value % 14 == 0:
        print(x, value // 14)
```

Найди цифру `x`, при которой число `3x12` в системе счисления с основанием 8 делится на 5.
