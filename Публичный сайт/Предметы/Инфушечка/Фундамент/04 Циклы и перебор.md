# Циклы и перебор

## Зачем это нужно

Перебор — главный рабочий прием в ЕГЭ. Мы не угадываем ответ, а заставляем компьютер честно проверить варианты.

## После урока ты умеешь

- выбирать между `for` и `while`;
- перебирать диапазон чисел через `range`;
- вести счетчик;
- накапливать сумму;
- искать минимум и максимум;
- писать вложенный перебор.

## Базовый шаблон

```python
count = 0

for n in range(1, 1001):
    if n % 7 == 0:
        count += 1

print(count)
```

## Накопление

```python
total = 0

for n in range(1, 101):
    total += n

print(total)
```

## Вложенный перебор

```python
count = 0

for a in range(1, 50):
    for b in range(1, 50):
        if a + b == 30 and a * b > 200:
            count += 1

print(count)
```

## Типичная ошибка

`range(1, 10)` не включает 10. Если по условию нужно «от 1 до 10 включительно», пиши `range(1, 11)`.
