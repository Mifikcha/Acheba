# Среда ЕГЭ и файлы экзамена

## Зачем это нужно

На экзамене проверяют не только идеи, но и бытовую уверенность: открыть файл, понять его формат, не потеряться в папках, не писать абсолютный путь с домашнего компьютера. Это скучный блок, зато он экономит нервы.

## После урока ты умеешь

- отличать `.txt` и `.ods`;
- понимать, какие задания используют какие файлы;
- открывать таблицы в Либраофис Таблицы;
- класть `.txt` рядом с программой и читать его из Питон.

## Форматы файлов

| Задания | Формат | Основной инструмент |
|---|---|---|
| 3, 9, 18, 22 | `.ods` | Либраофис Таблицы |
| 17, 24, 26, 27 | `.txt` | Питон |

> [!note]
> Если ты привык к Эксель, это не катастрофа. Логика табличных задач почти та же, но основной публичный маршрут курса дальше будет ориентироваться на Либраофис, потому что демо-файлы ЕГЭ выданы в открытых форматах.

## Правило папки

Для программных задач держи файл рядом с программой:

```text
ege/
  task17.py
  17.txt
```

Тогда в коде достаточно:

```python
with open("17.txt") as file:
    nums = [int(line) for line in file]
```

Это лучше, чем путь вида `C:/Users/.../Desktop/...`: такой путь работает только на твоем компьютере и легко ломается.

## Попробуй сам

1. Создай папку `ege`.
2. Положи туда файл `numbers.txt`.
3. Запиши в него пять чисел, каждое с новой строки.
4. Напиши программу, которая печатает сумму этих чисел.
