# Списки и последовательности

## Зачем это нужно

После `for/range` в старой базе сразу начинается пропасть: разборы ЕГЭ уже используют списки, пары соседних чисел, `append`, `min`, `max`, но отдельного урока про массивы не было. Этот модуль закрывает дыру.

## После урока ты умеешь

- создавать список;
- обращаться к элементу по индексу;
- менять элемент;
- добавлять через `append`;
- использовать `len`, `min`, `max`, `sum`;
- перебирать соседние пары.

## Создание списка

```python
nums = [10, 3, 7, 20]

print(nums[0])
print(nums[-1])
print(len(nums))
```

## Добавление элементов

```python
good = []

for n in range(1, 101):
    if n % 7 == 0:
        good.append(n)

print(good)
print(len(good))
```

## Пары соседних элементов

```python
nums = [4, 10, 3, 8, 1]
best = -10**10

for i in range(1, len(nums)):
    pair_sum = nums[i - 1] + nums[i]
    best = max(best, pair_sum)

print(best)
```

## Типичная ошибка

Последний индекс списка — `len(nums) - 1`, а не `len(nums)`. Поэтому цикл по соседним парам начинается с `1` или заканчивается на `len(nums) - 1`.
