# Строки для ЕГЭ

## Зачем это нужно

Строки в ЕГЭ — это не красивые тексты, а последовательности символов. Их нужно обходить, резать, заменять, считать символы и искать длинные цепочки.

## После урока ты умеешь

- брать символ по индексу;
- брать срез;
- считать символы через `.count`;
- заменять фрагменты через `.replace`;
- идти по строке циклом;
- готовиться к задачам 12 и 24.

## Минимальный пример

```python
s = "ABACABA"

print(s[0])
print(s[-1])
print(s[1:4])
print(s.count("A"))
```

## Обход строки

```python
s = "ABACABA"
count = 0

for ch in s:
    if ch == "A":
        count += 1

print(count)
```

## Замены

```python
s = "111222111"
s = s.replace("111", "A")
print(s)
```

## Попробуй сам

Дана строка `s = "AABABBBAAB"`. Найди максимальную длину подряд идущих символов `B`.
