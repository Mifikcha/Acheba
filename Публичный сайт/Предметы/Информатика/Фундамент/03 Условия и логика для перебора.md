# Условия и логика для перебора

## Зачем это нужно

Большая часть программных задач ЕГЭ устроена одинаково: перебираем кандидатов и оставляем только тех, кто подходит под условие. Поэтому `if` — это не просто синтаксис, а фильтр.

## После урока ты умеешь

- записывать простые и составные условия;
- использовать `and`, `or`, `not`;
- понимать разницу между «оба условия» и «хотя бы одно»;
- превращать условие задачи в проверку внутри цикла.

## Минимальный пример

```python
count = 0

for n in range(100, 1000):
    if n % 3 == 0 and n % 10 == 7:
        count += 1

print(count)
```

## Логика без магии

| Слово в условии | Питон |
|---|---|
| и | `and` |
| или | `or` |
| не | `not` |
| делится на 7 | `n % 7 == 0` |
| не делится на 7 | `n % 7 != 0` |
| оканчивается на 3 | `n % 10 == 3` |

## Типичная ошибка

```python
if n % 3 == 0 or 5:
    ...
```

Так писать нельзя: `5` сам по себе считается истинным значением. Нужно повторять левую часть:

```python
if n % 3 == 0 or n % 5 == 0:
    ...
```
