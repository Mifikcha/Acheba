# Словари

Словарь хранит пары: ключ и значение.

```python
scores = {
    "Иван": 80,
    "Маша": 95,
}

print(scores["Иван"])  # 80
```

Важно: `[]` используют и списки, и словари.

```python
numbers[0]      # элемент списка по индексу
scores["Иван"]  # значение словаря по ключу
```

Сам словарь обычно создают через `{}`.

### Частотный словарь

Главный базовый приём:

```python
freq = {}

for ch in text:
    freq[ch] = freq.get(ch, 0) + 1
```

`.get(ch, 0)` значит: взять значение по ключу `ch`, а если такого ключа ещё нет, взять `0`.

Если `for` или накопление ещё не автоматические, смотри [[06.3 Накопитель чисел]] и [[06.6 Условие внутри цикла]].

### Задачи

1. Посчитай количество каждой буквы в строке.
2. Посчитай, сколько раз встретилось каждое число в списке.
3. Выведи числа, которые встретились ровно два раза.

### Предскажи вывод

```python
freq = {}
for ch in "aba":
    freq[ch] = freq.get(ch, 0) + 1

print(freq["a"])
print(freq["b"])
```

> [!tip]- Ответ
> Сначала `2`, потом `1`.
