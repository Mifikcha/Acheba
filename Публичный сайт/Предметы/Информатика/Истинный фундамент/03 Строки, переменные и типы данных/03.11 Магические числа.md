# Магические числа

Магическое число — число, смысл которого не понятен из кода.

```python
print(10 * 4)
```

Что такое `10`? Что такое `4`? Непонятно.

Лучше дать числам имена:

```python
digits_count = 10
variants_count = 4
print(digits_count * variants_count)
```

Код стал длиннее, зато его можно прочитать.

### Задачи

1. Замени `print(60 * 3)` на переменные с понятными именами.
2. Для числа `98765` создай переменную `number`, а не пиши число в каждой строке.
3. Придумай имя для переменной, в которой хранится курс доллара.

### Предскажи вывод

```python
base = 10
power = 2
print(base ** power)
```

> [!tip]- Ответ
> Будет `100`. Имена помогают понять, что считается.
