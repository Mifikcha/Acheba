# Строка это текст

Строка — это текст внутри кавычек.

```python
print("Hello")
print("2 + 2")
```

Для Питона `"2 + 2"` — текст, а `2 + 2` — вычисление. Если это пока кажется странным, потом смотри [[Типы данных]].

Строкой может быть одно слово, один пробел или даже ничего:

```python
"A"
" "
""
```

### Задачи

1. Выведи строку `ЕГЭ`.
2. Выведи пустую строку.
3. Выведи текст `2 + 2`, а следующей строкой результат `2 + 2`.

### Предскажи вывод

```python
print("5 * 5")
print(5 * 5)
```

> [!tip]- Ответ
> Первая строка: `5 * 5`. Вторая строка: `25`.
