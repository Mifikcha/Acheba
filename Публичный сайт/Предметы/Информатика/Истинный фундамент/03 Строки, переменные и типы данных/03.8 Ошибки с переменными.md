# Ошибки с переменными

Переменную нужно создать до первого использования.

```python
print(greeting)
greeting = "Привет"
```

Так нельзя: когда Питон дошел до `print(greeting)`, имени `greeting` еще нет.

Правильно:

```python
greeting = "Привет"
print(greeting)
```

Самая частая ошибка здесь — `NameError`.

### Задачи

1. Поставь строки в правильном порядке: сначала `x = 5`, потом `print(x)`.
2. Найди опечатку: `answer = 42`, затем `print(ansver)`.
3. Создай переменную `pet = "Dragon"` до ее вывода.

### Предскажи вывод

```python
value = 10
print(vlaue)
```

> [!tip]- Ответ
> Будет ошибка `NameError`, потому что в имени переменной опечатка.
