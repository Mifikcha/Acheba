# Константы

Константа — значение, которое по смыслу не должно меняться.

```python
PI = 3.14
DAYS_IN_WEEK = 7
```

В Python константы технически можно изменить, но по договоренности мы так не делаем.

Обычная переменная:

```python
score = 10
```

Константа:

```python
MAX_SCORE = 100
```

### Задачи

1. Создай `SECONDS_IN_MINUTE = 60` и выведи.
2. Создай `LAST_DIGIT_DIVISOR = 10` и используй для `123 % LAST_DIGIT_DIVISOR`.
3. Придумай константу для количества вариантов ответа в тесте.

### Предскажи вывод

```python
LIMIT = 5
print(LIMIT + 1)
```

> [!tip]- Ответ
> Будет `6`. Константа тоже может участвовать в выражении.
