# Параметры функций

Функция может принимать значение снаружи.

```python
def get_last_char(text):
    return text[-1]

print(get_last_char("Python"))  # n
```

`text` — параметр. При вызове в него попадает конкретная строка.

Параметров может быть несколько:

```python
def cut(text, count):
    return text[:count]

print(cut("Python", 2))  # Py
```

Порядок аргументов при вызове важен.

### Задачи

1. Создай `first_char(text)`, которая возвращает первый символ строки.
2. Создай `sum_two(a, b)`, которая возвращает сумму двух чисел.
3. Создай `truncate(text, count)`, которая возвращает первые `count` символов и `...`.

### Мини-проверка

```python
def last_digit(number):
    return number % 10

print(last_digit(987))
```

> [!tip]- Ответ
> Будет `7`.
