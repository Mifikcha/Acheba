# Цепочка вызовов

Если метод возвращает строку, у результата можно сразу вызвать следующий метод.

```python
text = "  PyThOn  "
print(text.strip().lower())
```

Вычисление идет слева направо:

1. `strip()` убрал пробелы;
2. `lower()` привел буквы к нижнему регистру;
3. `print()` вывел результат.

Цепочки удобны, но длинные цепочки трудно читать. Если строка стала слишком сложной, вынеси шаг в переменную.

### Задачи

1. Выведи `"  ЕГЭ  ".strip().lower()`.
2. Выведи длину строки после `strip()`: `len(text.strip())`.
3. Замени `a` на `A`, а потом приведи результат к нижнему регистру.

### Предскажи вывод

```python
text = "  ABC  "
print(text.strip().lower())
```

> [!tip]- Ответ
> Будет `abc`.
