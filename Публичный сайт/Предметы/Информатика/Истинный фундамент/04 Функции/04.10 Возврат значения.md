# Возврат значения

`print` показывает значение на экране. `return` возвращает значение из функции.

```python
def get_answer():
    return 42

answer = get_answer()
print(answer)
```

После `return` функция заканчивает работу.

```python
def run():
    return 5
    return 10
```

Вторая строка `return` уже не выполнится.

### Задачи

1. Создай функцию `get_name`, которая возвращает строку `Python`.
2. Создай функцию `get_last_digit`, которая возвращает `123 % 10`.
3. Сохрани результат вызова функции в переменную и выведи переменную.

### Предскажи вывод

```python
def f():
    return 1
    print(2)

print(f())
```

> [!tip]- Ответ
> Будет `1`. `print(2)` не выполнится.
