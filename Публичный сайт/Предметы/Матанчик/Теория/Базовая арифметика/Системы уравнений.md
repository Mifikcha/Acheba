# Системы уравнений

Система уравнений — это несколько уравнений с несколькими переменными, которые должны выполняться **одновременно**. Решить систему — значит найти все наборы значений переменных, которые превращают в верное равенство каждое уравнение сразу, а не какое-то одно из них.

$$
\boxed{
\begin{cases} f_1(x,y) = 0, \\  f_2(x,y) = 0 \end{cases} \ — \ \text{решение: пара } (x;y), \text{ верная для обоих уравнений}}$$

Ниже — универсальные способы решения, которые работают как для линейных систем, так и для систем с квадратами, дробями и вообще любыми выражениями.

---

## 1. Способ подстановки

Самый универсальный метод, который работает почти всегда.

$$\boxed{\text{выразить одну переменную из одного уравнения} \to \text{подставить в другое} \to \text{решить уравнение с одной переменной}}$$

Порядок действий:

1. Из одного уравнения системы (обычно выбирают то, где переменную проще выразить) выражаем одну переменную через другую.
2. Подставляем это выражение вместо переменной в **другое** уравнение системы.
3. Решаем получившееся уравнение с одной переменной.
4. Найденные значения подставляем обратно в выражение из пункта 1 и находим вторую переменную.
5. Записываем ответ парами $(x;y)$ — сколько значений одной переменной нашли, столько пар и получится (с соответствующими им значениями второй).

Пример: $\begin{cases}x^2+y^2=17,\\ x-4y=0.\end{cases}$ Из второго уравнения $x=4y$. Подставляем в первое: $(4y)^2+y^2=17 \Rightarrow 17y^2=17 \Rightarrow y=\pm1$. Тогда при $y=1$: $x=4$; при $y=-1$: $x=-4$. Ответ: $(4;1),\ (-4;-1)$.

---

## 2. Способ сложения (алгебраического сложения)

Удобен, когда при почленном сложении (или вычитании) уравнений системы одна из переменных «сокращается».

$$\boxed{\text{домножить уравнения на подходящие числа} \to \text{сложить (или вычесть) почленно} \to \text{получить уравнение с одной переменной}}$$

Если переменная сама по себе не сокращается, оба (или одно) уравнения предварительно домножают на такие числа, чтобы коэффициенты при этой переменной стали противоположными.

Пример: $\begin{cases}x^2+y^2=5,\\ x^2-y^2=3.\end{cases}$ Складываем уравнения почленно: $2x^2=8 \Rightarrow x^2=4 \Rightarrow x=\pm2$. Подставляем в первое уравнение: при $x=2$ (и при $x=-2$) получаем $y^2=1 \Rightarrow y=\pm1$. Ответ: $(2;1),(2;-1),(-2;1),(-2;-1)$.

---

## 3. Графический способ

Строим график каждого уравнения системы в одной системе координат — точки пересечения графиков и есть решения системы (их координаты).

$$\boxed{\text{число решений системы} = \text{число точек пересечения графиков}}$$

Метод особенно удобен, когда нужно **не решить систему точно, а понять, сколько у неё решений** — иногда по виду графиков (парабола и гипербола, прямая и окружность) это видно сразу, без вычислений. Важный момент: графический метод даёт приближённый результат, поэтому найденные «на глаз» координаты точек пересечения обязательно нужно проверить подстановкой в оба уравнения системы.

---

## 4. Метод замены переменной

Если в систему входят не сами $x$ и $y$, а какие-то повторяющиеся комбинации от них (например, всюду встречаются только $x+y$ и $xy$), удобно ввести новые переменные для этих комбинаций, решить более простую систему относительно них, а уже потом вернуться к исходным $x$ и $y$.

Пример: $\begin{cases}(x+y)\cdot xy=20,\\ x+y-xy=1.\end{cases}$ Пусть $t=x+y,\ k=xy$. Система становится $\begin{cases}tk=20,\\ t-k=1.\end{cases}$ Решаем её (подстановкой): $t=5,\ k=4$ или $t=-4,\ k=-5$. Возвращаемся: $\begin{cases}x+y=5,\\ xy=4\end{cases}$ даёт $(4;1),(1;4)$, а $\begin{cases}x+y=-4,\\ xy=-5\end{cases}$ даёт $(-5;1),(1;-5)$.

---

## 5. Частые ошибки

- **Забыть подставить найденную переменную во все случаи** — если получилось несколько значений одной переменной, для каждого нужно отдельно найти соответствующее значение второй (не путать их «крест-накрест»).
- **Потерять часть решений при делении уравнения на выражение с переменной** — как и в обычных уравнениях, лучше выносить общий множитель, а не сокращать.
- **Забыть про ОДЗ**, если в системе есть дроби, корни или логарифмы — как и с обычными уравнениями, сначала проверяем допустимость, потом ищем решения.
- **Не проверить решения, найденные графическим методом** — координаты «на глаз» могут быть неточными.

---

## 6. Пример

Решим систему $\begin{cases}xy=180,\\ (x-3)(y-2)=120.\end{cases}$

1. Раскроем скобки во втором уравнении: $xy-2x-3y+6=120$.
2. Подставим $xy=180$ из первого уравнения: $180-2x-3y+6=120 \Rightarrow 3y+2x=66 \Rightarrow x=33-1{,}5y$.
3. Подставим в первое уравнение: $(33-1{,}5y)y=180 \Rightarrow 1{,}5y^2-33y+180=0$.
4. Решаем квадратное уравнение: $y=12$ или $y=10$.
5. Находим соответствующие $x$: при $y=12$: $x=33-18=15$; при $y=10$: $x=33-15=18$.

Ответ: $(15;12),\ (18;10)$.
