# Срезы строк

Срез берет кусок строки.

```python
word = "Python"
print(word[0:2])  # Py
```

Формула:

```python
строка[начало:конец]
```

Правая граница не включается. `word[0:2]` берет индексы `0` и `1`.

Можно не писать начало или конец:

```python
word[:2]  # первые два символа
word[2:]  # с индекса 2 до конца
```

### Задачи

1. Из `Python` выведи `Pyt`.
2. Из `Python` выведи `thon`.
3. Из `Informatics` выведи `form`.

### Предскажи вывод

```python
s = "abcdef"
print(s[1:4])
```

> [!tip]- Ответ
> Будет `bcd`. Индексы `1`, `2`, `3` вошли, индекс `4` не вошел.
