# Комментарии

> [!note] Зачем это нужно:
> Комментарии помогают подписывать шаги решения, особенно когда код становится длиннее трех строк.

Комментарий — это заметка для человека. Питон ее не выполняет.

```
# Это комментарий
print("Эта строка выполнится")
```

Комментарий начинается со знака `#`. Его удобно использовать, чтобы подписывать шаги решения:

```
# Считаем значение выражения
print(17 + 25)
```

Комментарий может стоять и после команды:

```
print(100)  # выводим ответ
```

### Задачи

1. Напиши программу из двух строк: на первой комментарий `начало`, на второй вывод числа `10`.
2. Напиши три команды вывода и подпиши каждую комментарием.
3. Закомментируй одну команду вывода так, чтобы она не выполнилась.

Если можешь выключить строку кода через `#` и потом вернуть ее обратно — идем дальше.
