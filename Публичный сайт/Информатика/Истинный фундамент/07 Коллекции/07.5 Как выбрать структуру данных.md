# Как выбрать структуру данных

Коллекции — это не три случайных синтаксиса. У каждой есть работа.

| Нужно | Что выбрать |
|---|---|
| сохранить порядок и повторы | `list` |
| оставить только разные элементы | `set` |
| связать ключ со значением | `dict` |
| посчитать частоты | `dict` |
| быстро проверить наличие | `set` или `dict` |

Примеры:

```python
scores = [80, 95, 80]       # список: порядок и повторы
unique_scores = set(scores) # множество: разные баллы
```

```python
student_score = {
    "Иван": 80,
    "Маша": 95,
}
```

Если в задаче сказано «сколько раз встретилось», почти всегда нужен словарь частот. Если сказано «сколько различных», почти всегда нужен `set`.

### Задачи

1. Нужно хранить последовательность оценок. Что выбрать?
2. Нужно узнать, сколько разных оценок было. Что выбрать?
3. Нужно хранить оценку каждого ученика. Что выбрать?
4. Нужно посчитать частоту каждого числа. Что выбрать?

### Предскажи вывод

```python
scores = [5, 4, 5, 3]
print(len(scores))
print(len(set(scores)))
```

> [!tip]- Ответ
> Сначала `4`, потом `3`.
