# Создание функции

Свою функцию создают через `def`.

```python
def say_hello():
    print("Hello")

say_hello()
```

Важны две вещи:

```python
def имя_функции():
    тело функции с отступом
```

Определение функции само по себе не запускает тело. Тело выполняется только при вызове.

### Задачи

1. Создай функцию `say_hi`, которая выводит `hi`, и вызови ее.
2. Создай функцию `print_answer`, которая выводит `42`, и вызови ее два раза.
3. Проверь, что будет, если определить функцию, но не вызвать.

### Предскажи вывод

```python
def run():
    print("go")

print("start")
run()
```

> [!tip]- Ответ
> Будет `start`, потом `go`.
