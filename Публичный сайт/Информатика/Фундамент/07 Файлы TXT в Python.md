# Файлы TXT в Питон

## Зачем это нужно

Задания 17, 24, 26 и 27 дают данные в `.txt`. Если ученик не умеет спокойно читать файл, он начинает решать не задачу, а проблему «почему Питон не видит файл».

## После урока ты умеешь

- читать файл рядом с программой;
- читать числа по строкам;
- читать одну длинную строку;
- разбивать строку через `.split`;
- использовать `map`;
- писать код без абсолютного пути.

## Числа по строкам

```python
with open("17.txt") as file:
    nums = [int(line) for line in file]

print(len(nums))
print(min(nums), max(nums))
```

## Одна длинная строка

```python
with open("24.txt") as file:
    s = file.readline().strip()

print(len(s))
```

## Числа в одной строке

```python
with open("26.txt") as file:
    nums = list(map(int, file.readline().split()))
```

Если в файле сначала идет служебное число, его читают отдельно:

```python
with open("26.txt") as file:
    n = int(file.readline())
    nums = [int(file.readline()) for _ in range(n)]
```

## Типичная ошибка

Не надо писать домашний абсолютный путь:

```python
open("C:/Users/name/Desktop/17.txt")
```

На экзамене путь будет другим. Положи файл рядом с программой и открывай по имени.
