# Алгоритмические шаблоны

## Зачем это нужно

Сложные программные задания не надо учить как набор заклинаний. Их нужно раскладывать на повторяющиеся шаблоны: поиск, счетчик, максимум, пары, сортировка, окно, префиксные суммы, остатки.

## После урока ты умеешь

- выбирать паттерн под условие;
- оценивать, пройдет ли наивный перебор;
- писать обработку последовательности в один проход;
- понимать, зачем нужна сортировка;
- видеть, где начинается advanced-уровень.

## Паттерн 1. Счетчик

```python
count = 0

for x in nums:
    if x % 2 == 0:
        count += 1
```

## Паттерн 2. Максимум по условию

```python
best = -10**20

for x in nums:
    if x % 7 == 0:
        best = max(best, x)
```

## Паттерн 3. Пары соседей

```python
count = 0
best = -10**20

for i in range(1, len(nums)):
    a = nums[i - 1]
    b = nums[i]
    if a % 3 == 0 or b % 3 == 0:
        count += 1
        best = max(best, a + b)
```

## Паттерн 4. Сортировка

```python
nums.sort()
```

Сортировка нужна, когда задача говорит про «максимальное количество», «минимальную сумму», «выбрать как можно больше объектов», «расставить по возрастанию».

## Паттерн 5. Окно

```python
left = 0
current = 0
best = 0

for right in range(len(nums)):
    current += nums[right]
    while current > 100:
        current -= nums[left]
        left += 1
    best = max(best, right - left + 1)
```

Окно полезно, когда нужно найти самый длинный/короткий подряд идущий фрагмент.

## Паттерн 6. Префиксные суммы

```python
pref = [0]

for x in nums:
    pref.append(pref[-1] + x)

segment_sum = pref[r] - pref[l]
```

Префиксные суммы позволяют быстро считать сумму отрезка.
