Логарифм числа b по основанию a (logab = c) — это такой показатель степени c, в которую нужно возвести a, чтобы получить b (то есть ac = b).

При этом задаются ограничения: a > 0, a ≠ 1, b > 0. Значение 𝑐 логарифма может быть любым.

Пример № 1:

Вычислите: image_description.

1. Действуем по определению. Подберем степень, в которую нужно возвести 3, чтобы получить 27:

log327 = 3

2. При возведении image_description в –3 степень получим 27, значит:

image_description

Ответ: 3; –3.

ЧАСТНЫЕ СЛУЧАИ ЛОГАРИФМА

1. Логарифм по основанию 10 записывается как lg:

log10 a = lga

2. Логарифм по основанию e (e ≈ 2,72) записывается как ln:

loge a = lna

Используем рассмотренные свойства для решения задачи.
