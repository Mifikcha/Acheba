## Ветвление в программировании

Сталкиваясь со многими задачами, нам не необходимо проверить какие-либо условия. Например, при вычислении корней квадратного уравнения, необходимо проверить значение дискриминанта (>0 / == 0 / < 0). В различных случаях будут разные алгоритмы. Справиться с описанной задачей помогает ветвление.

Ветвление — это операция, применяющаяся в случаях, когда выполнение или невыполнение некоторого набора команд должно зависеть от выполнения или невыполнения некоторого условия.

При выполнении определенного условия делается один алгоритм, при невыполнении другой:

![image_description](https://storage.yandexcloud.net/maximum-lms-ru1/public/knowledge-base-content/images/docx_230926_080425/image1.png)

Можно провести аналогию с реальной жизнью. Если вам задали домашнее задание, то его необходимо сделать, а если домашнее задание не задали, то делать вы его не будете и можно заняться своим хобби. И постоянно сами того не замечая, вы рассматриваете такие условия и действуете по разным алгоритмам.

В программирование ветвление вас будет окружать постоянно, в каждой значительной программе оно используется.

**1.** **Конструкция условного оператора ветвления** **if**

В первую очередь хотелось бы обратить внимание на синтаксис. Сначала пишется if, после чего идет условие, после написание условия ставится двоеточие, последующие строки, идущие с отступом, будут выполняться, только, если условие истинно.

if (условие):

⠀⠀ (тело условного оператора) # Выполняется в случае значения True

**Пример****:**

a = 3

if a == 3:

⠀⠀print(‘hello’)

**_Задание 1_**

На вход подается целое число. Напишите программу, определяющую входит ли число в отрезок [10; 20]. Если входит, то вывести YES.

**_Решение:_**

x = int(input()) #ввод числа

if 10 <= x <= 20: #если число на отрезке [10;20]

⠀⠀print(‘YES’) #вывести YES

**2.** **Конструкция** **if-else**

До этого было рассмотрено, как определить действия, которые выполняются, если условие после if истинно. Но что, если нам необходимо выполнять еще один набор инструкций, если условие ложно? В этом случае нужно использовать блок else. Данный блок содержит инструкции, которые выполняются, если условие после if ложно (равно False).

if (условие):

⠀ ⠀ (тело условного оператора) # Выполняется в случае значения True

else:

⠀ ⠀ (тело условного оператора) # Выполняется в случае значения False

**Пример****:****⠀****⠀**

a = 5

if a == 5:

⠀⠀print(‘hello’)

else:

⠀⠀print(‘bye’)

**_Задание 2_**

На вход подается четыре целых числа. Вывести ‘YES’, если сумма первых двух чисел больше суммы оставшихся, ‘NO’ в противном случае.

**_Решение:_**

a = int(input()) #ввод первого числа

b = int(input()) #ввод второго числа

c = int(input()) #ввод третьего числа

d = int(input()) #ввод четвертого числа

if a + b > c + d: #если сумма первых двух чисел больше оставшихся

⠀⠀print('YES') #вывод YES

else: #иначе

⠀⠀print('NO') #вывод NO

**3.** **Конструкция** **if-****elif****-else:**

Финальная конструкция, необходимая для работы с условиями: if-elif-else.⠀⠀

Это тот самый случай, когда возникает несколько условий (больше двух), связанных между собой, например, при вычисления корней квадратного уравнения (D > 0 / D == 0 / D < 0).

if (условие):

⠀⠀(тело условного оператора) # Выполняется в случае значения True

elif (условие):

⠀⠀(тело условного оператора) # Выполняется в случае значения False в предыдущих условиях и True в текущем

else:

⠀⠀(тело условного оператора) # Выполняется в случае значения False во всех условиях

**Пример****:****⠀****⠀**

a = 5

if a == 5:

⠀⠀ print(‘hello’)

elif a > 5:

⠀⠀ print(‘world’)

else:

⠀⠀ print(‘bye’)

**4. Условие кратности числа и проверки последней цифры:**

Как в задачах ОГЭ, так и в будущем в реальных проектах постоянно требуется проверка кратности какого-либо число или работа с цифрами числа. Рассмотрим, как можно проверить кратность числа или последнюю цифру:

if <значение % делитель == 0>: #число кратно
