**1.** **Правила работы с переменными**

Переменная в программировании — это именованная область памяти для хранения определенного типа данных (целочисленного/вещественного/строкового/логического и др.).

При описании для каждой переменной задаются ее имя и тип.

Есть определенные **правила для названия переменных**, которых нужно придерживаться в программе, чтобы в результате работы увидеть корректный результат:

1) Имя переменной должно быть существительным (отвечать на вопрос: кто, что). Здесь важно пометить, что, это общее правило программирования, чтобы для любого человека, который будет читать код и, возможно, в будущем его дорабатывать, была понятна программа, и он быстро смог с ней разобраться. Если же не следовать этому правилу и просто создать переменную, например, буквой a, то программа все также выведет корректный результат, однако лучше сразу себя приучать к правильному стилю программирования.

2) В качестве первого символа допускается писать буквы латинского алфавита (a-z, A-Z) и символ подчеркивания (_)

3) В качестве второго и последующих символов еще допустимо использовать цифры (0-9).

Последние два правила являются обязательными, если их не соблюдать, то программа будет выводить ошибку.

4) Переменные, отличающиеся регистром любой из букв — разные переменные. Например, cat = 5, Cat = 10, cAt = 11 — это три разных переменных.

**Типы данных переменных:**

|   |   |
|---|---|
|**Название**|**Описание**|
|Целочисленный (int)|Целые числа|
|Вещественный (float)|Дробные числа|
|Строковый (str)|Любая последовательность символов|
|Логический (bool)|True/False (истинна/ложь)|

Для того, чтобы придать переменной какое-либо значение, в языке программирования Python существует оператор присваивания. Обозначение: =

Создание переменной и присваивание ей значения: <имя переменной> = <значение>.

Например, x = 5 (создание переменной целочисленного типа, к которой далее в программе можно обращаться); x = 5.234 (создание переменной вещественного типа данных).

Существует еще два вида присваивания:

- каскадное (x = y = z = 5); всем переменным присваивается значение 5 (в результате такого присваивания получается, что x = 5, y = 5, z = 5)
- множественное (x, y, z = 4, 5, 3); каждой переменной присваивается соответственное значение (получается x = 4, y = 5, z = 3).

**2.** **Ввод и вывод данных**

**Ввод данных**

За ввод данных пользователем с клавиатуры отвечает функция input(). Изначально функция input() возвращает строковый тип данных. Значит, если будет написано x = input() и ввести с клавиатуры 5, то получится, что x = ‘5’. Переменная x будет иметь строковый тип данных и ее нельзя будет сложить, например, с целочисленным. И здесь возникает вопрос, а что делать, если нам нужно, чтобы мы вводили не строку, а число?

На самом деле, все достаточно просто, в python существует преобразование типов данных. Для того, чтобы ввести целочисленное значение нужно написать: x = int(input()), т.е. необходимо написать тип данных (int от integer — целочисленный) и взять значение другого типа данных в скобки. Соответственно, если есть желание ввести вещественное число, необходимо написать float(input()).

**Вывод данных**

За вывод данных отвечает функция print(). Она выводит результат выполнения программы на экран, чтобы пользователь мог получить необходимые для него данные.

**Примеры****:**

print(5) -> на экране 5

print(‘Hello World!’) -> на экране Hello World

x = 10

print(x) -> на экране 10

В функции print() можно выводить сразу несколько значений, причем различных типов данных.

**Пример:**

print('Каждый знает, что 2x2 =', 2 * 2) -> на экране: “Каждый знает, что 2x2 = 4”.

**3. Базовые математические операции** **и приоритет их выполнения**

**К базовым математическим операциям относятся:**

- Сложение (+);
- Вычитание (-);
- Умножение (*);
- Деление (/) — результатом деления **всегда** является вещественное число;
- Возведение в степень (**) — основания могут быть отрицательными и дробными;
- Целочисленное деление (//) - целая часть, которая получается при делении;

⠀⠀⠀_Примеры:_ 17 // 3 = 5.

⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀33 // 5 = 6

- Остаток от деления(%) — остаток, который остается после целочисленного деления;

⠀⠀⠀⠀_Пример__ы__:_ 17 % 3 = 2 (т.к. 3 * 5 = 15 - можем взять максимум 5 раз по 3, остаток: 17 — 15 = 2)

⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀_21 % 5 = 1 (т.к. 5 * 4 = 20_ _—_ _можем взять максимум 4 раза по 5, остаток 21_ _—_ _20 = 1)_

**Приоритет операций:**

1) Возведение в степень;

2) Умножение, деление, целочисленное деление и остаток от деления;

3) Сложение и вычитание.
