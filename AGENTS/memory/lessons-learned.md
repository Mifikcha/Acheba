## Факты проекта

- `AGENTS/About_me.md` содержит актуальный профиль пользователя; читать его перед персональной стратегией, планированием и задачами, чувствительными к предпочтениям.
- `AGENTS/memory/SKILL.md` адаптирован под Codex и не должен ссылаться на Gemini-specific runtime paths вроде `tools/gemini-cli-bot/lessons-learned.md`.
- `AGENTS/physics-solver/SKILL.md` содержит русскоязычный Codex-адаптированный навык для решения физических задач, выводов формул, моделирования и перевода единиц.
- Физические заметки в `репетиторство/шизончик/теория` размечены как темы учебной программы через YAML frontmatter; текущие разделы: `reference`, `mechanics`, `molecular_physics`, `electrodynamics`, `quantum_physics`.
- В `Репетиторство/Шизончик/Базы` лежат базы и программы: `База по физике за 9 класс.base`, `База по физике за 11 класс.base`, `Физика 9 класс — программа группы.md`, `Физика 11 класс — программа группы.md`.

## Правила рабочей папки

- Рабочий язык этой папки — русский.
- Все правки, редактирование, заметки, планы, пояснения и memory-файлы по умолчанию писать на русском, если пользователь явно не попросил другой язык.
- Для исследовательских выжимек в `хуйнюшка` сохранять не только извлечённые данные, но и контекст: зачем показатель нужен автору, как он связан с аргументом статьи, какие ограничения/источники данных указаны, и короткий интерпретирующий вывод.
