# Навык: решение физических задач

## Когда использовать

Используй этот навык, когда пользователь просит:

- решить задачу по физике;
- вывести формулу или уравнение движения;
- объяснить физический принцип;
- проверить размерности и порядок величины;
- смоделировать физическую систему;
- решить задачу по механике, электродинамике, термодинамике, оптике,
  квантовой механике, волнам, цепям или теории относительности;
- перевести физические единицы.

Рабочий язык этой папки — русский, поэтому решения, пояснения, заметки и
учебные материалы по умолчанию пиши на русском.

## Общий алгоритм решения

1. Определи физическую систему и область физики.
2. Сформулируй, что дано и что нужно найти.
3. Нарисуй схему мысленно или опиши её текстом.
4. Выбери законы, приближения и систему отсчёта.
5. Запиши уравнения сначала в символическом виде.
6. Проверь размерности.
7. Подставь числа только после вывода формулы.
8. Проверь предельные случаи и порядок величины.
9. Интерпретируй ответ физически, а не только алгебраически.

Если пользователь учится или готовит материал для ученика, объясняй решение
пошагово и явно называй идею каждого шага. Если пользователь просит короткий
ответ, дай компактное решение без лишней педагогики.

## Вычисления в Codex

Для расчётов можно использовать Python, если это помогает избежать арифметических
ошибок или проверить результат. Предпочитай:

- `sympy` для символьных выводов;
- `scipy.constants` для физических констант;
- `scipy.integrate.solve_ivp` для численных ОДУ;
- `numpy` для массивов и численной математики.

Не привязывайся к чужим виртуальным окружениям. Если библиотека недоступна,
сначала проверь локальные зависимости, затем используй стандартную библиотеку
или попроси разрешение на установку только если это действительно нужно.

## Механика

Для школьных задач чаще всего начинай с сил, ускорений, энергий, импульса и
выбора осей. Для более продвинутых задач можно использовать лагранжев подход.

```python
from sympy import *

t = symbols("t")
m, g, L = symbols("m g L", positive=True)

# Пример: математический маятник через лагранжиан
theta = Function("theta")(t)
T = Rational(1, 2) * m * (L * diff(theta, t))**2
V = -m * g * L * cos(theta)
Lag = T - V

EL = diff(diff(Lag, diff(theta, t)), t) - diff(Lag, theta)
eq = simplify(EL)
print(eq)
```

Численное моделирование:

```python
from scipy.integrate import solve_ivp
import numpy as np

def pendulum(t, state, g=9.81, L=1.0):
    theta, omega = state
    return [omega, -g / L * np.sin(theta)]

sol = solve_ivp(pendulum, [0, 10], [np.pi / 4, 0], max_step=0.01)
```

## Электродинамика и цепи

```python
from scipy import constants as const
import numpy as np

def coulomb_force(q1, q2, r):
    """Сила Кулона между двумя зарядами, Н."""
    return const.k * q1 * q2 / r**2

def capacitor_energy(C, U):
    """Энергия конденсатора, Дж."""
    return 0.5 * C * U**2

def rc_discharge(U0, R, C, t):
    """Разряд RC-цепи."""
    tau = R * C
    return U0 * np.exp(-t / tau)

def em_wavelength(frequency):
    """Длина электромагнитной волны."""
    return const.c / frequency

def photon_energy(wavelength):
    """Энергия фотона по длине волны."""
    return const.h * const.c / wavelength
```

## Квантовая физика

```python
from scipy import constants as const

def particle_in_box(n, L, m=const.m_e):
    """Энергия n-го уровня частицы в одномерном ящике."""
    return (n**2 * const.h**2) / (8 * m * L**2)

def hydrogen_energy_ev(n):
    """Энергия уровня атома водорода в эВ."""
    return -13.6 / n**2

def de_broglie_wavelength(p):
    """Длина волны де Бройля."""
    return const.h / p
```

Ключевые проверки:

- энергия уровней должна иметь правильный знак и масштаб;
- переходы между уровнями проверяй через разность энергий;
- для классического предела проверяй большие квантовые числа или малость
  квантовых поправок.

## Термодинамика и статфизика

```python
from scipy import constants as const
import numpy as np

def ideal_gas_pressure(n, T, V):
    """Давление идеального газа."""
    return n * const.R * T / V

def carnot_efficiency(T_hot, T_cold):
    """КПД цикла Карно для температур в Кельвинах."""
    return 1 - T_cold / T_hot

def planck_spectral_radiance(wavelength, T):
    """Спектральная яркость абсолютно чёрного тела."""
    return (2 * const.h * const.c**2 / wavelength**5) / (
        np.exp(const.h * const.c / (wavelength * const.k * T)) - 1
    )

def maxwell_boltzmann_speed_distribution(v, T, m):
    """Распределение Максвелла по скоростям."""
    return (
        4
        * np.pi
        * (m / (2 * np.pi * const.k * T))**1.5
        * v**2
        * np.exp(-m * v**2 / (2 * const.k * T))
    )
```

## Перевод единиц

```python
from scipy.constants import eV, atm

def ev_to_joule(energy_ev):
    return energy_ev * eV

def joule_to_ev(energy_joule):
    return energy_joule / eV

def celsius_to_kelvin(t_celsius):
    return t_celsius + 273.15

def atm_to_pa(pressure_atm):
    return pressure_atm * atm
```

## Проверки качества решения

- Всегда проверяй размерность итоговой формулы.
- Отделяй физическую модель от алгебры.
- Явно называй приближения: без трения, малые колебания, точечный заряд,
  идеальный газ, нерелятивистский предел и так далее.
- Проверяй знак ответа и физический смысл.
- Для численных ответов указывай единицы измерения.
- Для школьных задач не усложняй решение университетским аппаратом без нужды.
- Для сложных задач сначала давай чистый вывод, затем вычислительную проверку.
