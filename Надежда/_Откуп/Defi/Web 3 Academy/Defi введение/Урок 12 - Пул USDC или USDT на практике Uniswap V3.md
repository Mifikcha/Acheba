Uniswap и пулы ликвидности
Uniswap — децентрализованная биржа (DEX), использующая AMM для обмена активов через пулы ликвидности. Пулы версии v2 поддерживают пропорцию активов 50/50 по рыночной стоимости, распределяя капитал от 0 до ∞, что снижает эффективность.

Пулы версии v3 позволяют задавать диапазоны ликвидности (например, 0.999–1.001 для USDT/USDC), концентрируя капитал в активных торговых зонах. Это повышает доходность (до 8.5% годовых против 3% для v2 USDC/USDT).

Доходность v2 низкая: 3% для USDC/USDT, 8% для ETH/USDT. Пулы v2 оправданы только с инсентивс (дополнительными токенами). Статистика пулов: USDC/USDT v2, ETH/USDT v2.

Практика внесения ликвидности
Процесс внесения ликвидности на Uniswap (демонстрация с USDT/USDC, кошелёк OKX Wallet):

Подключите кошелёк к Uniswap, выберите пару (USDT/USDC).
Задайте диапазон (0.99–1.001), выберите комиссию (0.01% для стейблкоинов).
Подтвердите транзакции: два approve (разрешение для USDT и USDC), добавление ликвидности.
Получите NFT-позицию, отображающую активы и комиссии.
Пропорция активов в v3 меняется с курсом (например, больше USDC при росте USDT). Комиссии накапливаются в USDT/USDC, отображаются в разделе "Unclaimed Fees". Пример: Позиция за 150 дней с диапазоном 0.999–1.001 дала 8.49% годовых.

Варианты диапазонов для USDT/USDC: 0.99–1.001 (широкий, для пассивной стратегии, захватывает большинство колебаний); 1–1.0006 (узкий, максимизирует комиссии, но риск выхода); 1–1.008 (средний, баланс доходности и стабильности). Выбор зависит от стратегии и объёmov торгов. Диапазоны могут выходить из зоны при дипеге, но возвращаются на длинной дистанции. Подробнее о комиссиях: Uniswap Fee Tiers.

Пулы v3 с диапазонами эффективнее v2, концентрируя капитал в активных зонах торгов.
Сравнение v2 и v3, стратегия
Пулы v2 (50/50) распределяют капитал неэффективно, давая низкую доходность (3% для USDC/USDT, 8% для ETH/USDT). Они подходят только с инсентивс. Пулы v3 с диапазонами (например, 0.999–1.001) обеспечивают до 8.5% годовых, так как капитал сосредоточен в зоне активных торгов.

Стратегия для новичков: Используйте v3 с узкими диапазонами для стейблкоинов, ориентируясь на статистику объёмов (например, USDC/USDT v2). Не переставляйте диапазоны при дипеге, ждите возвращения курса. Лендинг-маркеты (следующий урок) проще для начинающих.

Управление позицией: Увеличение ликвидности (Increase Liquidity) или вывод (Remove Liquidity) доступны в интерфейсе Uniswap. Комиссии собираются вручную или реинвестируются. Подробнее: Uniswap v3 Docs.

Диапазоны в v3 позволяют зарабатывать больше комиссий, чем фиксированные пулы v2.
Определения терминов
Диапазоны (Liquidity Ranges): Ценовые рамки в пулах Uniswap v3, где концентрируется ликвидность для повышения доходности (например, 0.99–1.001 для USDT/USDC).

Уровень комиссии: Процент комиссии за свапы в пуле (0.01% для стейблкоинов, 0.05% для активов/стейблкоинов, 0.3% или 1% для новых токенов).

Approve: Транзакция, разрешающая смарт-контракту (например, Uniswap) использовать токены (USDT, USDC) для операций. Требуется один раз для каждой валюты.

NFT-позиция: Невзаимозаменяемый токен (NFT), представляющий позицию ликвидности в Uniswap v3, содержащий данные об активах, диапазоне и комиссиях.
