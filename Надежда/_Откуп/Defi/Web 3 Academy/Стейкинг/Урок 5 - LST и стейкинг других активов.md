Что такое LST?
LST (Liquid Staking Token) — токен, выдаваемый провайдерами ликвидного стейкинга, отражающий стоимость актива и доходность стейкинга. Пример: ETH → STETH через Lido Finance, SOL → JitoSOL через Jito Network.

95% ликвидного стейкинга связано с Ethereum (Lido Finance, Rocket Pool, Binance). Провайдеры берут ETH, направляют валидаторам, выдавая LST (например, BETH от Binance), который растёт в цене на доходность стейкинга.

Ликвидный стейкинг активов
AVAX через Benqi Finance: стейкайте AVAX, получая SAVAX с доходностью 5.5% годовых. Unstaking занимает 15 дней (лучший курс), через агрегаторы быстрее, но курс хуже.

SOL через Jito Network: стейкайте SOL, получая JitoSOL с доходностью 8.1% годовых. Unstaking занимает 1 час (лучший курс), через агрегаторы быстрее (хуже курс). TON через Tonstakers: доходность 3.17% годовых.

Использование LST в DeFi
LST увеличивает доходность в DeFi: базовая от стейкинга плюс дополнительная от стратегий. Например, JitoSOL можно использовать для ликвидности на Kamino Finance, получая комиссии от торговой пары JitoSOL/SOL.

LST также подходит для залога на лендинг-маркетах, позволяя брать займы в стейблкоинах или других активах. Это открывает новые стратегии в DeFi, увеличивая общую доходность.

LST расширяет возможности в DeFi.
Рекомендации
Изучите провайдеров ликвидного стейкинга на DeFiLlama. Разные комиссии (10–25%) и сроки unstaking (1 час для SOL, 15 дней для AVAX) влияют на выбор провайдера.

Используйте LST для повышения доходности в DeFi, комбинируя базовую ставку стейкинга с дополнительными стратегиями. Подробности таких подходов рассмотрены в следующем уроке.

Определения терминов
LST: Liquid Staking Token, отражающий актив и доходность стейкинга.

SAVAX: LST для AVAX, выдаваемый Benqi Finance.

JitoSOL: LST для SOL, выдаваемый Jito Network.

Инструменты
Ресурсы для ликвидного стейкинга:

Lido Finance — Провайдер ликвидного стейкинга для Ethereum.
DeFiLlama LST — Список всех провайдеров ликвидного стейкинга.
Jito Network — Провайдер ликвидного стейкинга для Solana.
Tonstakers — Провайдер ликвидного стейкинга для TON.
Benqi Finance — Провайдер ликвидного стейкинга для Avalanche.
Документация Jito Network — Руководство по ликвидному стейкингу SOL.
Документация Benqi Finance — Руководство по ликвидному стейкингу AVAX.
