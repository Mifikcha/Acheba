Установка MetaMask
MetaMask — базовый некастодиальный кошелёк для новичков. Установите его как расширение в браузеры: Firefox, Google Chrome, Microsoft Edge, Opera, Яндекс.Браузер.

Перейдите на официальный сайт MetaMask, скачайте расширение, согласитесь с правилами. Откажитесь от сбора данных (Help us improve MetaMask). Используйте английский интерфейс для избежания ошибок перевода.

MetaMask — фундамент для работы с криптой.
Создание кошелька и безопасность
Создайте кошелёк, установите пароль (можно сбросить при переустановке). Получите мнемоническую фразу (12 слов) — ключ к активам. Запишите её на бумагу, не храните цифровые копии.

Подтвердите фразу, введя несколько слов. Храните фразу в надёжном месте, никому не передавайте. После установки кошелёк готов к работе с EVM-сетями (Ethereum, Linea).

Рекомендации
Изучите модуль «Основы безопасности» на платформе для понимания мнемонической фразы и кошельков. Модуль «Криптокошельки» поможет выбрать другие кошельки.

Используйте несколько кошельков для разных задач. Следующий урок покажет настройку MetaMask для DeFi. Всегда проверяйте ссылки, чтобы избежать фишинга.

Задание: Создание некастодиального кошелька MetaMask
Шаги выполнения
Перейдите на официальный сайт MetaMask (metamask.io) через один из поддерживаемых браузеров (Firefox, Chrome, Edge, Opera, Яндекс.Браузер).
Скачайте и установите расширение MetaMask для вашего браузера, следуя инструкциям на сайте.
Нажмите «Создать новый кошелек», откажитесь от отправки данных разработчикам.
Создайте пароль для кошелька, который будете помнить.
Запишите мнемоническую фразу из 12 или 24 слов на бумажный носитель, сохраните его в надежном месте. Подтвердите фразу, введя несколько слов в интерфейсе MetaMask.
Завершите создание кошелька, нажав «Подтвердить» и «Готово».
Результат
У вас должен быть создан некастодиальный кошелек MetaMask с записанной мнемонической фразой.
