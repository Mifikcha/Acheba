EVM-сети и их особенности
MetaMask поддерживает EVM-сети, такие как Avalanche, Binance Smart Chain, Polygon, Optimism, Base, Blast, Linea, Mantle, ZKSync. Они используют архитектуру Ethereum, но не поддерживают Solana или Bitcoin.

Каждая сеть использует свою монету для оплаты комиссии за транзакцию: ETH для Ethereum, Arbitrum, Base, Blast, Linea, Optimism, ZKSync; AVAX для Avalanche; BNB для Binance Smart Chain; MATIC для Polygon. Ethereum имеет высокую комиссию, другие сети — низкую. Адрес кошелька одинаков для всех EVM-сетей.

Разные сети предлагают уникальные инструменты для DeFi.
Добавление сетей в MetaMask
Добавляйте сети через интерфейс MetaMask: выберите сеть (например, Arbitrum, Polygon), нажмите "Add" и "Approve". Для переключения между сетями используйте выпадающее меню.

Для нестандартных сетей (например, Blast, Mantle) используйте Chainlist: найдите сеть, подключите MetaMask, добавьте. Расширьте интерфейс MetaMask через "Expand View" (три точки → Expand View) для удобства.

Рекомендации
Комбинируйте сети для доступа к различным DeFi-инструментам. Используйте Chainlist для добавления сетей, отсутствующих в MetaMask. Изучите модуль «Криптокошельки» для обзора функций MetaMask.

Следующий урок покажет, как купить криптовалюту через P2P на Bybit и вывести на MetaMask. Работайте в сетях с низкими комиссиями для экономии.

В кошельке адрес для всех EVM сетей будет одинаковым в пределах одного суб-аккаунта.
Определения терминов
EVM-сети: Блокчейны, использующие архитектуру Ethereum.

Chainlist: Сервис для добавления сетей в MetaMask.

Комиссия за транзакцию: Плата за проведение операций в сети.

Инструменты
Ресурсы для настройки MetaMask:

MetaMask — Некастодиальный кошелёк для EVM-сетей.
Chainlist — Сервис для добавления сетей.
Bybit — Централизованная биржа для покупки криптовалюты.
