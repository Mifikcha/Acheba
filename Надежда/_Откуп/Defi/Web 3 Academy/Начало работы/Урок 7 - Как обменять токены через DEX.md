Обмен через Web3 Academy Swap
В разделе Exchange на Web3 Academy выберите вкладку Swap. Подключите MetaMask, выберите сеть Arbitrum, укажите небольшую сумму USDT для обмена на токены (например, Arbitrum или эфир).

Для обмена нужен эфир для оплаты газа. Без эфира транзакции невозможны, даже для отправки USDT обратно на биржу. Swap — децентрализованный обмен, активы остаются под вашим контролем, в отличие от централизованных бирж.

Покупка эфира для газа
На Bybit переведите небольшую сумму USDT с аккаунта финансирования на торговый аккаунт. Купите эфир через спотовую торговлю (рыночный ордер). Переведите эфир обратно на аккаунт финансирования, выведите в MetaMask, выбрав сеть Arbitrum.

После вывода эфир появится в MetaMask. Небольшая сумма эфира позволяет совершать множество транзакций благодаря низкой комиссии в Arbitrum. Комиссии в Ethereum выше, в других сетях (Polygon, Avalanche) — чуть выше.

Импорт токенов
После обмена токены (например, Arbitrum) могут не отобразиться в MetaMask. Используйте Arbiscan, найдите контракт токена, скопируйте адрес, импортируйте через «Import tokens» в MetaMask.

Этот процесс повторяется для каждого нового токена (например, USDC). Некоторые кошельки автоматически отображают токены, но MetaMask требует ручного импорта.

Рекомендации
Изучите модуль «Основы безопасности» для понимания кастодиальных и некастодиальных кошельков. Используйте Web3 Academy Swap для децентрализованного обмена. Следующий урок покажет отправку криптовалюты на другие адреса.

Храните активы в MetaMask, а не на Bybit, для полного контроля. Arbitrum подходит для экономии на комиссиях. Проверяйте транзакции в Arbiscan для прозрачности.

Определения терминов
Децентрализованный обмен: Обмен активов без доверия третьим лицам.

Газ: Комиссия за транзакции в блокчейне.

Arbiscan: Блокчейн-обозреватель для сети Arbitrum.
