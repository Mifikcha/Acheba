Интерфейс MetaMask
Главный экран MetaMask отображает баланс в ETH и долларах, список токенов и NFT. Функция "Import Tokens" позволяет добавить токены вручную или через поиск (например, USDC, Wrapped Bitcoin). Раздел "Activity" показывает историю транзакций, а "Portfolio" — более детальный обзор активов.

Кошелёк поддерживает функции Buy/Sell, Swap и Bridge, но их использование не рекомендуется из-за высоких комиссий (~1%). Также доступны: добавление сетей (через Chainlist), создание субаккаунтов для airdrop или стратегий, подключение аппаратных кошельков (например, Ledger).

MetaMask — основа для работы с DeFi и криптовалютами.
Настройки MetaMask
В разделе "General" настройте валюту (рекомендуется доллары) и язык (лучше английский для корректного поиска ошибок). "Advanced" позволяет добавить кастомные RPC для сетей (например, при airdrop), настроить автолок (2–3 минуты) и скрыть токены без баланса.

"Security & Privacy" показывает мнемоническую фразу и включает защиту от фишинга — оставьте её включённой. Отключите передачу данных MetaMask. Лучше использовать встроенные функции безопасности, такие как WalletGuard, для защиты транзакций (Примечание: WalletGuard теперь встроен в MetaMask и автоматически выполняет симуляцию транзакций).

Правильные настройки — залог удобной работы с MetaMask.
Рекомендации
Избегайте Swap и Bridge в MetaMask из-за комиссий — используйте W3A Swap для экономии. Создавайте субаккаунты для airdrop или разных DeFi-стратегий, чтобы разделять позиции. Отключите уведомления и лишние функции (например, экспериментальные, если не нужны).

Для безопасности всегда проверяйте транзакции. Настройте кошелёк под себя, добавляя только необходимые сети и контакты для быстрых переводов. Это упростит работу с криптовалютами.

Определения терминов
Субаккаунт: Дополнительный аккаунт внутри кошелька с отдельным приватным ключом.

RPC: Точка доступа для получения данных о сети (баланс, транзакции).

ENS-домен: Читаемое имя, привязанное к адресу кошелька.
