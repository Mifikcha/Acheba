Установка Core Wallet
Core Wallet доступен как расширение для браузера (например, Chrome) или приложение для iOS/Android. Установите расширение, затем выберите восстановление кошелька через мнемоническую фразу (12 или 24 слова), а не через Google/Apple ID.

После ввода фразы задайте имя кошелька и пароль. Это стандартный процесс для создания аккаунта. Использование фразы обеспечивает полный контроль над кошельком, что важно для безопасности.

Core Wallet — инструмент для работы с нативным BTC.
Интерфейс Core Wallet
Кошелёк поддерживает сети Avalanche, Ethereum и Bitcoin (нативный BTC). Основные функции включают: Assets, NFT Gallery, Transactions, Staking, Swap, Bridge (BTC → BTC.b), Network Management, Account Management, View on Explorer, Connect to Apps, Notifications, Help and Support.

Core Wallet позволяет работать с субаккаунтами и несколькими мнемоническими фразами в одном интерфейсе, что отличает его от MetaMask. Сети добавляются вручную или через Chainlist, а встроенный мост переносит BTC в сеть Avalanche.

Мост в Core Wallet — ключ к использованию BTC в DeFi.
Настройки Core Wallet
В "General Settings" настройте язык (рекомендуется английский из-за ошибок перевода) и валюту. "Security Settings" позволяют отключить передачу данных разработчикам, чтобы защитить приватность. Проверьте мнемоническую фразу в настройках.

"Network Settings" включают добавление сетей вручную или через Chainlist. В "Advanced Settings" отключите Testnet Mode и скрытие токенов без баланса, если они не нужны. Это упрощает работу с кошельком.

Рекомендации
Используйте Core Wallet только для переноса BTC в BTC.b через встроенный мост, чтобы затем применять их в DeFi на сети Avalanche. Для других задач предпочтительнее MetaMask, так как Core Wallet может подтормаживать и имеет проблемы с подключением.

Настраивайте кошелёк на английском языке, чтобы избежать ошибок перевода. Если интерфейс вам подходит, используйте его, но для большинства функций MetaMask остаётся более удобным и надёжным выбором.

Определения терминов
BTC.b: Обёрнутая версия биткоина для использования в DeFi на сети Avalanche.

Субаккаунт: Дополнительный аккаунт внутри кошелька с отдельным приватным ключом.

Мнемоническая фраза: Набор слов для восстановления кошелька и доступа к средствам.

Инструменты
Ресурсы для работы с Core Wallet:

Core Wallet — Кошелёк для управления BTC и работы с Avalanche.
Chainlist — Сервис для добавления блокчейн-сетей в кошелёк.
