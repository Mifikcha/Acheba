Обзор Rabby Wallet
Rabby Wallet работает только с EVM-сетями (например, Ethereum, Avalanche), не поддерживая не-EVM сети, такие как Solana. Это кошелёк для DeFi, но не мультивалютный в широком смысле.

Главное преимущество — встроенная защита от скама (аналог WalletGuard), которая не требует дополнительных расширений. Кошелёк подходит для пользователей, ищущих альтернативу MetaMask с повышенной безопасностью.

Rabby Wallet — безопасный выбор для EVM-сетей.
Интерфейс Rabby Wallet
Установка проста: импортируйте мнемоническую фразу или подключите аппаратные кошельки (Ledger, Trezor) через WalletConnect. Интерфейс включает: Send/Receive, Swap (не рекомендуется), NFT, History (с фильтром от скама), Gastopup, Approvals, Dapps (список проверенных приложений).

Поддерживает субаккаунты, которые совпадают с MetaMask, Core Wallet и OKX Wallet. Сети добавляются через Chainlist или вручную. Функция Dapps помогает безопасно находить децентрализованные приложения, такие как Uniswap.

Встроенная защита от скама
Rabby Wallet предупреждает об опасности при подключении к сайту: низкая популярность, малый возраст адреса (например, 15 дней), EOA вместо смарт-контракта. Это снижает риск подключения к фейковым сайтам.

При подписании транзакций кошелёк блокирует подозрительные действия, показывая, например, апрув на триллионы USDT или отсутствие истории взаимодействия с адресом. Кнопка подписи неактивна, пока не снимете предупреждения.

Защита Rabby Wallet — надёжный барьер против скама.
Настройки Rabby Wallet
Настройки включают управление субаккаунтами, подключёнными Dapps и whitelist для адресов (например, биржи), чтобы пропускать проверки. Сети добавляются вручную или через Chainlist, с поддержкой кастомных RPC.

Autolog (рекомендуется 1 час) выводит на экран ввода пароля. Можно очистить неподтверждённые транзакции, настроить язык и тему. Исключения для MetaMask позволяют работать с двумя кошельками без конфликтов.

Рекомендации
Не используйте Swap и Gastopup в Rabby Wallet из-за возможных комиссий — лучше выбрать W3A Swap. Используйте Approvals для отзыва разрешений и Dapps для поиска проверенных приложений, избегая скама.

Rabby Wallet — хорошая альтернатива MetaMask для EVM-сетей благодаря защите от скама. Для не-EVM сетей (например, Solana) используйте мультивалютные кошельки, такие как OKX Wallet, или специализированные приложения.

Определения терминов
Субаккаунт: Дополнительный аккаунт внутри кошелька с отдельным приватным ключом.

EOA: Адрес, управляемый приватным ключом, а не смарт-контрактом (External Owned Account).

Approvals: Разрешения на доступ к вашим активам, выданные смарт-контрактам.

Инструменты
Ресурсы для работы с Rabby Wallet:

Rabby Wallet — Кошелёк для EVM-сетей с защитой от скама.
Chainlist — Сервис для добавления блокчейн-сетей в кошелёк.
