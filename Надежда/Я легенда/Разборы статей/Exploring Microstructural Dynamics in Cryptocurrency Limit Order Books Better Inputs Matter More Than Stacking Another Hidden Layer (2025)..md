# 2. Введение (Introduction)

## Роль LOB в формировании цены

В электронных рынках цена формируется через **limit order book (LOB)**.

LOB содержит:

* заявки на покупку (bids)
* заявки на продажу (asks)

Каждый уровень книги показывает:

```
price
volume
```

---

## Микроструктурная гипотеза

Авторы утверждают:

на высоких частотах цена определяется **дисбалансом спроса и предложения в LOB**.

Фундаментальные новости играют **меньшую роль**. 

Поэтому:

```
LOB → главный источник сигналов
```

---

## Особенности крипторынка

Криптовалютные рынки отличаются от традиционных:

| традиционные рынки | крипта       |
| ------------------ | ------------ |
| торговые часы      | 24/7         |
| регулирование      | слабее       |
| ликвидность        | распределена |

---

Это делает:

```
алгоритмические стратегии особенно важными
```

# 4. Feature Engineering

Авторы создают несколько **ручных признаков** из LOB.

---

## 1. Mid-price

[
$m_t$ = $\frac{a_t^1 + b_t^1}{2}$
]

где

* (a_t^1) — лучший ask
* (b_t^1) — лучший bid.

Это **справедливая цена** в данный момент. 

---

## 2. Order imbalance (1 уровень)

[
I_t^1 =
\frac{Q^b_{t,1} - Q^a_{t,1}}
{Q^b_{t,1} + Q^a_{t,1}}
]

где:

* ($Q^b$) — объём bid
* ($Q^a$) — объём ask.

Это показывает:

```
кто сильнее — покупатели или продавцы
```

---

## 3. Aggregate imbalance (5 уровней)

[
I_t^5 =
$\frac{\sum $Q^b$ - \sum Q^a}
{\sum $Q^b$ + \sum Q^a}$
]

Это более стабильный показатель дисбаланса.

---

## 4. Weighted mid-price change

Авторы используют взвешенные изменения mid-price.

Идея:

```
более близкие уровни важнее
```

# 5. Модели, которые сравниваются

Исследование тестирует **6 моделей**.

---

## 1. Logistic Regression

Самая простая модель.

Плюсы:

* быстрая
* интерпретируемая
* устойчива к шуму.

Обычно точность:

```
48–64%
```

на LOB datasets. 

---

## 2. XGBoost / CatBoost

Gradient Boosted Trees.

Используют:

* nonlinear зависимости
* ensemble learning.

---

## 3. CNN + LSTM

Нейросеть:

```
CNN → извлекает spatial features
LSTM → temporal dependencies
```

---

## 4. DeepLOB

Одна из самых известных архитектур.

Структура:

```
CNN layers
→ LSTM
→ classifier
```

Она автоматически учит **feature representations**.

---

## 5. CNN + XGBoost

Гибридная модель:

```
CNN → embedding
XGBoost → prediction
```

---

# 6. Формулировка задачи (Classification)

Прогнозируется **движение mid-price**.

Две постановки:

---

## Binary classification

```
up / down
```

---

## Ternary classification

```
up / flat / down
```

---

Причина ternary подхода:

если игнорировать "flat", модель начинает принимать шум за движение.

---

# 7. Проблема шума

LOB snapshots очень шумные.

Причины:

* flickering orders
* быстрые отмены заявок
* маркетмейкеры

Это создаёт **очень низкое signal-to-noise ratio**. 

---

# 8. Методы фильтрации данных

Авторы применяют **два метода сглаживания**.

---

## Savitzky–Golay filter

Это метод сглаживания временных рядов.

Идея:

вместо простого усреднения он **аппроксимирует локальный полином**.

Формально:

минимизируется ошибка

[
\sum (v_{t+j} - polynomial(j))^2
]

в окне наблюдений. 

---

## Kalman filter

Kalman рассматривает наблюдения как:

```
true price + noise
```

Модель:

[
$x_t$ = x_{t-1} + w_t
]

[
$v_t$ = $x_t$ + ε_t
]

Фильтр оценивает **скрытую истинную цену**.

# 11. Основные результаты

## 1. Фильтрация данных улучшает результаты

Savitzky–Golay фильтр **почти всегда улучшает точность**.

Например:

для 500ms горизонта:

```
accuracy ≈ 0.52–0.54
```

после сглаживания. 

---

## 2. Сложные нейросети не дают большого преимущества

Результаты моделей **очень близки**.

Иногда:

```
XGBoost > DeepLOB
```

---

## 3. Prediction horizon влияет на точность

Чем длиннее горизонт:

```
100ms → хуже
1000ms → лучше
```

Потому что шум сглаживается.
