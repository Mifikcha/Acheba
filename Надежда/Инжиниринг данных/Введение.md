# Кто такой Дата-инженер ?

Дата-инженер обычно отвечает за **управление рабочими процессами**, **конвейерами** обработки и **ETL-процессами**
1. Сбор
2. Перемещение и хранение
3. Подготовка данных
4. Агрегация данных

# Нужные навыки

1. **Знание SQL** (различных диалектов) и Python.
2. Опыт работы с **облачными платформами**, в частности Amazon Web Services (AWS), Y.Cloud, VK.Cloud, Azure.
3. Предпочтительно знание **Java/Scala**.
4. Хорошее понимание баз данных **SQL и NoSQL** (моделирование данных, хранение данных).
# Для Big Data

1. Опыт работы с большими данными: Hadoop, Spark, Kafka.
2. Знание алгоритмов и структур данных.
3. Понимание основ распределенных систем.
4. Опыт работы с инструментами визуализации данных, такими как Tableau или ElasticSearch, будет большим плюсом.

# Источники данных

1. Логи поведения пользователей в интернете
2. GPS-сигналы от автомобилей для транспортной компании
3. Данные, снимаемые с датчиков в большом адронном коллайдере
4. Оцифрованные книги в Российской Государственной Библиотеке
5. Информация о транзакциях всех клиентов банка
6. Информация о всех покупках в крупной ритейл сети и т.д.

# Типы взаимодействия с потоками данных

1. off-line
2. псевдо real-time (пакетная)
3. real-time

# ETL. Extract Transform Load

1. Извлечение
2. Трансформация
	1. очистка
	2. агрегирование
	3. фильтрация
	4. объединение
	5. нормализация
	6. обогащение
3. Загрузка

# Конвейеры

Конвейеры - **серия шагов по обработке, необходимых для подготовки корпоративных данных к анализу**

1. Завершенность
2. Воспроизводимость
3. Отказоустойчивость
4. Горизонтальная масштабируемость
