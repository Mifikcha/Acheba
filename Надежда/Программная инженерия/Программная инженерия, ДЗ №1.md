3) Запрос POST на https://jsonplaceholder.typicode.com/

Изначально запрос POST планировалось реализовать на VK API, однако для этого нужен расширенный доступ к приложению, для чего нужна авторизация разработчика приложения по паспорту, а для этого требуется запрос, который будут одобрять некоторое время.

Поэтому было решено сделать POST запрос на вышеуказанной платформе.

```python
import requests
import json
url = 'https://jsonplaceholder.typicode.com/posts'
headers = {
    'Content-type': 'application/json; charset=UTF-8',
}
data = {
    'title': 'foo',
    'body': 'bar',
    'userId': 1,
}
response = requests.post(url, headers=headers, data=json.dumps(data))
json_response = response.json()
print(json_response)
```

Результат:

```
{'title': 'foo', 'body': 'bar', 'userId': 1, 'id': 101}
```
