Найдите страны с продолжительностью жизни выше среднего по миру. Отсортируйте результат по убыванию продолжительности жизни и выведите колонки с названием страны и продолжительностью жизни "Country" и "Life Expectancy" соответственно.

Сохраните результат в CSV-файл с именем `high_life_expectancy_countries.csv`.

К файлу-источнику можно обратиться по имени `world-data-2023.csv`.

Источник данных - [https://www.kaggle.com/datasets/nelgiriyewithana/countries-of-the-world-2023](https://www.kaggle.com/datasets/nelgiriyewithana/countries-of-the-world-2023)

## Примечания

Необходимо использовать библиотеку **pandas**.

Файл-источник и файл с результатом должны находиться в одной директории с исполняемым скриптом.
