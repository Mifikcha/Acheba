Создайте таблицу, включающую только страны с плотностью населения (Density (P/Km2)) выше 100 человек на квадратный километр.

Сохраните результат в файл `high_density_countries.csv`.

К файлу-источнику можно обратиться по имени `world-data-2023.csv`.

Источник данных - [https://www.kaggle.com/datasets/nelgiriyewithana/countries-of-the-world-2023](https://www.kaggle.com/datasets/nelgiriyewithana/countries-of-the-world-2023)
