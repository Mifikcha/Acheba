Напишите функцию, которая принимает массив и стандартизует его, затем возвращает результат, используя библиотеку **numpy**.

Функция должна принимать массив, а затем возвращать его стандартизованный вариант, чтобы получить новый массив со средним значением 0 и стандартным отклонением 1. Результат операции выведите с помощью `return`.

Аргумент - массив целых чисел.

## Формат ввода

```
[[ 6 10  3  2  1]
 [ 2  5  5  6  4]
 [ 0  1  1  9  3]
 [ 0  7  1  6  9]
 [ 9  0  0  8  8]]
```

## Формат вывода

```
[[ 0.531085    1.73809638 -0.37417353 -0.67592637 -0.97767921]
 [-0.67592637  0.22933216  0.22933216  0.531085   -0.07242068]
 [-1.27943206 -0.97767921 -0.97767921  1.43634354 -0.37417353]
 [-1.27943206  0.83283785 -0.97767921  0.531085    1.43634354]
 [ 1.43634354 -1.27943206 -1.27943206  1.13459069  1.13459069]]
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.

Стандартизация — это процесс преобразования данных так, чтобы они имели среднее значение (mean) 0 и стандартное отклонение (standard deviation) 1. Это достигается путем вычитания среднего значения из каждого элемента массива и деления результата на стандартное отклонение.

Стандартизация обычно используется для того, чтобы привести данные к одному масштабу и упростить анализ.
