Напишите функцию, которая принимает один аргумент и возвращает несколько объектов, используя библиотеку **numpy**.

Функция должна создавать две матрицы из чисел, а затем возвращать их матричное умножение и вычисление определителя. Созданные исходные массивы и результат операций выведите с помощью `return`.

Аргумент должен задавать размер исходных массивов.

Наполнение массивов можете производить на свое усмотрение.

## Формат ввода

your_func_name((2, 2))

## Формат вывода

```
[[0.2089887  0.34730663]
 [0.54341372 0.31938997]]

[[0.92366727 0.12491969]
 [0.16590297 0.77896661]]

[[0.25065522 0.29664707]
 [0.55492121 0.3166772 ]]

-0.12198229019198184

0.6987814199802299
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.

Также, вероятно вам пригодится оператор распаковки аргументов - `*`.
