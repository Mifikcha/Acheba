Напишите функцию, которая принимает три аргумента и возвращает несколько объектов, используя библиотеку **numpy**.

Функция должна создавать массив из случайных целых чисел и находить среднее, медиану и стандартное отклонение. Созданный массив и результаты операций выведите с помощью `return`.

Первый аргумент должен задавать размер массивов, второй и третий - нижнюю и верхнюю границу диапазона возможных значений соответственно.

## Формат ввода

your_func_name((4, 4), 1, 100)

## Формат вывода

```
[[77 65 47 58]
 [ 7 25  4 61]
 [87 83 56 38]
 [53 57 87 84]]

55.5625

57.5

25.573347331743648
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.
