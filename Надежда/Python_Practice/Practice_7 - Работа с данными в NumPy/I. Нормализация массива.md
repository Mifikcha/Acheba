Напишите функцию, которая принимает массив и нормализует его, затем возвращает результат, используя библиотеку **numpy**.

Функция должна принимать массив, а затем возвращать его нормализованный вариант (приведите значения к диапазону от 0 до 1). Результат операции выведите с помощью `return`.

Аргумент - массив целых чисел.

## Формат ввода

```
[[ 1  0  7  1 10]
 [ 7  5  4  5  0]
 [ 4  5  8  1  9]
 [ 1  3  7  9  7]
 [ 3  5  9  6  6]]
```

## Формат вывода

```
[[0.1 0.  0.7 0.1 1. ]
 [0.7 0.5 0.4 0.5 0. ]
 [0.4 0.5 0.8 0.1 0.9]
 [0.1 0.3 0.7 0.9 0.7]
 [0.3 0.5 0.9 0.6 0.6]]
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.
