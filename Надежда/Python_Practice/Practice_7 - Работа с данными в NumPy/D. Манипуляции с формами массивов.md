Напишите функцию, которая принимает два аргумента и возвращает два массива, используя библиотеку **numpy**.

Функция должна создавать массив из чисел, а затем изменить его форму. Созданный исходный массив и результат операции выведите с помощью `return`.

Первый аргумент должен задавать размер исходного массива, второй - размер нового массива.

Наполнение массивов можете производить на свое усмотрение.

## Формат ввода

your_func_name((3, 5), (15, 1))

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.

Также, вероятно вам пригодится оператор распаковки аргументов - `*`.
