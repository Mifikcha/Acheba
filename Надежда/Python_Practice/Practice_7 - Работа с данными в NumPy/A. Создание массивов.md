
Напишите функцию, которая принимает три аргумента и возвращает массив случайных целых чисел, используя библиотеку **numpy**.

Первый аргумент должен задавать размер массива, второй и третий - нижнюю и верхнюю границу диапазона возможных значений соответственно.

## Формат ввода

your_func_name((2, 3), 1, 100)

## Формат вывода

```
[[81  9  7]
 [84 96 58]]
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.
