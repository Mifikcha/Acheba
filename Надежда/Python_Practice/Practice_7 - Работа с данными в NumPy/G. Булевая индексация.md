Напишите функцию, которая принимает два аргумента и возвращает массив, используя библиотеку **numpy**.

Функция должна создавать массив из чисел, а затем возвращать значения меньше порога. Созданный исходный массив и результат операции выведите с помощью `return`.

Первый аргумент должен задавать размер исходного массива, второй - величину порога.

Наполнение массивов можете производить на свое усмотрение.

## Формат ввода

```
your_func_name((5, 2), 0.5)
```

## Формат вывода

```
[[0.78991318 0.33918389]
 [0.76761876 0.37521751]
 [0.43603319 0.12336686]
 [0.24135151 0.64178222]
 [0.08517563 0.99047733]]

[0.33918389 0.37521751 0.43603319 0.12336686 0.24135151 0.08517563]
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.

Также, вероятно вам пригодится оператор распаковки аргументов - `*`.
