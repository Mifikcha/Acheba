Напишите функцию, которая принимает массив и число, затем возвращает объект, используя библиотеку **numpy**.

Функция должна принимать массив из целых чисел, а затем возвращать произведение всех значений, кратных заданному числу. Результат операции выведите с помощью `return`.

Первый аргумент - массив целых чисел, второй - делитель.

Наполнение массивов можете производить на свое усмотрение.

## Формат ввода

```
input_array = [[ 84 -74  23  81 -62]
 [  5 -96 -91 -55  47]
 [ 42 -16 -12  98  55]
 [ 19 -51  41  -9  98]
 [-22  -2  85  32 -62]]

your_func_name(input_array , 2)
```

## Формат вывода

```
-8121445126233915392
```

## Примечания

Необходимо использовать библиотеку **numpy**.

В решении требуется только объявленная функция - вызов функции и ввод-вывод данных осуществляется на этапе тестирования.
