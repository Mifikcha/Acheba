1. Размеры точек: Задайте размеры точек пропорционально значениям y, используя формулу `size = y * 10`, чтобы точки с более 2 высокими значениями y были крупнее.
    
2. Цветовая карта: Примените цветовую карту `viridis` для раскраски точек в зависимости от значения y.
    
3. Подписи осей: Установите подпись оси x как "Значение x" и оси y как "Значение y".
    
4. Заголовок: Назовите график "Диаграмма рассеяния с цветовой картой".
