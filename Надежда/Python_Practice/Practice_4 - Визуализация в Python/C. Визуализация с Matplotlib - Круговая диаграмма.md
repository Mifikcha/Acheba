## Примечания

Используйте следующие импорты:

```
import matplotlib.pyplot as plt
```

для визуализации данных.

Также необходимо использование `autopct` для отображения процентного значения с использованием форматирования строк Python.

`autopct='%1.1f%%'` означает, что для каждого сектора круга строка формата будет выглядеть как `'1.1f%'`.
