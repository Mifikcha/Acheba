Расширьте класс **Book**, добавив булевый атрибут `is_available`, который будет указывать, доступна ли книга для выдачи. Реализуйте методы `checkout` и `return_book` для выдачи и возврата книг, изменяющие доступность.

## Формат ввода

```
author = Author("Антон", "Чехов", "1860-01-29")
book = Book("Три сестры", author, 1901)

print(book.book_info())  # Книга доступна
book.checkout()
print(book.book_info())  # Книга недоступна
book.return_book()
print(book.book_info())  # Книга снова доступна
```

## Формат вывода

```
True
False
True
```
