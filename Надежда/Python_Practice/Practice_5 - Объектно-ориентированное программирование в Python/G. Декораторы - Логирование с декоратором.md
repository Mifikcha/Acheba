Напишите декоратор **log**, который будет записывать в консоль имя функции и аргументы, с которыми она была вызвана.

## Формат ввода

```
@log
def factorial(n):
    """Вычисляет факториал числа n."""
    if n == 0:
        return 1
    return n * factorial(n - 1)

# Пример использования
result = factorial(5)
print(result)
```
