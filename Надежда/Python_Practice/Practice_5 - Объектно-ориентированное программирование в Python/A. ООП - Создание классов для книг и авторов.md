Реализуйте класс **Author**, который будет содержать:

- имя (first_name)
- фамилию (last_name)
- дату рождения (birth_date)
- метод full_name, возвращающий полное имя автора в виде строки

Затем создайте класс **Book**, который будет содержать:

- название (title)
- автора (author - экземпляр класса **Author**)
- год издания (publication_year)
- метод book_info, возвращающий следующую информацию о книге в виде форматированной строки:

`'1984', Джордж Оруэлл, опубликована в 1949`

Пример использования:

```
author1 = Author("Джордж", "Оруэлл", "1903-06-25")

book1 = Book("1984", author1, 1949)
```
