### Метод Violinplot

plt.violinplot() — это функция в библиотеке Matplotlib, которая используется для создания скрипичных диаграмм. Эти диаграммы представляют собой более информативный вариант ящиковых диаграмм, поскольку они отображают плотность распределения данных в каждой точке.

```python

matplotlib.pyplot.violinplot(data, vert=True, widths=0.5, showmeans=False, 
showextrema=True, showmedians=False, quantiles=None, points=100, bw_method=None, side='both', *, data=None)
```

Основные параметры

- data: Обязательный параметр. Может быть массивом, списком или DataFrame. Определяет данные, которые будут использованы для построения скрипичных диаграмм.
- vert: Булевый параметр. Если True (по умолчанию), скрипки будут ориентированы вертикально. Если False, то горизонтально.
- widths: Число или массив чисел. Определяет ширину скрипок.
- showmeans: Булевый параметр. Если True, то на графике будут отображены средние значения для каждой группы.
- showmedians: Булевый параметр. Если True, то на графике будут отображены медианы для каждой группы.
- points: Число. Определяет количество точек, используемых для аппроксимации плотности.
- bw_method: Метод подбора ширины окна для оценки плотности.

Дополнительные параметры для настройки внешнего вида

- patch_artist: Булевый параметр. Если True, то скрипки будут заполнены цветом.
- color: Цвет или список цветов для скрипок.
- facecolor: Цвет заливки скрипок.
- edgecolor: Цвет границ скрипок.
- linewidths: Ширина границ скрипок.
- labels: Список строк. Используется для подписи скрипок.

#### Пример

```python

# Создадим графики распределения данных в виде скрипичной диаграммы
import numpy as np
import matplotlib.pyplot as plt

# создадим данные с равномерными распределением
uniform = np.arange(-100, 100)

# создадим данные с нормальным распределением
normal = np.random.normal(size = 100)*30

# добавим два графика
fig, (ax1, ax2) = plt.subplots(nrows = 1,
                               ncols = 2,
                               figsize =(9, 4),
                               sharey = True)

# создадим график для равномерного распределения
ax1.set_title('Uniform Distribution')
ax1.set_ylabel('Observed values')
ax1.violinplot(uniform)

# создадим график для нормального распределения
ax2.set_title('Normal Distribution')
ax2.violinplot(normal)

#обязательно в файлах .py
plt.show()
```
