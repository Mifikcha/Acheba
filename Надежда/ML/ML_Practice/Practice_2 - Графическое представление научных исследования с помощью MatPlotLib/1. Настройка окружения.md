Ознакомиться с библиотеками matplotlib для графического представления данных в Python.

Графики являются одним из самых важных инструментов в арсенале data scientist'а. Они позволяют визуально оценить, как распределены данные в вашем наборе данных. Это помогает:

- Обнаружить выбросы: Значения, значительно отклоняющиеся от остальных данных.
- Оценить нормальность распределения: Многие статистические методы предполагают нормальное распределение данных.
- Сравнить распределения разных групп: Например, сравнить распределение признака у разных классов в задаче классификации.
- Выбрать подходящие методы преобразования данных, например нормализацию или стандартизацию данных.

Выбор библиотеки для построение графиков:

- Matplotlib: наиболее гибкий, предлагает широкий спектр возможностей настройки, подходит для низкоуровневого управления и сложных графиков.
- Seaborn: высокоуровневый интерфейс, созданный на основе Matplotlib, упрощает общие задачи визуализации благодаря встроенным темам и стилям, что хорошо подходит для статистических графиков.
- Plotly : интерфейс высокого уровня для интерактивной и динамической визуализации, идеально подходящий для веб-приложений и информационных панелей
