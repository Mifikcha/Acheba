### Гистограммы

Данный тип диаграммы позволяет визуализировать распределение данных, разделяя их на интервалы (bins) и подсчитывая количество точек данных, попадающих в каждый интервал.

Распределения данных в виде гистограммы в pyplot можно построить с помощью метода hist или plot(kind='bar').

```python

n, bins, patches = plt.hist(data, bins=None, range=None, density=False, 
weights=None, cumulative=False, **kwargs)
```

Основные параметры функции plt.hist():

data: Массив или список значений, для которых нужно построить гистограмму.

Необязательные:

- bins: Число интервалов (bins) на оси x. Можно указать: Целое число: будет создано указанное количество интервалов с равными шириной. Массив: будут использованы заданные границы интервалов. Функция: будет использована для динамического определения границ интервалов.
- range: Диапазон значений данных, для которых будет построена гистограмма. Указывается в виде списка из двух элементов: [начало, конец].
- density: Если True, вместо частоты (количества точек данных) на оси y будет отображаться плотность распределения (нормированная на единицу).
- weights: Массив весов для каждой точки данных. Вес влияет на вклад точки данных в расчет частоты/плотности в каждом интервале.
- cumulative: (по умолчанию False) Если True, будет построена накопительная гистограмма.
- histtype: Тип гистограммы: 'bar' (стандартная), 'step', 'stepfilled'.
- align: Выравнивание баров: 'mid', 'left', 'right'.
- orientation: Ориентация гистограммы: 'vertical' или 'horizontal'.
- color: Цвет баров. *edgecolor: Цвет границ баров.
- label: Метка для легенды.

Возвращаемые значения:

- n: Массив, содержащий количество элементов в каждом интервале (бинне). Это фактически высоты столбцов гистограммы.
- bins: Массив, содержащий границы интервалов. Он на один элемент длиннее, чем массив n, так как включает в себя левую границу первого интервала и правую границу последнего.
- patches: Список объектов Patch, представляющих каждый столбец гистограммы. Эти объекты можно использовать для дальнейшей настройки
- внешнего вида столбцов, например, изменения цвета, ширины или прозрачности.

#### Пример:

```python

import matplotlib.pyplot as plt
import numpy as np

# Данные
data = np.random.randn(1000)

# Построим гистограмму для 20 интервалов, зададим границы черным цветом
plt.hist(data, bins=20, edgecolor='black')

# Настройка заголовка и подписей осей
plt.title('Гистограмма')
plt.xlabel('Значение')
plt.ylabel('Частота')

# Отображение сетки
plt.grid(True)

# Отображение графика
plt.show()
```

# Пример использования возвращаемых значений:
import matplotlib.pyplot as plt
import numpy as np

# Создаем случайные данные
data = np.random.randn(1000)

# Строим гистограмму и сохраняем возвращаемые значения
n, bins, patches = plt.hist(data, bins=30, density=True)

# Выводим значения для первых 5 интервалов
print("Количество элементов в первых 5 интервалах:", n[:5])
print("Границы первых 5 интервалов:", bins[:6])

# Изменяем цвет первых 5 столбцов
for patch in patches[:5]:
    patch.set_facecolor('r')

plt.show()
```

# Добавление нескольких типов графиков на одну систему координат
import matplotlib
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(10**7)
mu = 121
sigma = 21
x = mu + sigma * np.random.randn(1000)

num_bins = 100

n, bins, patches = plt.hist(x, num_bins,
                            density = 1,
                            color ='green',
                            alpha = 0.7)

y = ((1 / (np.sqrt(2 * np.pi) * sigma)) *
     np.exp(-0.5 * (1 / sigma * (bins - mu))**2))

plt.plot(bins, y, '--', color ='black')

plt.xlabel('X-Axis')
plt.ylabel('Y-Axis')

plt.title('Гистограмма распределения данных\n\n',
          fontweight = "bold")

plt.show()
```
