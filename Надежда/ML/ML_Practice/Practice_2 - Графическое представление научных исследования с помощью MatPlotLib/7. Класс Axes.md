Класс Axes() - это область, где отображаются данные, включая оси, метки, линии и другие элементы графика. Он позволяет создавать несколько подграфиков на одном полотне.

Создавать и получать доступ к областям axes внутри контейнера можно несколькими способами. Рассмотрим основные:

## Метод subplots:

plt.subplots() cоздает нескольких графиков на одной фигуре. Он позволяет организовать данные в сетку, что особенно полезно при сравнении различных наборов данных или при отображении многомерных данных.

```python

import matplotlib.pyplot as plt

fig, axes = plt.subplots(nrows, ncols, index)

```

Параметры:

- nrows: Количество строк в сетке.
- ncols: Количество столбцов в сетке.
- index: Позиция подграфика в сетке, нумерация начинается с 1 в верхнем левом углу и идет слева направо и сверху вниз. Возвращаемые значения (необязательно):
    
- fig - контейнер с графиками
- axes - объект Axes или массив объектов Axes, в зависимости от количества созданных координатных осей.

#### Пример

```python

import matplotlib.pyplot as plt

# по-умолчанию создает фигуру с одним Axes (графиком)
fig, ax = plt.subplots()
```

Обращаться к объектам axes можно по их индексу в массиве или в методе subplot

#### Пример

```python

import numpy as np
import matplotlib.pyplot as plt

# Создаем данные
x = np.linspace(0, 2 * np.pi, 100)
y1 = np.sin(x)
y2 = np.cos(x)

plt.figure(figsize=(10, 4))
# Создаем фигуру с двумя подграфиками в одной строке. Обращаемся по index к первому графику
plt.subplot(1, 2, 1)
plt.plot(x, y1)
plt.title('Синус')

# Обращаемся ко второму графику
plt.subplot(1, 2, 2)
plt.plot(x, y2, color = 'red')
plt.title('Косинус')

plt.show()
```

Для того чтобы добавить отступы между графиками на сетке воспользуемся методом tight_layout

```python

matplotlib.pyplot.tight_layout(*, pad=1.08, h_pad=None, w_pad=None, rect=None)
```

- pad:float, по-умолчанию =1.08. Отступ между краем рисунка и краями подграфиков, в долях от размера шрифта.
    
- h_pad, w_pad: float, default: pad. Отступ (высота/ширина) между краями смежных подграфиков, как доля размера шрифта.
    

#### Пример

```python

import matplotlib.pyplot as plt
import numpy as np

# Создаем фигуру с двумя подграфиками. Сохраняем в переменные fig и axes контейнер и массив подграфиков
fig, axes = plt.subplots(nrows=2, ncols=1)

# Строим данные на первом подграфике
x = np.linspace(0, 2 * np.pi, 100)
y1 = np.sin(x)
axes[0].plot(x, y1)
# Добавим два графика на второй координатной оси.
y2 = np.cos(x)
y3 = np.cos(x*x)
axes[1].plot(x, y2)
axes[1].plot(x, y3)
#добавим отступы между графиками
plt.tight_layout(pad=1.08, h_pad=5,w_pad=0)
plt.show()
```

### Класс Axes

Объекты класса Axes можно добавлять отдельно внутри контейнера.

Например если создать объекта класса через одноименный метод plt.axes и указать координаты графика, он создаст координатную ось и добавит её в определенной позиции внутри полотна

```python

plt.axes(rect, **kwargs)
```

Параметры:

- rect: list, tuple. Список с координатами точки и размером графика
- **kwargs: другие параметры характерные для класса Axes

#### Пример

```python

import matplotlib.pyplot as plt

fig = plt.figure()
ax = plt.axes((0.1, 0.1, 0.8, 0.8), facecolor='yellow')  # [left, bottom, width, height]
ax = plt.axes([0.65, 0.6, 0.2, 0.2], facecolor='grey')  # [left, bottom, width, height]
```

- объект класс Axes содержит множество встроенных методов. Например ранее рассмотренный метод plot, работает аналогично и для объектов axes

#### Пример

```python

import numpy as np
import matplotlib.pyplot as plt
import numpy as np

# Создаем фигуру с двумя подграфиками. Сохраняем в переменные контейнер и массив подграфиков
fig, axes = plt.subplots(nrows=2, ncols=1)

x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)
axes[0].plot(x, y)
plt.show()
```

- Добавление меток и заголовков: с помощью методов set_xlabel/set_ylabel можно задавать подписи осей, а set_title добавит заголовок для графика.

#### Пример

```python

import numpy as np
import matplotlib.pyplot as plt
import numpy as np

# Создаем фигуру с двумя подграфиками. Сохраняем в переменные контейнер и массив подграфиков
fig, axes = plt.subplots(nrows=2, ncols=1)

x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)
y = np.cos(x)
axes[0].plot(x, y)
axes[0].set_xlabel('x')
axes[0].set_ylabel('y')
axes[0].set_title('Sin')

axes[1].plot(x, y1)
axes[1].set_xlabel('x')
axes[1].set_ylabel('y')
axes[1].set_title('Cos')
plt.tight_layout()
plt.show()
```

- Установка ограничений:
    - методы set_xlim/set_ylim устанавливают ограничения для значений осей.
    - метод set_xticks/set_yticks устанавливает диапазон и шаг значений для осей

#### Пример

```python

import matplotlib.pyplot as plt
import numpy as np

t = np.arange(0.0, 2.0, 0.01)

s1 = np.sin(2 * np.pi * t)
s2 = np.exp(-t)
s3 = s1 * s2

fig, axs = plt.subplots(3, 1, sharex=True)
# Remove vertical space between Axes
fig.subplots_adjust(hspace=0)

# Plot each graph, and manually set the y tick values
axs[0].plot(t, s1)
axs[0].set_yticks(np.arange(-0.9, 1.0, 0.4))
axs[0].set_ylim(-1, 1)

axs[1].plot(t, s2)
axs[1].set_yticks(np.arange(0.1, 1.0, 0.2))
axs[1].set_ylim(0, 1)

axs[2].plot(t, s3)
axs[2].set_yticks(np.arange(-0.9, 1.0, 0.4))
axs[2].set_ylim(-1, 1)
plt.tight_layout()
plt.show()
```

- Добавление аннотаций: метод annotate позволяет добавить текст на график в точку с указанными координатами

```python

plt.annotate(text, xy, xytext=None, xycoords='data', textcoords=None, arrowprops=None)
```

- textstr: Текст аннотации
- xy(float, float): Точка на графике для которой добавляется аннотация.
- xytext(float, float), default: xy. Координаты текстового поля.
- arrowprops: dict. Стиль стрелки.

#### Пример

```python

import matplotlib.pyplot as plt
import numpy as np

# Создаем фигуру с двумя подграфиками
fig, axes = plt.subplots(nrows=2, ncols=1)

# Строим данные на первом подграфике
x = np.linspace(0, 2 * np.pi, 100)
y1 = np.sin(x)
axes[0].plot(x, y1)
axes[0].set_title('Sine')

# Строим данные на втором подграфике
y2 = np.cos(x)
axes[1].plot(x, y2)
axes[1].set_title('Cosine')
# Добавим аннотацию для точки 2,1
axes[0].annotate(text='Важная точка', xy=(2, 1), xytext=(1, 1.5), arrowprops=dict(arrowstyle="->"))
plt.tight_layout()
plt.show()
```
