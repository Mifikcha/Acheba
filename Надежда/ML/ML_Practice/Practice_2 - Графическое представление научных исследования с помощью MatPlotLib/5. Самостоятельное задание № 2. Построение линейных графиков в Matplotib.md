- Измените тип линии. Используйте параметр linestyle в plt.plot(). Например, linestyle='--' для пунктирной линии.
- Добавьте точки. Используйте параметр marker в plt.plot(). Например, marker='o' для кружков.
- Измените цвет линии. Используйте параметр color в plt.plot(). Например, color='red'.
- Добавьте легенду. Используйте plt.legend().
