### Метод scatterplot

plt.scatter() — это функция в библиотеке Matplotlib, которая используется для построения диаграмма рассеивания. Эти диаграммы позволяют визуализировать взаимосвязь между двумя признаками.

```python

matplotlib.pyplot.scatter(x, y, s=None, c=None, marker=None, cmap=None, 
norm=None, vmin=None, vmax=None, alpha=None, 
linewidths=None, *, markers=None, **kwargs)
```

Основные параметры

- x: array или list. Значения для оси x.
- y: array или list. Значения для оси y.
- s: array или list. Размер маркеров.
- c: array или list. Цвет маркеров.
- marker: str. Тип маркера (например, 'o', 's', '^', '*').

#### Пример

```python

import matplotlib.pyplot as plt
import numpy as np

# создадим 50 случайных точек
np.random.seed(3)
x = 4 + np.random.normal(0, 2, 50)
y = 4 + np.random.normal(0, 2, len(x))

# размер и цвет зададим случайным образом
sizes = np.random.uniform(15, 80, len(x))
colors = np.random.uniform(15, 80, len(x))

# создадим график
fig, ax = plt.subplots()

#добавим данные
ax.scatter(x, y, s=sizes, c=colors, vmin=0, vmax=100)

#установим ограничения для осей
ax.set(xlim=(0, 8), xticks=np.arange(1, 8),
       ylim=(0, 8), yticks=np.arange(1, 8))

plt.show()
```

#### Пример

```python

import numpy as np
import matplotlib.pyplot as plt

# Создаем случайные данные
np.random.seed(0)
x = np.random.rand(100, 1)
y = 2 + 3 * x + np.random.randn(100, 1)

# Строим график рассеяния
plt.scatter(x, y, label='Данные')

# Добавляем линию регрессии
plt.plot(x, 2 + 3 * x, color='red', label='Линия регрессии')

# Добавляем подписи осей и легенду
plt.xlabel('Признак')
plt.ylabel('Целевая переменная')
plt.legend()

plt.show()
```
