Для первоначального знакомства с датасетом полезно посмотреть на сами данные. Для этого в Pandas есть методы `head()` и `sample()`.

1. **Метод `head()`**:
    
    - Возвращает первые `n` строк DataFrame.
    - Полезен для быстрой проверки структуры и содержимого данных.
    - Параметры метода `head()`:
        - `n: int` — количество строк для вывода. По умолчанию 5.
2. **Метод `sample()`**:
    
    - Возвращает случайную выборку элементов по указанной оси.
    - Полезен для исследовательского анализа данных, обучения модели или любой ситуации, когда вам требуется случайное подмножество ваших данных.
    - Параметры метода `sample()`:
        - `n: int` — количество элементов для возврата.
        - `frac: float` — доля элементов для возврата.
        - `replace: bool` — разрешить или запретить выборку одной и той же строки более одного раза (по умолчанию False).
        - `weights: float` — веса для выборки.
        - `random_state: int` — начальное значение для генератора случайных чисел.
        - `axis: int` — ось для выборки (0 для строк, 1 для столбцов).

---

### Формат ввода:

**Загрузите данные из файла `books_part15.csv`:**

1. Выведите первые 3 строки с помощью метода `head()`.
2. Выведите случайные 5 строк с помощью метода `sample()`.
3. Выведите 2% случайных данных с помощью параметра `frac=0.02`.
4. Выберите строки с возможностью повторения.

Пример:

```python
import pandas as pd

# Загрузим данные в переменную df_books
df_books = pd.read_csv("books_part15.csv")

# Установим столбец 'ISBN' как индекс
df_books.set_index('ISBN', inplace=True)

# Выведем список столбцов
print(f"Список столбцов: \n {df_books.columns}", end='\n')

# Выведем первые три строки
print(f"Первые три строки: \n {df_books.head(3)}", end='\n')

# Выведем случайные 5 строк
print(f"\n\nСлучайные 5 строк: \n {df_books.sample(5)}", end='\n')

# Выведем 2% случайных строк
print(f"\n\n2% случайных строк: \n {df_books.sample(frac=0.02)}", end='\n')

# Выборка с возможностью повторений
print(f"\n\nВыборка с возможностью повторений: \n {df_books.sample(n=5, replace=True)}")
```

Этот код позволяет вам загрузить данные из файла, выбрать случайные строки, а также проверить первые строки данных для быстрой оценки структуры и содержимого.
