Основные форматы файлов для хранения данных:

- **CSV (Comma Separated Values)**: Простой текстовый формат, разделённый запятыми, подходит для небольших и средних по размеру наборов данных.
- **Excel (xlsx, xlsm, xlsx)**: Универсальный формат для хранения табличных данных, но может быть громоздким и сложным для работы с большими объёмами данных.
- **JSON (JavaScript Object Notation)**: Лёгкий текстовый формат, удобный для обмена данными между веб-приложениями и Python.
- **Feather**: Бинарный формат, разработанный специально для Pandas, обеспечивает сжатие данных.
- **Parquet**: Колоночный формат, оптимизированный для хранения больших наборов данных, обеспечивает высокую скорость сжатия и чтения.
- **HDF5 (Hierarchical Data Format)**: Гибкий формат, позволяющий хранить разнородные данные, включая массивы, таблицы и метаданные.

### Функции Pandas для чтения данных в формат DataFrame:

1. *_Выгрузка данных из файлов с расширением _.csv__:

```python
import pandas as pd

df = pd.read_csv("your_file.csv", sep=',', header='infer', names=None, index_col=None)
```

**Ключевые параметры:**

- `filepath`: путь к CSV-файлу.
- `sep`: символ, используемый для разделения значений (по умолчанию — «,»).
- `header`: номера строк, которые будут использоваться в качестве имён столбцов.
- `names`: список имён столбцов, которые будут использоваться, если нет строки заголовка.
- `index_col`: столбец, который будет использоваться в качестве индекса строки.
- `usecols`: столбцы для включения в DataFrame.
- `dtype`: типы данных для столбцов.
- `skiprows`: количество строк, которые нужно пропустить в начале файла.
- `nrows`: количество строк для чтения.
- `na_values`: значения, которые следует считать отсутствующими.
- `keep_default_na`: конвертировать ли существующие значения NaN в значение NaN Python по умолчанию.
- `verbose`: следует ли печатать информацию о данных.
- `parse_dates`: анализировать ли даты.

2. **Выгрузка данных из файлов Excel**:

```python
import pandas as pd

df = pd.read_excel(filepath="data.xlsx", sheet_name="Sheet2", header=2, index_col=0, usecols="A:C", parse_dates=["Date"])
```

**Ключевые параметры:**

- `filepath`: путь к Excel-файлу.
- `sheet_name`: имя листа с данными.
- `header`: номера строк, которые будут использоваться в качестве имён столбцов.
- `names`: список имён столбцов, которые будут использоваться, если нет строки заголовка.
- `index_col`: столбец, который будет использоваться в качестве индекса строки.
- `usecols`: столбцы для включения в DataFrame.
- `dtype`: типы данных для столбцов.
- `skiprows`: количество строк, которые нужно пропустить в начале файла.
- `nrows`: количество строк для чтения.
- `na_values`: значения, которые следует считать отсутствующими.
- `keep_default_na`: конвертировать ли существующие значения NaN в значение NaN Python по умолчанию.
- `verbose`: следует ли печатать информацию о данных.
- `parse_dates`: анализировать ли даты.
### Функции Pandas для сохранения данных:

1. **Сохранение в формат CSV**:

```python
import pandas as pd

df.to_csv("output_file.csv", sep=',')
```

**Ключевые параметры:**

- `filepath`: путь к CSV-файлу.
- `sep`: разделитель, используемый для разделения значений (по умолчанию — «,»).

2. **Сохранение в формат Excel**:

```python
import pandas as pd

df.to_excel("output_file.xlsx", sheet_name='Sheet1')
```

**Ключевые параметры:**

- `filepath`: путь к Excel-файлу.
- `sheet_name`: имя листа с данными.

**Формат ввода:**

1. Загрузите данные из файла `movies_small_df.csv` в DataFrame `movies`.
2. Укажите в качестве индексов первый столбец (нумерация с 0).
3. Сохраните данные в файл `movies_small_df.json`.

Пример:

```python
import pandas as pd

filepath = "movies_small_df.csv"

# Загрузка данных
movies = pd.read_csv(filepath, index_col=0)

# Сохранение в формате JSON
movies.to_json("movies_small_df.json")
```
