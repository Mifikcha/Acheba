В Pandas есть несколько полезных методов для работы с пропущенными значениями:

1. **Методы `isna()` / `isnull()`** — для поиска пропущенных значений.
2. **Метод `fillna()`** — для заполнения пропусков.
3. **Метод `dropna()`** — для удаления строк или столбцов с пропущенными значениями.

---

### Пример:

```python
import pandas as pd

# Загрузка данных
df_books = pd.read_csv("books_part_with_nan.csv")

# Установка индекса по столбцу 'ISBN'
df_books.set_index('ISBN', inplace=True)

# Выводим количество пропущенных значений по каждому столбцу
print(f"Пропуски по столбцам: \n {df_books.isnull().sum()}")

# Выводим строки с пропущенными значениями в столбце 'Book-Author'
mask1 = df_books['Book-Author'].isnull()
print(f"Строки с пропущенными авторами: \n {df_books[mask1].iloc[:,:3]}")

# Выводим строки с пропущенными значениями в столбце 'Publisher'
mask2 = df_books['Publisher'].isnull()
print(f"Строки с пропущенными изданиями: \n {df_books[mask2].iloc[:,:3]}")

# Заполнение пропусков
df_books.fillna({
    'Book-Author': 'Unknown',  # Заполняем пропуски в столбце 'Book-Author' значением 'Unknown'
    'Publisher': df_books['Publisher'].mode().values[0],  # Заполняем пропуски в 'Publisher' модой
    'Year-Of-Publication': df_books['Year-Of-Publication'].median()  # Заполняем пропуски в 'Year-Of-Publication' медианой
}, inplace=True)

# Проверяем, остались ли пропуски
print(f"Пропуски по столбцам после заполнения: \n {df_books.isnull().sum()}")
```

### Описание:

1. **Загрузка данных:**
    
    - Загружаем данные из файла с пропущенными значениями.
    - Устанавливаем индекс по столбцу 'ISBN'.
2. **Поиск пропущенных значений:**
    
    - С помощью `isnull().sum()` проверяем количество пропущенных значений в каждом столбце.
    - Используем маски `df['Column'].isnull()` для фильтрации строк с пропусками в конкретных столбцах и выводим первые 3 столбца этих строк.
3. **Заполнение пропусков:**
    
    - Используем метод `fillna()` для заполнения пропусков:
        - В столбце `'Book-Author'` заполняем пропуски значением `'Unknown'`.
        - В столбце `'Publisher'` заполняем пропуски наиболее часто встречающимся значением (модой).
        - В столбце `'Year-Of-Publication'` заполняем пропуски медианой.
4. **Проверка остались ли пропуски:**
    
    - После заполнения пропусков проверяем, остались ли еще пропущенные значения в DataFrame.

### Пример вывода:

1. **Пропуски по столбцам:**
    
    - Выведется количество пропущенных значений для каждого столбца до и после заполнения.
2. **Строки с пропущенными значениями:**
    
    - Для столбцов `'Book-Author'` и `'Publisher'` будут выведены строки с пропущенными значениями, ограниченные первыми тремя столбцами для наглядности.
3. **Проверка после заполнения:**
    
    - После выполнения метода `fillna()` пропуски в выбранных столбцах будут заполнены, и выведется сообщение, что пропусков больше нет.

---

### Дополнительно:

- Метод `dropna()` можно использовать для удаления строк или столбцов с пропущенными значениями, например:
    
    ```python
    df_books.dropna(axis=0, how='any', inplace=True)  # Удаляет строки с хотя бы одним пропуском
    ```
    

Этот подход позволяет эффективно работать с пропущенными данными и подготовить датасет для дальнейшего анализа или обучения модели.
