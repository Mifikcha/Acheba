Методы выборки строк:

1. **Использование метода `.loc`:** выборка данных по индексу строк.
    
2. **Использование метода `.iloc`:**
    
    - Выборка по номеру строки в таблице.
    - Поддерживает выборку по диапазонам.

---

### Формат ввода:

**Выберите строки из датасета `Books`:**

1. Выгрузите данные из файла `books_part1.csv`.
2. Выведите общую информацию о данных в таблице.
3. Задайте в качестве индексов строк столбец `'ISBN'`.
4. Выберите с 1 по 10 строку и первые 3 столбца с помощью метода `.iloc`.
5. Выберите строки с индексами `'0002005018'`, `'0060973129'` и столбец `'Book-Title'`.

Пример:

```python
import pandas as pd

# Загрузим данные в переменную df_books
df_books = pd.read_csv("books_part1.csv")

# Зададим столбец 'ISBN' как индекс
df_books.set_index('ISBN', inplace=True)

# Выведем общую информацию о данных
print(f"Общая информация о данных: {df_books.info()}")

# Выведем индексы строк
print(f"Индексы строк: {df_books.index}")

# Выберем с 1 по 10 строки и первые 3 столбца с помощью метода iloc
print(f"C 1 по 10 строки: {df_books.iloc[1:10, :3]}")

# Выберем строки с индексами '0002005018', '0060973129' и столбец 'Book-Title' с помощью метода loc
print(f"Выбор данных из столбца 'Book-Title' по индексам '0002005018', '0060973129': {df_books.loc[['0002005018', '0060973129'], ['Book-Title']]}")
```

Этот код позволяет загрузить данные, задать индекс по столбцу `'ISBN'`, вывести общую информацию о данных, выполнить выборку строк и столбцов в зависимости от нужд.
