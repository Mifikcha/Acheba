Метод `concat` позволяет объединять несколько объектов Pandas (например, Series или DataFrame) вдоль определенной оси (добавление строк или столбцов). Он поддерживает объединение по индексам, а также предоставляет параметры для настройки поведения объединения.

**Ключевые параметры:**

- `objs`: список или словарь объектов Pandas для объединения.
- `axis`: ось, вдоль которой выполняется объединение. 0 — для строк, 1 — для столбцов (по умолчанию 0).
- `ignore_index`: bool, по умолчанию False. Если True, индексы для объединенных данных будут переназначены.
- `join`: {'inner', 'outer'}, по умолчанию 'outer'. Метод объединения индексов таблиц.

---

### Пример объединения двух датасетов:

```python
import pandas as pd

# Датасет с информацией о книгах
df_books = pd.DataFrame(
    {
        "ISBN": ["0", "1", "2", "3"],
        "Title": ["B0", "B1", "B2", "B3"],
        "Genre": ["C0", "C1", "C2", "C3"]
    },
    index=[0, 1, 2, 4],
)

# Датасет с рейтингами
books_raiting = pd.DataFrame(
    {
        "Raiting": ["2", "9", "2", "7"]
    },
    index=[0, 1, 2, 8],
)

# Объединение только тех данных, которые есть в обеих таблицах
df_full = pd.concat([df_books, books_raiting], axis=1, join='inner')
print("Информация о книгах (только общие индексы):")
print(df_full)

# Изменение способа объединения, добавляем все данные с двух таблиц
df_outer = pd.concat([df_books, books_raiting], axis=1, join='outer')
print("\nДанные с объединением всех индексов:")
print(df_outer)
```

---

### Описание работы кода:

1. **Создание двух DataFrame:**
    
    - `df_books`: содержит информацию о книгах с колонками `ISBN`, `Title` и `Genre`.
    - `books_raiting`: содержит данные о рейтингах с колонкой `Raiting`.
2. **Объединение с параметром `join='inner'`:**
    
    - В результате будет объединено только те строки, у которых есть совпадение индексов в обоих DataFrame. То есть строки с индексами 0, 1, и 2 будут объединены, а строка с индексом 4 из `df_books` и строка с индексом 8 из `books_raiting` не будут включены, так как они отсутствуют в другом DataFrame.
3. **Объединение с параметром `join='outer'`:**
    
    - При использовании `join='outer'` объединяются все строки из обоих DataFrame, и если для какого-то индекса нет данных в одном из DataFrame, то соответствующие значения будут заполнены `NaN`.

### Пример вывода:

```plaintext
Информация о книгах (только общие индексы):
  ISBN Title Genre Raiting
0    0    B0    C0       2
1    1    B1    C1       9
2    2    B2    C2       2

Данные с объединением всех индексов:
  ISBN Title Genre Raiting
0    0    B0    C0       2
1    1    B1    C1       9
2    2    B2    C2       2
3    3    B3    C3     NaN
8  NaN   NaN   NaN       7
```

В первом случае, при `join='inner'`, были объединены только строки с индексами 0, 1, и 2, так как только для этих индексов имеются данные в обеих таблицах. Во втором случае, при `join='outer'`, все строки из обоих DataFrame были объединены, и для отсутствующих значений были заполнены `NaN`.

Этот подход помогает гибко управлять объединением данных с разными индексами и колонками.
