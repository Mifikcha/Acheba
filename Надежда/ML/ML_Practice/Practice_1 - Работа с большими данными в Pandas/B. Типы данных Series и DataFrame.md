В Pandas существует два типа данных: **DataFrame** и **Series**.

- **DataFrame** — 2-мерная структура (таблица), в которой можно хранить данные различного типа.
- **Series** — одна колонка или вектор-столбец данных.

### Создание одномерного типа данных в Pandas

Для создания объекта Series используется следующая форма:

```python
pd.Series(data, index=None, dtype=None, name=None, copy=False)
````

### Создание двухмерного типа данных в Pandas

Для создания объекта DataFrame используется следующая форма:

```python
pd.DataFrame(data, index=None, dtype=None, copy=False)
```

### Основные параметры:

- **data**: данные, которые вы хотите структурировать в DataFrame. Это могут быть различные структуры данных, в том числе:
    - Массивы NumPy
    - Списки списков
    - Словари
    - Другой фрейм данных
- **index**: определяет метки строк (ключи) для вашего DataFrame. Если он не указан, создается целочисленный индекс по умолчанию.
- **columns**: метки столбцов (заголовки) для вашего DataFrame. Если он не указан, создается целочисленный индекс по умолчанию.
- **dtype**: указывает тип данных для DataFrame. Если не указано, задается на основе данных.
- **copy**: логическое значение, указывающее, копировать ли данные.
- **name**: имя набора данных. Только для Series.

## Формат ввода

Создайте DataFrame с данными о пациентах. Таблица будет содержать столбцы **ФИО**, **Возраст** и **Рост** пациентов.

1. Создайте словарь с ключами "Name", "Age", "Height (cm)".
2. Заполните произвольными значениями.
3. Конвертируйте словарь в формат DataFrame.
4. Выведите содержимое таблицы.

```python
import pandas as pd

data_dict = {
    "Name": ["Иванов Алексей", "Потапова Елена", "Жданов Антон"],
    "Age": [22, 35, 58],
    "Height (cm)": [190, 180, 165]
}

df = pd.DataFrame(data_dict)

print("Пациенты:")
print(df)
```
