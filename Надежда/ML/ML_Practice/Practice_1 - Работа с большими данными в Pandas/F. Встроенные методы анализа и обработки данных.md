1. **Управление столбцами**

Основные методы и свойства управления столбцами:

- Список всех столбцов хранится в свойстве `.columns`.
- Чтобы переименовать столбец, можно воспользоваться методом `.rename`:

```python
df.rename(columns={"Old name": "New name"})
```

2. **Встроенные методы расчёта статистических показателей**

`DataFrame` и `Series` имеют большое количество встроенных статистических методов для анализа данных, таких как `sum`, `max`, `mean` и т.д.

- Метод `.describe` выводит основные статистические показатели по каждому столбцу.
- Предварительный анализ данных:
    - Вывод списка столбцов и их типов — `.info()`
    - Просмотр уникальных значений в столбце (для типа `Series`) — `.unique()`
    - Количество уникальных значений в датасете (для типов `Series` и `DataFrame`) — `.nunique()`
    - Возвращает `Series` объект, содержащий частоту каждой отдельной строки в `DataFrame` — `.value_counts()`

---

### Формат ввода:

1. Загрузите данные из файла `movies_small_df.csv` в датафрейм `movies`.
2. Выведите количество строк и столбцов.
3. Выведите общую информацию о столбцах и их типах.
4. Выведите список столбцов.
5. Выведите основные статистические показатели по всем столбцам.
6. Выведите средний рейтинг фильмов.
7. Выведите количество фильмов по каждому жанру.

Пример:

```python
import pandas as pd

# Загрузим данные в переменную movies
movies = pd.read_csv("movies_small_df.csv")

# Выведем информацию о наборе данных
print("Размерность по каждой оси (количество строк и столбцов):")
print(f"{movies.shape}")

# Выведем информацию о наборе данных
print("Общая информация о наборе данных:")
print(f"{movies.info()}")

# Выведем список столбцов
print("Список столбцов:")
print(f"{movies.columns}")

# Выведем основные статистические показатели по всем столбцам
print("Основные статистические показатели данных:")
print(f"{movies.describe()}")

# Выведем средний рейтинг фильмов
print("Средний рейтинг фильмов:")
print(f"{movies['Ratings'].mean()}")

# Выведем количество фильмов по каждому жанру
print("Уникальные жанры:")
print(f"{movies['Genre'].unique()}")
print("Количество фильмов по каждому жанру:")
print(f"{movies['Genre'].value_counts()}")
```
