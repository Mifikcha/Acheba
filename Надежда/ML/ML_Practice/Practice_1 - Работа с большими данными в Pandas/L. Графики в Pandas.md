Pandas предоставляет несколько удобных методов для построения графиков, включая:

- **Метод `plot`**: для создания различных типов графиков.
- **Метод `hist`**: для построения гистограмм.

---

### Пример:

```python
import pandas as pd

# Создание DataFrame с данными о фильмах
df_movies = pd.DataFrame({
    'Name': ['13 Sins', '22 Jump Street', '3 Days to Kill', '300: Rise of an Empire', 'A Haunted House 2'],
    'Budget': [4000000, 50000000, 28000000, 110000000, 3500000],
    'Likes': [4632, 3465, 328, 2429, 12163]
})

# Построение графика зависимости бюджета от количества лайков
df_movies.plot(kind='bar', x='Budget', y='Likes', 
               title='Зависимость бюджета от лайков', color='c', 
               ylabel='Likes', xlabel='Budget', grid=True)

# Построение гистограммы распределения данных
df_movies.hist()
```

---

### Описание:

1. **Создание DataFrame:**
    
    - `df_movies` содержит информацию о фильмах: названия, бюджеты и количество лайков.
2. **График зависимости бюджета от лайков:**
    
    - Используем метод `plot`, чтобы построить столбчатую диаграмму (`kind='bar'`) с осью `x` как бюджет и осью `y` как количество лайков.
    - Устанавливаем заголовок с помощью параметра `title`, подписи осей через `xlabel` и `ylabel`, а также добавляем сетку с помощью параметра `grid=True`.
3. **Гистограмма распределения данных:**
    
    - Используем метод `hist()` для построения гистограммы, которая показывает распределение данных по всем столбцам DataFrame (в данном случае по столбцам `Budget` и `Likes`).

---

### Ожидаемый результат:

1. **График зависимости бюджета от лайков**:
    
    - Будет построена столбчатая диаграмма, где ось X будет показывать бюджеты фильмов, а ось Y — количество лайков для каждого фильма. Цвет столбцов будет установлен как `c` (цвет по умолчанию).
2. **Гистограмма**:
    
    - Гистограмма покажет распределение значений для столбцов `Budget` и `Likes` с дефолтными интервалами (10 корзин).

---

### Дополнительные настройки:

- В методе `plot()` можно настроить другие параметры, такие как `figsize` (размер графика), `legend` (показ легенды), `color` (цвет столбцов) и другие.
- Метод `hist()` также поддерживает параметр `bins`, который позволяет настроить количество корзин в гистограмме, а `color` позволяет изменить цвет.

Этот способ визуализации полезен для первичного анализа данных, чтобы наглядно понять взаимосвязи между переменными и распределение значений в датасете.
