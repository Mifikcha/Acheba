# Общие правила

Важно: в базе любой из перечисленных ниже агентов способен запускать субагентов для любых целей, если сочтет нужным.

Также каждый агент должен, если ему понадобиться, выйти в интернет и поискать вопрос там (вполне возможно, что это необязательно, ведь у нас есть отдельный агент по поиску информации).

Каждый агент должен иметь возможность плотно взаимодействовать с другими агентами и кидать им запросы для выполнения с одобрения оркестратора.

Система должна быть достаточно автономной, чтобы я смог условно поставить флажок \goal и она меня не отвлекала по мелочам. Но также я должен иметь возможность более ручного управления и взаимодействия с ней, на случай если мне это понадобится.

Возможно, стоит дать им имена, поскольку сортировать их по задачам как-то не особо звучит. Типа агент главный оркестратор отдал агенту по поиску информации такой-то такой-то запрос, тот отдал кодинг агенту вот такой кусок, и еще агент по написанию статей получил такой-то кусок. Неудобно. По-моему гораздо проще дать имена. Но об этом позже.

# Роли агентов

Оркестратор - должен читать мои сообщения в телеграмм, в том числе голосовые, решать какого рода это запрос и отдавать его другим агентам / предлагать создать нового агента, если запрос выходит за рамки одного из агентов / предлагать расширить компетенции одного из агентов.

Кодинг агент - основной агент для кодинга. Идеально если это будет codex в терминале в виде нескольких базовых сущностей вроде оркестратор, внедрятель и рефактор / багфикс. Вся эта тройка агентов может работать параллельно. Должна быть довольно сложная модель вроде gpt 5.5 хотя бы, а лучше еще лучше.

Агент по написанию статей - агент выполняет одну задачу: взять информацию из агента по поиску информации, оформить ее определенным заранее написанным образом по правилам редактирования написанными мной или по моим правкам голосом (оркестратор сам решает, что нужно задействовать агента по написанию статей). Агент должен уметь оформлять вещи в word, pdf, latex формате. По базе основный форматы - это word и pdf, latex опционален. Однако агент должен тесно взаимодействовать с агентом по поиску информации и кодинг агентом, поскольку иногда правки могут быть довольно трудновыполнимыми для агентов. Что-то в роде: исправь формулы в ворде по шаблону, прописанному в методичке такой-то такой-то. Кк выяснилось, это довольно сложная задача для агента.

Агент по поиску информации представляет собой, по сути, минимум 2 агента - один ищет информацию в интернете, проводит столь глубокое исследование вопроса, сколько он считает нужным, а второй его проверяет, проводит факт-чек. В целом, ChatGPT с этим очень неплохо справляется и режим исследования здесь вполне пригодится.

Агент по поиску информации частично связан с агентом по просмотру видосов. Агент по просмотру видосов уже реализован, ссылка на ютуб: https://www.youtube.com/watch?v=So3srrfKiWg

Агент по базе Obsidian - это агент, который имеет доступ к базе Obsidian и может редактировать ее и вносить правки. Идеально будет, если он сможет управлять некоторыми плагинами или плагинами, которые в целом легко поддаются управлению потому, что имеют легкоредактируемые для агентов файлы вроде yaml или md.

Агент репетитор - это агент, который тесно связан с агентом obsidian, по крайней мере может запросить у него какую-то информацию или самостоятельно взять ее из базы obsidian. Главная задача этого агента - это статистика учеников, редактирование заметок по их успеваемости, ведение excel таблички через API, изменение расписания итд. Главная фишка - он должен быть ПОЛНОСТЬЮ автономен. Т.е. вот что я его попросил делать и повторять - то он делает ПОЛНОСТЬЮ без моего участия. Попросил читать все диалоги в телеграмме и потом на их основании менять расписание в excel табличке - он так и делает, пока я его не остановлю. Попросил из записей уроков с помощью агента по просмотру видосов извлекать ключевые моменты из урока, оценивать самостоятельность ученика и на этом всем формировать отчет для родителей в тг - он это делает сам, без моего участия. Я разве что запускаю запись урока. Все.

Агент Telegram выполняет функцию отправки сообщений родителям и общения с ними. Теоретически, он может писать от моего имени в телеграмм или, по крайней мере, взаимодействовать с агентом по поиску информации чтобы искать лидов.
